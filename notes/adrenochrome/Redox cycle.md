# Redox cycle

A **Redox cycle** (reduction-oxidation cycle) is a process in which a molecule is repeatedly oxidized and then reduced, often generating [[notes/_link/Reactive Oxygen Species]] (ROS) in the process.

## Adrenochrome Redox Cycling
The conversion between [[Leuco-adrenochrome]] and [[Adrenochrome]] is a classic example of a redox cycle. This cycling can continuously generate [[Superoxide anion]] radicals, contributing to cellular [[notes/_link/Oxidative Stress]].

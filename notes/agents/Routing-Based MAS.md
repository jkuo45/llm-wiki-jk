# [[Routing-Based MAS]]

[[Routing-Based MAS]] is a design pattern for [[Multi-Agent Systems (MAS)]] where an orchestration layer acts as a router. Depending on user input, this layer decides which specific agents to invoke. While it allows for targeted agent interaction, the routing layer can become a single point of failure; an error at this level can lead to communication mishaps or system discrepancies.

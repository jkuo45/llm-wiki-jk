# [[Monte Carlo Tree Search (MCTS)]]

[[Monte Carlo Tree Search (MCTS)]] is a sophisticated decision-making algorithm used in the [[Plan Generation]] phase for agents. By simulating numerous possible future actions and their outcomes, the agent can evaluate different strategies and select the plan that most effectively leads toward its defined [[Goal|goals]].

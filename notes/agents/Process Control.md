# [[Process Control]]

[[Process Control]] is an industrial application of [[Multi-Agent Systems (MAS)]] where agents are used to manage and monitor complex production and manufacturing processes. These systems ensure that industrial operations run efficiently and safely by coordinating various sensors, controllers, and actuators.

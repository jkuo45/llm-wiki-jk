# [[Broadcast-Based MAS]]

[[Broadcast-Based MAS]] is a [[Multi-Agent Systems (MAS)]] design pattern that eliminates the routing layer (which can be a single point of failure). In this architecture, information is disseminated to all agents simultaneously. Each agent then decides whether to contribute to the final aggregated output, enhancing the system's [[Robustness]] and preventing communication mishaps.

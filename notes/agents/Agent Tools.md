# [[Agent Tools]]

[[Agent Tools]] (or [[Agent Tools|Tools]]) are the specialized capabilities provided to agents to help them finish their tasks. They act as "Swiss Army knives" for agents and can include [[API|APIs]], executable functions, or other external services. The agent leverages these tools to interact with its [[Environment|environment]] and execute its [[Planning|plan]].

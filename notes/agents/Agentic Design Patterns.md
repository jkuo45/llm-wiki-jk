# [[Agentic Design Patterns]]

[[Agentic Design Patterns]] are conceptual frameworks and workflows used to organize the behavior of software agents. These patterns improve [[Modularity]], [[Maintainability]], and [[Efficiency]] within [[Agent-Based Systems (ABS)|agent-based systems]]. Key examples include [[Agent Reflection|Reflection]], [[Agent Tools|Tool Use]], [[Planning]], and [[Multi-agent Collaboration]].

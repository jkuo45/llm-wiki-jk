# [[Hierarchical Planning]]

[[Hierarchical Planning]] is a variation of the [[Planning]] process where agents decompose complex [[Goal|goals]] into smaller, manageable sub-plans. This structured approach allows for more efficient problem-solving in systems with high levels of complexity or long-term objectives.

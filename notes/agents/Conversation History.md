# [[Conversation History]]

[[Conversation History]] is a fundamental component of [[Agent Memory]]. It involves passing previous interactions between the user and the agent back to the underlying [[Large Language Models (LLMs)|LLM]]. This allows the agent to maintain context, understand references to past topics, and provide more coherent responses over time.

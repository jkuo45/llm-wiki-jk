# [[Multi-agent Collaboration]]

[[Multi-agent Collaboration]] is a primary [[Agentic Design Patterns|agentic design pattern]] where multiple agents work together to achieve common objectives. Crucial for handling tasks too complex for a single agent, collaboration requires established [[Agent-to-Agent Communication Protocol (AACP)|communication protocols]], coordination, and negotiation strategies.

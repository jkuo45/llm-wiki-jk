# [[Goal Check]]

[[Goal Check]] is an essential step in the [[Execution]] phase where an agent assesses whether its objectives have been met. After performing a sequence of actions, the agent re-evaluates the system's state to determine if it should end its activity, move to the next goal, or [[Replanning|replan]] based on current circumstances.

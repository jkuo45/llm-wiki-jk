# [[Modularity]]

[[Modularity]] is a defining characteristic of [[Agentic Systems]]. By dividing a system into independent, specialized agents, each with its own responsibilities and tools, developers can create architectures that are easier to build, test, and scale. This approach also enhances [[Maintainability]] and allows for easier system updates.

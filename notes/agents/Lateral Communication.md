# [[Lateral Communication]]

[[Lateral Communication]] is a component of the [[Agent-to-Agent Communication Protocol (AACP)]] in [[Multi-Agent Systems (MAS)]]. It enables direct, peer-to-peer communication between agents situated at the same hierarchical level. This is essential for collaborative problem-solving, rapid information exchange, and coordination among equals.

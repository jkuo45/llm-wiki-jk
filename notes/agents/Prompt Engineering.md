# [[Prompt Engineering]]

[[Prompt Engineering]] is the practice of crafting the instructions (the [[Prompt Engineering|prompt]]) that define how an agent behaves and operates. The prompt outlines an agent's goals and constraints. In complex [[Agentic Systems]], responsibilities are divided among multiple agents so that the prompt for each individual agent remains simple and manageable, avoiding the bottlenecks of a single, over-complex prompt.

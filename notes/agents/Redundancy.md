# [[Redundancy]]

[[Redundancy]] is an inherent feature of [[Multi-Agent Systems (MAS)]] where multiple agents have overlapping capabilities. This redundancy provides built-in [[Fault Tolerance]] and [[Resilience]]; if one agent malfunctions or fails, other agents can take over its responsibilities, ensuring the system's continued operation.

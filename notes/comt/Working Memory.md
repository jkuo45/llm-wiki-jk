# Working Memory

**[[Working Memory]]** is a cognitive system with a limited capacity that is responsible for temporarily holding and processing information. it is a core component of [[Executive Function]].

## Neural Basis
The [[Prefrontal Cortex]] ([[Prefrontal Cortex]]) is the primary brain region associated with [[Working Memory]]. Optimal performance depends on balanced [[Dopamine]] signaling within the PFC.

## Role of COMT
The [[COMT]] enzyme is a major regulator of [[Dopamine]] levels in the [[Prefrontal Cortex]]. 
- **Slow [[COMT]] ([[Val158Met]] Met/Met):** Associated with higher baseline dopamine and often better performance on complex working memory tasks.
- **Fast [[COMT]] ([[Val158Met]] Val/Val):** Associated with lower baseline dopamine and potentially poorer working memory performance, especially under stress.

## Connections
- [[Prefrontal Cortex]]: The anatomical seat of working memory.
- [[Dopamine]]: The primary neurotransmitter modulating working memory capacity.
- [[COMT]]: Regulates the availability of dopamine in the cortex.

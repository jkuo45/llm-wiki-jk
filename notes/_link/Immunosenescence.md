# Immunosenescence

Immunosenescence refers to the gradual deterioration of the immune system associated with aging, leading to increased susceptibility to infections, autoimmune diseases, and cancer.


**Immunosenescence** (or [[Immune Aging]]) is the systemic deterioration of immune function that accompanies [[notes/_link/Aging]].

## Hallmarks
- Impaired immune reactions to new antigens.
- Perturbed memory responses, especially in [[T Cell]] immunity.
- Accumulation of memory T cell subsets with [[notes/_link/Senescence]]-like features.
- Accompanied by [[notes/_link/Inflammaging]], a chronic state of innate immune activation.


## Reversal
- Clinical implementation of [[Autophagy Inducer|autophagy inducers]] (e.g., [[Rapamycin]], [[notes/_link/Metformin]], [[notes/_link/Spermidine]]) provides potential to partially reverse systemic immunosenescence.

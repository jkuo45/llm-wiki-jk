# Pulse Oximetry

[[Pulse Oximetry]] non-invasively estimates arterial oxygen saturation (SpO2) using light absorption. [[Methylene blue]] in blood artifactually lowers the reading by interfering with measurement wavelengths; [[Arterial Blood Gas]] / [[Co-oximetry]] should be used instead during and after infusion.

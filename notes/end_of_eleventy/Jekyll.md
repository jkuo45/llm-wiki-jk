# Jekyll

[[Jekyll]] is a Ruby-based static site generator created by GitHub co-founder Tom Preston-Werner in 2008. It repopularized the concept of "blogging for hackers" and became widely used due to its integration with GitHub Pages. It served as a direct inspiration for [[Eleventy]].

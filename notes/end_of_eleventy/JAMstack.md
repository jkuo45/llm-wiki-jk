# JAMstack

[[JAMstack]] (JavaScript, APIs, and Markup) is a modern web development architecture based on client-side JavaScript, reusable APIs, and pre-rendered Markup. The term was popularized by [[Netlify]] CEO Matt Biilmann to describe a shift away from traditional database-driven CMS platforms like [[WordPress]].

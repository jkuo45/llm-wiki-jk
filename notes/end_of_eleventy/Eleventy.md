# Eleventy

[[Eleventy]] (also known as 11ty) is a lightweight, flexible static site generator (SSG) positioned as an "anti-framework". Created by [[Zach Leatherman]] in 2017, it was designed to leverage the Node.js ecosystem without imposing a rigid client-side JavaScript framework.

## Key Features
- Supports multiple templating engines (Liquid, Nunjucks, Markdown, etc.)
- Zero client-side JavaScript by default
- Highly flexible and performance-focused

In 2024, Eleventy moved to [[Font Awesome]], and in 2026, it was rebranded as [[Build Awesome]].

# CASTOR2

CASTOR2 is a protein that forms a complex with [[CASTOR1]] to function as an arginine sensor for the [[mTORC1]] pathway.

## Function

CASTOR2 is a paralog of [[CASTOR1]] that also binds [[Arginine]] and regulates [[mTORC1]] via [[GATOR2]]. It provides redundancy and combinatorial sensitivity to arginine concentrations.

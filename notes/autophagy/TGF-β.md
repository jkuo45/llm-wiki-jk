# TGF-β

Transforming growth factor-beta (TGF-β) is a multifunctional cytokine that regulates various cellular processes; its signaling pathway involves [[SMAD3]], which can negatively regulate [[TFEB]] expression.

## Function

TGF-β is a pleiotropic cytokine that signals via SMAD2/3 phosphorylation by the type II and type I receptor complex (TβRII/TβRI). It regulates cell proliferation, differentiation, migration, and immune suppression.
## Autophagy Connection

TGF-β induces [[Autophagy]] via SMAD3-dependent upregulation of autophagy genes. It also activates [[mTORC1]] in certain contexts, creating complex, context-dependent regulation.

# Orion

The Orion Multi-Purpose Crew Vehicle (Orion MPCV) is a class of partially reusable spacecraft to be used in [[NASA]]'s [[Artemis program]]. The spacecraft consists of a Crew Module (CM) and a Service Module (SM). The [[Artemis II]] Orion capsule was named [[Integrity]].

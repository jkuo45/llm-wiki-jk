# Machine Learning (ML)

Machine Learning is a subset of [[Artificial Intelligence]] that focuses on the use of data and algorithms to imitate the way that humans learn, gradually improving its accuracy. In accounting, ML is used for [[Predictive Analytics]], [[Fraud Detection]], and automating reconciliations.

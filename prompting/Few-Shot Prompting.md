# Few-Shot Prompting

[[Few-Shot Prompting]] is a technique that enables [[in-context learning]] by providing a few demonstrations (examples) within the prompt to steer the model toward better performance on a specific task.

## Key Components
- **Exemplars**: A small set of input-output pairs that demonstrate the desired behavior.
- **Task Instruction**: A description of the task to be performed.
- **Format**: The structure of the examples (e.g., Q&A format) significantly affects performance.

## Benefits
- Improves model performance on complex or specialized tasks.
- Reduces the need for [[Fine-tuning]].
- Allows for rapid prototyping of new tasks.

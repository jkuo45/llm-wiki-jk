# [[Robotic Process Automation (RPA)]]

[[Robotic Process Automation (RPA)]] is a technology that leverages software agents to automate repetitive, rules-based computational tasks. In an agentic workflow, RPA is an example of [[Agent Tools|tool use]], where the primary agent delegates specific tasks to specialized software tools to enhance functionality and free up its own processing power for decision-making.

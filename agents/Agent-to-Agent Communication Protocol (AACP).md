# [[Agent-to-Agent Communication Protocol (AACP)]]

The [[Agent-to-Agent Communication Protocol (AACP)]] is designed to facilitate structured and efficient communication among agents within a [[Multi-Agent Systems (MAS)|Multi-Agent System]]. It is pivotal for achieving consensus and addressing complex problems collaboratively. The protocol features both [[Hierarchical Communication]] and [[Lateral Communication]] architectures.

# [[Plan Selection]]

[[Plan Selection]] is the stage in the [[Planning]] phase where an agent evaluates the various options developed during [[Plan Generation]]. The agent selects the most appropriate plan based on predefined optimization criteria, such as efficiency or success probability, ensuring it uses resources effectively to achieve its objectives.

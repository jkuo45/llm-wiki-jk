# [[Agent-Based Systems (ABS)]]

[[Agent-Based Systems (ABS)]] are software architectures composed of autonomous or semi-autonomous agents. These systems allow agents to make decisions, formulate [[Planning|plans]], execute actions, and adapt to changes. A common framework for organizing behavior within these systems is the [[Plan-Execute Agentic Design Pattern]].

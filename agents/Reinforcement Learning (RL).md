# [[Reinforcement Learning (RL)]]

[[Reinforcement Learning (RL)]] is a machine learning paradigm where an agent learns to make decisions by receiving rewards or feedback from its environment. It is used in [[Autonomous Systems]] and [[Agent Reflection|reflection]] workflows to help agents improve their strategies and adapt their behaviors based on past performance and new data.

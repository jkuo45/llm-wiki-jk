# [[Agent Reflection]]

[[Agent Reflection]] (or simply [[Agent Reflection|Reflection]]) is an [[Agentic Design Patterns|agentic design pattern]] where an agent thinks about its own thinking process. This involves evaluating its actions, learning from experiences, and adapting its strategies based on past performance. It enables agents to improve over time, make better decisions, and avoid repeating mistakes.

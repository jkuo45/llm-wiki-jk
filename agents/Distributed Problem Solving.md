# [[Distributed Problem Solving]]

[[Distributed Problem Solving]] is a primary benefit of [[Multi-Agent Systems (MAS)]]. It involves breaking down a large, complex problem into smaller sub-tasks that can be solved in parallel by multiple agents. This approach increases the overall system [[Efficiency]], [[Scalability]], and [[Robustness]].

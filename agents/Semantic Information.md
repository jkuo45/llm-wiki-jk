# [[Semantic Information]]

[[Semantic Information]] is a specialized form of [[Agent Memory]]. Instead of merely saving entire raw [[Conversation History|conversations]], the system extracts and stores meaningful, distilled data from past interactions. This structured information allows the agent to maintain deep context and make better decisions in future tasks.

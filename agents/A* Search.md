# [[A* Search]]

[[A* Search]] is a decision-making algorithm used within the [[Plan Generation]] phase of an [[Agent-Based Systems (ABS)|agent-based system]]. It helps the agent evaluate available resources, actions, and constraints to generate one or more [[Planning|plans]] to achieve set [[Goal|goals]] efficiently.

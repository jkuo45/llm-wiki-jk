# [[Distributed Manufacturing]]

[[Distributed Manufacturing]] is an application of [[Agentic Systems]] where a network of autonomous agents (such as assembly robots) manages production. In this system, each agent can plan its specific assembly steps based on incoming orders and then execute those actions to produce products efficiently.

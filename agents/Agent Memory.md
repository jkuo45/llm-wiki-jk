# [[Agent Memory]]

[[Agent Memory]] serves as the backbone of [[Large Language Models (LLMs)|LLM]] agents, acting as their personal archive of knowledge and experiences. It enables agents to understand context, learn from past interactions, and make informed choices. Memory can range from simple [[Conversation History]] to extracted [[Semantic Information]].

# [[State Monitoring]]

[[State Monitoring]] is the process in the [[Execute Phase]] where an agent continuously assesses the state of the system to determine if its actions are progressing toward its [[Goal|goals]]. By monitoring the [[Environment]] and receiving feedback, the agent can adapt its [[Planning|plan]] or trigger [[Replanning]] to cope with dynamic changes.

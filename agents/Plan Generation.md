# [[Plan Generation]]

[[Plan Generation]] is a critical stage in the [[Planning]] phase where an agent develops one or more possible courses of action to achieve its set [[Goal|goals]]. This process often employs decision-making algorithms like [[A* Search]] or [[Markov Decision Processes (MDPs)]] to evaluate available resources and constraints.

# SIRT 在腫瘤細胞代謝中的多效角色

## 概述

**sirtuin 家族**（SIRT1–SIRT7）是 NAD+ 依賴的醯基轉移酶，其在腫瘤代謝中的多效性源自三個來源：(1) **亞細胞區室化** — 核 SIRT1/SIRT6/SIRT7、胞質 SIRT2 與線粒體 SIRT3/SIRT4/SIRT5 作用於不同的代謝節點；(2) **催化混雜性** — 去乙醯化、去丙二醯化、去琥珀醯化、去麩醯胺醯化與 ADP-核糖基化；以及 (3) **依脈絡而定** — 同一個 sirtuin 可因腫瘤類型、階段與基因背景而成為腫瘤抑制性或致癌性。

## 代謝軸

### 糖解與 Warburg 效應

- **SIRT6** 是最明確的抗 Warburg sirtuin：它共同抑制 HIF-1α 並抑制糖解酶（葡萄糖轉運蛋白、Hexokinase 2）的轉錄，且去乙醯化 ERK1/2 啟動子上的組織蛋白 H3。SIRT6 缺失容許「Warburg 樣」有氧糖解；其恢復在 HCC/神經膠質瘤中抑制糖解（經由 JAK2/STAT3）並增強肺癌的放射敏感性。
- **SIRT3** 透過氧化還原間接對抗有氧糖解：它活化 MnSOD/SOD2 與 IDH2，降低 ROS，從而**使 HIF-1α 不穩定** — 切斷該主控糖解轉錄因子。因此 SIRT3 缺失傾向於 Warburg 效應。
- **SIRT1** 為雙向：PGC-1α 去乙醯化抑制糖解並驅動氧化磷酸化，然而 SIRT1 在某些脈絡中（例如 CRC 雜合缺失誘發 c-Myc → 麩醯胺酸代謝 → 增殖）也與致癌性 c-Myc 和 HIF-1α 結盟。
- **SIRT2** 在某些情況下透過去乙醯化磷酸甘油酸變位酶 Lys100 → 導向 NADPH 生成並在肺癌中加速腫瘤生長，促進腫瘤糖解。
- **SIRT5** 在 CRC、HCC 與 NSCLC 中為促腫瘤性，透過將代謝重編程為糖解與麩醯胺酸分解。

### 麩醯胺酸代謝與 TCA 回補

- **SIRT4** 是最明確的抗麩醯胺酸節點：它單體 ADP-核糖基化 **GDH**，限制 glutamate→α-ketoglutarate 通量，並限制「麩醯胺酸成癮」癌症所依賴的 TCA 循環回補碳供應。SIRT4 缺失常見於 HCC、胃癌、CRC、膀胱癌與乳癌，並預測不良預後 — 使其成為代謝性腫瘤抑制因子。
- **SIRT5** 則相反：在 CRC 中它增強麩醯胺酸分解並去琥珀醯化 **LDHB** 以過度活化自噬，供應癌細胞回收的營養。
- **SIRT3** 透過刺激丙酮酸脫氫酶複合體（PDC）與活化 AceCS2 接入此迴路，有利於氧化性 TCA 通量並抑制糖解程序。
- NAD+/TCA 連結廣義上重要：MYC 高表現腫瘤經由 Complex I 再生的 NAD+ 維持麩醯胺酸驅動的 TCA 循環，而 sirtuin 是這些相同路徑上對 NAD+ 敏感的煞車。這就是 NAD+ 耗竭在 MYC 高表現與麩醯胺酸依賴性癌症中作為合成致死槓桿興起的原因，也是 sirtuin 調節（例如 EX-527 等 SIRT1 抑制劑、SIRT5 致活劑）被探索用於治療的原因。

### ROS、氧化還原與脂質代謝

- **SIRT3** 與 **SIRT5** 協調抗氧化防禦（SOD2/SOD1、IDH2、NADPH 回收）；SIRT3 降低線粒體膜電位與 ROS，保護基因體完整性（ATM–Chk2）但亦賦予放射抗藥性。
- **SIRT6** 透過去乙醯化 SREBP 啟動子上的 H3 以抑制 SREBP1/2 與 ChREBP，從而抑制從頭脂肪生成。
- **SIRT1** 活化胞質 AceCS1（脂肪酸合成）並調節 PPAR-γ，而 **SIRT4** 抑制肝脂肪酸氧化（MTPα）並在營養充足條件下促進脂質堆積。

### 生長機制與細胞命運

- **SIRT7** 驅動核糖體生物發生（RNA Pol I 活化 rDNA）並經由 H3K18 去乙醯化抑制 p21 — 為腫瘤所需的生物合成能力提供燃料 — 且在乳癌、甲狀腺癌與 HCC 中過度表現。
- **SIRT1** 去乙醯化 p53、Ku70 與 FOXO 因子，有利於修復而抑制凋亡；這在正常的急性壓力下具保護性，但在慢性活化下可能促進腫瘤發生。
- **SIRT2** 調節細胞週期（微管蛋白）並展現腫瘤抑制（乳癌中的 BRCA1–BARD1、IDH1 去乙醯化抑制 CRC 遷移）與致癌（Slug 穩定化）兩面。

## 重點摘述（第一部分）

SIRT 形成一個**區室化、NAD+ 依賴的代謝變阻器**：核 SIRT1/6 對抗 Warburg 程序並控制轉錄，線粒體 SIRT3–5 調節 TCA、麩醯胺酸回補與氧化還原，而 SIRT2/7 調諧細胞骨架與生物合成能力。它們對 NAD+ 的共同依賴意味著腫瘤代謝狀態（Complex I 活性、麩醯胺酸分解、NAMPT/CD38）直接控制 sirtuin 輸出 — 這就是 NAD+ 耗竭在 MYC 高表現與麩醯胺酸依賴性癌症中作為合成致死槓桿興起的原因，以及為何 sirtuin 調節（例如 EX-527 等 SIRT1 抑制劑、SIRT5 致活劑）正被探索用於治療。

**注意：** 每個 sirtuin 皆展現雙重/依脈絡的行为，因此代謝表型無法從單一 sirtuin 孤立解讀。

# 依 Sirtuin 分類的雙重 / 依脈絡行為

## SIRT1 — 典型「雙面刃」

最具依脈絡性的成員。兩面皆經由重疊的標的發揮作用：

- **腫瘤抑制性：** 去乙醯化 p53、Ku70、p73 與 FOXO 因子，因此在急性基因毒性壓力下它削弱凋亡以利修復；去乙醯化 hnRNP A1 以在 HCC 中抑制糖解/生長；去乙醯化雄激素受體（Lys630）以抑制前列腺癌生長；抑制 NF-κB p65 與 HMGB1（卵巢癌中的抗血管新生）；去乙醯化 PAK1 K420 以阻礙膠質母細胞瘤。
- **致癌/促腫瘤：** 在*慢性*情況下去乙醯化 p53 實際上削弱了腫瘤抑制煞車，且 SIRT1 與 c-Myc 和 HIF-1α 結盟；驅動三陰性乳癌的 EMT/metadherin 化療抗藥性；促進 NSCLC 的 cisplatin 抗藥性（VEGF-A）；驅動 tamoxifen 抗藥性（經由 FoxO1 的 MRP2）；透過 CDK2 去乙醯化 → p27 降解促進 T-ALL。
- **關鍵脈絡變數：**
  - **劑量依賴** — 在 CRC 中最明確示範：SIRT1 雜合缺失誘發 c-Myc → 麩醯胺酸代謝 → 增殖，但同合缺失觸發凋亡並減少腫瘤形成。
  - **腫瘤類型/階段** — 在神經膠質瘤/HCC 中為腫瘤抑制因子，在胃癌/子宮內膜/白血病脈絡中為促進因子。
  - **嚴重度** — 與其心臟表型相同原則（7.5× 心臟過度表現具保護性；12.5× 致病性）。

## SIRT2 — 多數上皮中的腫瘤抑制因子，基底樣/白血病中的促進因子

- **抑制面：** 促進 BRCA1–BARD1 異源二聚化 → 同源重組（乳腺）；去乙醯化 IDH1 以抑制 CRC 肝轉移；去乙醯化 AKR1C1 + 抑制 STAT3 以抑制 NSCLC 遷移；使卵巢癌對 cisplatin 增敏。
- **促進面：** 去乙醯化 Slug → 穩定化 → 基底樣乳腺腫瘤發生/侵襲；去乙醯化磷酸甘油酸變位酶 K100 → NADPH 通量 → 加速肺腫瘤生長；促進子宮內膜癌幹性/MEK-ERK 訊號；去乙醯化 LMO2 以驅動 T-ALL 生長/植入。
- **脈絡：** 常*對立*於保護性的 SIRT1/3/6 軸的胞質 sirtuin；傾向於神經退化（AD、PD、HD）中有害，但在代謝/腎/關節疾病中具保護性。在白血病中分裂：NAMPT/SIRT2 活化減少 AML 增殖，但 SIRT2 抑制抑制 T-ALL。

## SIRT3 — 多為保護性，但線粒體氧化表型為雙面刃

- **抑制面（代謝）：** 活化 MnSOD/SOD2 與 IDH2 → 抑制 ROS → 使 HIF-1α 不穩定（抗 Warburg）；刺激 PDC；在卵巢癌中透過 Twist 下調/EMT 抑制轉移；下調 GST-π1 → 使 HCC 對 sorafenib/化療增敏；在乳腺中破壞 ERα–p53 交互作用。
- **促進面（矛盾地經由相同生物學）：** 抑制 ROS 如此之好，動力學上賦予放射/化療抗藥性 — 在 NSCLC 中透過 ATM–Chk2 促進 DNA 修復/放射抗藥性，在 CRC 中改善抗藥性（SOD2/PGC-1α）；去乙醯化 p53（致癌角色）；重編程脂肪酸合成（ACC1 上調）以驅動子宮頸癌侵襲；透過 Ku70–Bax 促進神經膠質瘤存活；在淋巴結陽性乳癌與 OSCC 中升高。
- **核心張力：** 線粒體「守護者」表型（低 ROS、OXPHOS 完整、基因體穩定）*對抗腫瘤起始具保護性*，但*經由防止壓力誘發死亡而支持已確立的腫瘤*。在 NAFLD 與骨關節炎中亦真正為雙重。

## SIRT4 — 最一致具腫瘤抑制性，但帶有代謝代價

- **抑制因子（主導）：** 經由單體 ADP-核糖基化抑制 GDH → 限制麩醯胺酸驅動的 TCA 回補（直接攻擊「麩醯胺酸成癮」）；透過氨基酸刺激的胰島素分泌抑制 mTOR；在 HCC 中上調 p16/p21 並抑制 CyclinB1/Cdc2/Cdc25c → 凋亡；在 CRC 中恢復 E-cadherin；經由麩醯胺酸代謝抑制負向調控 SIRT1。
- **缺點（為何脈絡仍重要）：** 其 GDH 抑制減少氨基酸刺激的胰島素分泌，並抑制肝脂肪酸氧化（MTPα）→ 脂質堆積；它是唯一具有有害心臟效應（加劇 Ang II 肥大/纖維化）的 sirtuin。因此 SIRT4 雖抗腫瘤，但代謝上「節儉」，且缺失在 HCC、胃癌、CRC、膀胱癌、乳癌中一致預測不良存活。

## SIRT5 — 具促腫瘤代謝偏好的去乙醯酶

- **促進面（代謝重編程）：** 在 HCC、CRC、NSCLC 中過度表現，推動麩醯胺酸分解 + 糖解；去琥珀醯化 LDHB → 過度活化的自噬 → 腫瘤生長的營養回收；CRC 中依賴去戊二醯化的麩醯胺酸分解；在卵巢癌中透過 Nrf2/HO-1 促進 cisplatin 抗藥性。
- **抑制/依脈絡面：** 在胰腺癌中，高表現與*有利*預後相關 — 缺失促進 GOT1 乙醯化 → 透過麩醯胺酸/麩胱甘肽代謝增殖；在 HCC 中為*雙重* — 抑制免疫逃脫/膽酸代謝驅動的 HCC，但透過 OXPHOS→糖解重編程促進生長/轉移。
- **註：** SIRT5 幾乎無典型的去乙醯酶活性（它是去琥珀醯酶/去丙二醯酶/去麩醯胺醯酶），且對菸鹼醯胺抑制具抗性 — 因此在 SIRT1–3 可能被抑制的腫瘤微環境中仍保持活性。

## SIRT6 — 最一致具保護性，僅在肺/HCC 中為雙重

最明確的抗癌 sirtuin（抗 Warburg、促 DDR、抑制 survivin、HIF-1α、c-MYC），但有兩個依脈絡而定的例外：

- **肺癌（雙重）：** 透過 CHD4 協調 → 染色質鬆弛/DNA 修復與糖解抑制 → 放射增敏；但透過 snail 依賴的 KLF4 轉錄抑制 → EMT/轉移而促癌。
- **HCC：** 去乙醯化 hnRNP A1 → 抑制糖解/生長，且 USP48 穩定的 SIRT6 減弱代謝重編程（抑制性），然而耗竭下調多重抗藥性蛋白 1 → 增強化療敏感性（因此高 SIRT6 亦與化療抗藥性相關）。
- **化療抗藥性致癌基因：** 如此有效地抑制凋亡（survivin/HIF-1α），使其在乳腺/前列腺癌中賦予化療抗藥性 — 同樣的 DDR/節儉程序在預防起始後，後來在治療期間讓已確立的腫瘤存活。

## SIRT7 — 具階段依賴性轉移效應的增殖性生物合成驅動因子

- **促進面（多數癌症）：** 活化 RNA Pol I → 核糖體生物發生 → 生長；去乙醯化 p21/CDKN1A 啟動子 H3K18 → 細胞週期進展；在乳腺、甲狀腺、HCC 中過度表現；透過 E-cadherin 抑制（EMT）促進 CRC 侵襲；在 HCC 中抑制 p53。
- **抑制面：** 可能透過 EMT 相關基因啟動子上的 H3K18 去乙醯化抑制轉移 — 同一個 H3K18 標記既提升 p21（促增殖）又靜默 EMT 基因（抗轉移），顯示單一酵素的符號如何隨啟動子脈絡翻轉。
- **生物標記註：** 表現隨白血病治療反應陽性而上升，復發時下降 — 監測用途而非固定的致癌角色。

## 跨領域模式

1. **ROS 與 DNA 修復是斷層線。** SIRT3/SIRT6 保護免於氧化損傷並修復 DNA — 這*預防腫瘤起始*，但在已確立的疾病中*介導治療抗藥性*（SIRT3 放射抗藥性、SIRT6 化療抗藥性）。
2. **具相反符號的受質共享。** SIRT1/SIRT3 皆去乙醯化 p53 — SIRT1 的 p53 抑制為促腫瘤性，SIRT3 在某些模型中為有文獻記載的「致癌基因」路徑；SIRT2 去乙醯化 Slug（致癌）但經由完全不同的複合體去乙醯化 BRCA1（抑制）。
3. **區室很重要。** 線粒體三聯體（SIRT3/4/5）掌管代謝狀態，而核 SIRT1/6/7 掌管相同代謝程序（糖解、麩醯胺酸分解、脂肪生成）的轉錄 — 因此細胞層級的「SIRT 輸出」是代謝設定值（線粒體）與轉錄閘門（核）的整合。
4. **劑量與階段主導。** CRC SIRT1、心臟 SIRT1 與 SIRT7 的 H3K18ac 展現相同原則：低/中度活性具保護性，高/慢性活化翻轉為病理；早期缺失有利於起始，而晚期缺失使腫瘤對治療增敏。

## 重點摘述（第二部分）

多效性並非隨機 — 它是 NAD+ 可用性、亞細胞區室、標的部位選擇性與腫瘤演化階段的產物，這就是為何沒有 sirtuin 能被描述為純粹「促」或「抗」癌。

## 關於表格的註記

- **階段圖例：** *臨床前* = 僅細胞/動物研究或研究工具；*第一/二期* = 已進行的人體試驗（sirtuin 專一藥物大體已完成，無關鍵性推進）；*臨床試驗（進行中）* = 正積極招募以進行 NAD⁺ 前驅物策略；*已核准* = 以非 sirtuin 適應症上市。
- **選擇性注意：** 早期抑制劑（sirtinol、cambinol、tenovins、suramin）為雙重/多亞型；真正亞型選擇性的異位劑（EX-527→SIRT1、AGK2/SirReal2→SIRT2、MDL-800/801 & UBCS039→SIRT6）為近期且屬臨床前。
- **唯有 SIRT1 導向藥物已進入人體試驗**（STAC SRT2104/SRT501；抑制劑 EX-527）。所有 SIRT2/3/4/5/6/7 專一化學物仍屬臨床前。最先進的*臨床*槓桿是間接 NAD⁺ 提升（NMN/NR、CD38 抑制）。
- **依脈絡而定主導用途：** 當該亞型為腫瘤抑制性（HCC 中的 SIRT6、SIRT3 守護者角色）時致活劑有助，但當該亞型為致癌性（胃癌/子宮內膜癌中的 SIRT1、SIRT3 放射抗藥性、SIRT6 化療抗藥性）時可能有害；抑制劑面臨鏡像風險。

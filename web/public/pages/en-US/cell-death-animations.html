What each cell death looks like, live

Eight looping 3-D cells, one per program from the comparison table. Membrane = outer sphere · inner sphere = nucleus/DNA · capsules = mitochondria · dots = molecules (PAR, AIF, Ca²⁺, ROS/iron, cytokines, DAMPs). Lytic programs end in rupture; apoptosis ends in neat parcels; autophagy mostly survives.

12 s loop · phase label top-left · scroll for all 8

How to read them. Swelling + sudden burst with debris cloud = lytic (necrosis, necroptosis, pyroptosis, PANoptosis, late ferroptosis). Shrinkage + surface blebs pinching off into separate balls = apoptosis. PAR signal → AIF marching nucleus-ward with no swelling = parthanatos. Peroxidation patches + shrinking condensed mitochondria = ferroptosis. Crescent moons closing around cargo and fusing with a lysosome = autophagy. Built with three.js r160 (CDN importmap); vertex-displaced membranes, instanced particles, no post-processing. Respects prefers-reduced-motion (starts paused).

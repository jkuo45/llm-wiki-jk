酵素 · Caspase · 激酶 · Sirtuin

Caspase、激酶與 Sirtuin

這三大酵素超家族以不同的反應化學、時間尺度與次細胞位置調控細胞死亡。本頁描繪其直接交互作用，從蛋白質修飾、胞器功能、細胞命運決定，一路到組織層級的後果。

干預狀態

一個網路，三種時間尺度

激酶以可逆磷酸化快速調整蛋白質狀態；Sirtuin 將蛋白質去醯化與 NAD+ 可用性及次細胞脈絡耦合；Caspase 切割底物，並可形成較穩定的死亡承諾。三維視圖將共享調控因子置於同一網路；選擇細胞區隔可將同一批節點重新配置到細胞核、細胞質、粒線體、細胞膜與炎質體位置。

細胞死亡的分層調控

交互作用層級 · 急性至慢速調控

激酶提供快速、可逆的控制；Sirtuin 提供 NAD⁺ 耦合的控制；Caspase 執行蛋白水解變化。其共享節點整合受體訊號、DNA 損傷、代謝、粒線體完整性與轉錄。

反應化學

不同的底物、燃料與可逆性

三大家族都會改變既有蛋白質，但化學操作與啟動邏輯不同。磷酸化與去醯化各有對應的反向酵素；Caspase 的蛋白水解改變共價結構，無法僅還原一個翻譯後修飾就逆轉。

激酶

ATP 依賴性磷轉移 · 快速 · 可逆

激酶將 ATP 的末端 γ-磷酸轉移到受體羥基，最常見於絲胺酸、蘇胺酸或酪胺酸。磷酸酶可逆轉此反應。

  • 定位與支架結合決定哪些底物可及。
  • 磷酸化可改變催化狀態、定位、結合或降解速率。
  • 激酶輸出取決於脈絡；Akt 在某處境支持存活，在另一處境則參與壓力訊號。
protein–OH+ ATP →
protein–O–PO32−+ ADP
反向反應
蛋白質磷酸酶移除磷酸基。
典型時間尺度
訊號傳導為數秒至數分鐘；各蛋白質的停留時間不一。
細胞死亡範例
Akt–Caspase-9、Src–Caspase-8、PAK2–Caspase-7、CDK1–Caspase-2。

Sirtuin

NAD⁺ 依賴性去醯化 · 代謝耦合 · 原則上可逆

Sirtuin 將醯基從離胺酸連結的底物轉移到 NAD⁺，產生菸鹼醯胺與 2′-O-醯基-ADP-核糖。醯基轉移酶可重新加上部分標記。

  • NAD⁺ 可用性、菸鹼醯胺回饋、定位與翻譯後修飾共同調節活性。
  • SIRT1/6/7 主要位於細胞核；SIRT2 廣布於細胞質；SIRT3/4/5 主要位於粒線體。
  • 去醯化可改變轉錄因子活性、蛋白質交互作用、定位或代謝酵素功能。
protein–NHCO–R+ NAD⁺ →
protein–NH₂+ NAM + OAADPR
反向反應
組蛋白／蛋白質乙醯轉移酶及其他醯基轉移酶可還原部分標記。
主要輸入
NAD⁺ 將 Sirtuin 反應速率與細胞代謝狀態相連。
細胞死亡範例
SIRT1–p53/FOXO、SIRT5–細胞色素 c、SIRT3–NLRP3／粒線體制約。

Caspase

Asp 後半胱胺酸蛋白水解 · 放大 · 難以逆轉

Caspase 水解特定天門冬胺酸殘基 C 端的肽鍵。啟動型在鄰近平台上活化；執行型切割結構、細胞核與修復相關蛋白質。

  • DISC、凋亡體、炎質體等組裝體控制鄰近性與催化資格。
  • 有限切割可切換調控因子；廣泛切割可拆解細胞底物。
  • Caspase-1 另可成熟 IL-1β／IL-18 並切割 gasdermin；發炎型 Caspase 可在明顯裂解前就釋放細胞激素。
protein–Asp↓X–peptide+ H₂O →
fragment A + fragment B+ 2 H⁺
反向反應
蛋白水解產物須被降解或重新聚合；磷酸酶無法還原原始肽鍵。
啟動控制
鄰近性、抑制因子結合、平台組裝，以及啟動型–執行型回饋。
細胞死亡範例
Caspase-3/7 效應；Caspase-1 發炎底物加工；切割 SIRT1 或 PKCδ 可改變回饋。

調控結構

匯聚於共享控制節點

三大家族在受體訊號、轉錄、粒線體完整性、炎質體組裝與抑制因子穩定性交會之處匯聚。綠色實線表示活化或許可；紅色虛線表示抑制；琥珀色點線表示切割。最具資訊量的研究靶點往往是這些共享節點，因為一次擾動可同時改變不只一層控制。

細胞命運情景

當一層控制失效時，什麼改變了？

同一套酵素家族支撐發育期細胞清除、壓力適應、免疫調節與腫瘤持存。結果取決於哪些調控輸入占優勢。選擇一個情景以更新三維模型與機轉摘要。

激酶層 數秒 → 數分鐘

Akt、Src 與檢查點激酶施加快速抑制或改變支架使用。磷酸酶允許重置與重複訊號傳導。

Sirtuin 層 數分鐘 → 數小時

充足的 NAD⁺ 支撐 SIRT1/SIRT3/SIRT5 對轉錄、粒線體與炎質體組裝的制約，並受定位與底物脈絡影響。

Caspase 層 數分鐘 → 不可逆

啟動型與執行型活性仍低於廣泛底物切割所需之程度；發炎型 Caspase 亦相應受限。

組織情境

組織後果源自不同的易損細胞

研究設計

分開測量狀態、反應、位置與後果

有說服力的實驗要區分酵素豐度與催化活性、修飾狀態與總蛋白、細胞結果與通路標籤。擾動一層、至少測量兩個空間層級，並納入一個正交的活性或發炎終點。

核心測量面板

  1. 定義啟動輸入：死亡受體、DNA 損傷、內質網壓力、病原訊號、代謝壓力或處理。
  2. 測量激酶狀態：在已驗證處使用位點特異磷酸抗體，並搭配總蛋白與磷酸酶敏感讀值。
  3. 測量 Sirtuin 功能：NAD⁺/NADH、位點特異乙醯化、次細胞定位，以及催化測定或靶點特異救援。
  4. 測量 Caspase 加工：全長與切割型啟動／執行 Caspase、活性報告基因、直接底物切割與抑制因子救援。
  5. 解析位置：以影像或分級分離定位膜 DISC、凋亡體、粒線體、細胞核與炎質體組裝。
  6. 測量結果：克隆形成存活、細胞膜完整性、凋亡標記、細胞激素釋放、發炎孔洞形成與吞噬細胞清除。

擾動邏輯

  1. 激酶抑制或突變：檢驗快速磷酸化變化是否先於 Caspase 活性。
  2. 磷酸酶活化：檢驗可逆性，以及反應是否需要激酶本身而非下游蛋白豐度。
  3. SIRT1/3/5 基因操作：區分催化功能與支架效應，並控制定位。
  4. NAD+ 導向擾動：區分 Sirtuin 依賴效應與 PARP、CD38 等其他耗用 NAD+ 的過程。
  5. 選擇性與廣譜 Caspase 阻斷：區分啟動訊號、執行型凋亡與發炎細胞激素加工。
  6. 組合條件：檢測共享節點（p53、FOXO、XIAP、Bax、NLRP3），而不只是三個酵素家族的名字。

詮釋界線。「抑制 Sirtuin 對癌症具治療性」與「活化 Sirtuin 對老化具保護性」都不是普適陳述。效應取決於同工酶、定位、底物、NAD+ 可用性、疾病狀態、劑量、時間與細胞型別。同樣的推理適用於常用語「Caspase 活化」。請確認特定 Caspase、活性位點、底物、區隔與表現型終點。

知識圖譜追蹤日誌 · 腎上腺素紅

[推測性] 腎上腺素紅方案的網絡分析：作用劑與腎上腺素紅節點的耦合，相對於粒線體激效、自噬與 Sirtuins

此推測性方案將亞甲藍（繞過複合物 I/III 的電子分流）與氨基胍（二羰基／AGE 捕獲）結合作為推測性的氧化還原中繼模型。在活體中產生受控的腎上腺素紅氧化還原脈衝尚屬未驗證——文獻中唯一的直接化學依據為體外止血製造製程（US4501923A）。粒線體激效、自噬與Sirtuins 的參與為假說，未於人體驗證，且未量化。本頁報告各方案作用劑至腎上腺素紅節點的儲存邊路徑，資料取自 llm-wiki-jk 知識圖譜。本頁不是臨床建議——請見 §01 的安全說明。

01 · 目標與範圍

腎上腺素紅的氧化損傷與低劑量毒物興奮效應兩種解釋

知識庫對腎上腺素紅有兩種解釋。氧化損傷解釋將其描述為氧化還原循環的兒茶酚胺氧化產物，可產生 ROS 並消耗穀胱甘肽；心肌細胞與多巴胺能神經元的鐵死亡為假說，未於人體驗證。方案解釋將腎上腺素紅視為低劑量氧化還原壓力源，其 ROS 輸出被提出可影響粒線體激效、自噬與Sirtuins；此劑量依賴性參與為假說，未量化且未於人體驗證。兩種解釋對應圖譜建構中同一個腎上腺素紅節點。

先前的分析追蹤腎上腺素紅節點至三個適應性程式的儲存路徑。本分析涵蓋方案所列作用劑：亞甲藍（MB，繞過複合物 I/III 的電子分流）、氨基胍（AG，二羰基／AGE 捕獲），以及綱要文件在粒線體激效氧化還原中繼（MRR）、糖氧化蛋白質恆態（GOPS）與 SASP 重塑氨基色素（SRAC）機轉下提出的搭配作用劑（卡巴佐酮、維他命 C、尿石素 A、亞精胺、雷帕黴素、非瑟酮、肌酸、白藜蘆醇）。上述機轉均為假說，未於人體驗證。各作用劑已針對建構 273eba0b1872c83844c9cf5dcabbde8c94c16060 完成追蹤。

主要目標

將各方案作用劑與腎上腺素紅節點的連結分類為直接化學邊（反應、衍生、還原）或共享氧化還原／損傷橋接邊，並報告其 Fiedler 座標與相對於適應性程式的 PPR 耦合。

次要目標：(a) 比較核心作用劑（MB、AG）與適應性程式的 PPR 耦合；(b) 辨識耦合模式（直接邊與共享橋接）；(c) 比較方案追蹤與四節點基準的重現、延伸或矛盾。

毒物興奮效應假說的劑量依賴性

知識圖譜儲存邊關係，不包含劑量反應資料。將腎上腺素紅歸類為低劑量毒物興奮作用劑屬於低劑量假說：其 ROS／親電子化學被提出會參與適應性訊號傳導，而非使其飽和。此圖譜未量化劑量。本頁的網絡分析不依賴劑量；毒物興奮效應主張未於人體驗證，需依原始文獻評估（參見§10）。

安全性——為何本頁不是方案

  • 亞甲藍：FDA 黑框警語——強效可逆 MAO-A 抑制劑；血清素作用藥物（SSRI/SNRI/MAOI/哌替啶）必須先停用（≥2 週，氟西汀 5 週），待 MB 停用 ≥24 小時後再恢復。G6PD 缺乏症禁用（溶血、海因茲小體）。劑量 >7 mg/kg 出現不良反應；0.5–4 mg「保健」劑量範圍為社群慣例，非核准適應症（標示：高鐵血紅素血症，1 mg/kg 靜脈注射）。
  • 氨基胍（pimagedine）：糖尿病腎病變 ACTION I/II 第三期試驗未達成主要試驗終點，計畫因安全性終止（腎小球腎炎、吡哆醇／B6 耗竭、ANCA 相關血管炎、二胺氧化酶抑制／組織胺不耐）。從未獲准上市。
  • 腎上腺素紅／AMM／卡巴佐酮：無人體安全性、藥動學或劑量資料。卡巴佐酮為氧化還原靜默的止血性縮氨脲，非毒物興奮效應觸發劑；AMM 為腙封固的衍生物——二者皆不會如腎上腺素紅般自由循環。維他命 C＋腎上腺素紅在體外為促氧化還原循環，非乾淨解毒劑。
  • 本修訂版標示的證據缺口：腎上腺素紅 → NF-κB 抑制／SASP 抑制（SRAC）尚無衰老前臨床資料；腎上腺素紅芳基化 GPX4 為未驗證假說（兒茶酚胺誘發鐵死亡本身已有證據支持）。

03 · 耦合階梯

本建構上的 PPR 階梯：一個核心作用劑居首，其餘居中

以腎上腺素紅為種子進行個人化 PageRank，排序追蹤節點於同一階梯。僅氨基胍 #4（0.00686）在本建構居前十五；其餘直接邊作用劑依次為卡巴佐酮 #22（0.00409）與維他命 C #29（0.00341）、亞甲藍 #35（0.00307），接著是適應性程式粒線體激效 #36／自噬 #38／Sirtuins #232。種子反轉時，腎上腺素紅自氨基胍起排名#3、自亞甲藍起排名#16；自適應性程式起排名#13／#50／#86。先前建構「四個核心作用劑居前十五」的主張無法重現——AG 的直接邊仍是單一最強耦合。

直接反應作用劑與調節作用劑的名次分離

直接反應作用劑（AG、卡巴佐酮、維他命 C）排名 #4–#29，系統性調節作用劑居 #146–#272。直接反應作用劑經儲存邊與腎上腺素紅節點共享漫步質量；調節劑經中介程式與橋接抵達。PPR 階梯因此按儲存邊連結排序作用劑，而非依綱要文件的提案順序。

MB ⇄ AG 共享兩個鄰居：單胺氧化酶與一氧化氮合成酶（Jaccard 0.022）

MB 與 AG 各帶一條 MAO 抑制邊（0.92／0.9）與一條 NOS 家族邊（MB 抑制 sGC/NOS；AG 阻擋 NO 生成並抑制 iNOS 而不降低 eNOS）。兩核心作用劑之間無已儲存化學邊；二者皆連結至共享中介。圖結構與雙作用劑方案一致，而非單一反應級聯；生物學解釋為假說，未於人體驗證。

化學組合：卡巴佐酮與維他命 C

兩條直接邊將化學組連結至腎上腺素紅：Carbazochrome --is_an_intermediate_for(0.9)--> Adrenochrome（另加 is_derivative_of 0.95）與 Vitamin C --reduces(0.75)--> Adrenochrome（維他命 C 另帶 prevents_oxidation_of(0.85)）。二者位於與其餘所有追蹤節點相同的 Fiedler 側（卡巴佐酮 +0.0006，維他命 C +0.0003，§07）——本建構無化學／程式符號分界。其兩兩Jaccard（卡巴佐酮，維他命 C）= 0.045。

二者耦合深度不同：維他命 C PPR #29，有效電阻 0.088（z −1.27）；卡巴佐酮 PPR #22，有效電阻 0.338（z −0.77），為直接邊節點中最大有效電阻。卡巴佐酮居腎上腺素紅社群（k-core 3，度 8）。直接儲存邊存在；卡巴佐酮依化學為氧化還原靜默（縮氨脲封固的鄰醌），故其邊反映衍生關係，而非氧化還原活性。

追蹤集合中的三種耦合模式

  • 化學反應（AG reacts_with）——直接儲存邊，無橋接，PPR #4。
  • 衍生／還原（卡巴佐酮 is_an_intermediate_for、維他命 C reduces）——衍生物／還原劑節點上的直接儲存邊。
  • 經共享橋接的功能調節（MB 與調節作用劑）——無直接邊；與腎上腺素紅共享複合物 I／氧化壓力／ROS 橋接。

Arm B (autophagic clearance):    Autophagy --associated_with(0.95)--> Neuromelanin --sequesters(0.80)--> Adrenochrome   (1 of 5 shortest paths)
Arm C (sirtuin/NRF2):            Sirtuins --is_co_activated_by(0.80)-- NRF2 --(Adrenochrome activates NRF2, 0.80)-- Adrenochrome   (sole shortest path, undirected)

先前建構「每臂恰好一座速率限制橋接」的解讀無法重現。本建構上 A、B 兩臂各有多條等長最短路徑，故無單一橋接按跳數為速率限制。C 臂已不再經 SASP/NF-κB：先前建構記錄的 Adrenochrome —inhibits→ NF-κB 0.6 三元組於現行圖譜中缺席（adrenochrome 與 nf_kappab 雙向無邊），因此針對舊建構計算的衰老型態方向審計敘事與橋接擾動掃描一併退役。Sirtuins 現僅經 NRF2 抵達腎上腺素紅。Sirtuins —suppress(0.85)→ SASP 邊仍存在，但不在最短路徑上。掃描已排入重算佇列（§09），舊數字刪除不再沿用。

圖譜改變了什麼，以及對舊敘事的影響

NF-κB 實體碎片化在本建構已基本解決（NF-κB 為單一度 140 樞紐；僅剩 NF-kB signaling 度 2 為近重複），故先前「≥7 個變體分攤漫步質量」的保留不再適用於 C 臂。衰老型態假說（腎上腺素紅抑制 NF-κB → 抑制 SASP）尚無衰老前臨床資料，且本建構無已儲存三元組——僅作為標示假說保留，非計算結果。

07 · 社群邊界

本建構上的 Fiedler 座標：無化學／程式分界

λ₂（代數連結度）= 0.0994。本建構所有 14 個追蹤節點於 Fiedler 軸的同側聚為小正值（腎上腺素紅 +0.0005；範圍自 +0.0003 氨基胍／維他命 C／尿石素 A 至 +0.0008 自噬）。先前建構化學組與程式層之間的正負社群邊界無法重現——且因 Fiedler 符號具特徵向量任意性，僅其量級與 λ₂ 有意義。此處採用的解讀因此為否定：本建構不支持以符號分層。圖 7 以真實值繪製座標於壓縮軸上，使聚集可見，而非以分界暗示。

重跑後的 H2/H8 狀態

先前的 H2/H8（「腎上腺素紅及其化學家族與程式層相反，Fiedler 符號為負」）作為結果已退役，僅作為未來建構的可證偽假說保留（§08）：重跑若呈現一致的符號分界即復活之；本建構證偽之。周邊低度節點（卡巴佐酮 度 8、維他命 C 度 21）無論符號於重建下皆為最不穩定的 Fiedler 成員。

08 · 假說

重跑後的假說 H1–H8（未於人體驗證）

H1–H5 沿用自四節點研究；H6–H8 為方案特有。所有假說皆為針對建構 273eba0b1872c83844c9cf5dcabbde8c94c16060 計算的圖結構假說；由此衍生的生物學預測未於人體驗證。本次重跑三條假說改變狀態（H1 縮小，H2/H8 作為結果退役）。「證偽」欄列出將推翻各假說的再分析。

#假說圖譜依據將推翻它的再分析
H1各適應性程式經由少量等長最短路徑（橋接家族互異：MH 6、Auto 5、Sirt 經 NRF2 1）連結腎上腺素紅節點。最短路徑 multiplicity 6/5/1；ROS 與黑質素臂在列；Sirtuins 僅經 NRF2。Sirtuins 獲得第二條最短路徑，或 ROS／黑質素退出 MH/Auto 最短集。
H2作為結果已退役：化學／程式 Fiedler 符號分界。作為假說保留：未來建構可能呈現腎上腺素紅化學家族與程式層之間一致的符號分界。本建構證偽之：14 個追蹤節點皆為 +0.0003…+0.0008（λ₂ 0.0994）。任何呈現符號一致分界的未來建構即復活其作為結果的地位。
H3方案核心與程式之間的漫步耦合以 AG 為首，MH ≈ Auto ≫ Sirtuins。PPR 前向 #4（AG）／#35（MB）／#36（MH）／#38（Auto）／#232（Sirt）；反向腎上腺素紅 #3（AG）／#13（MH）／#50（Auto）／#86（Sirt）。加權再分析下 Sirtuins 排名高於 MH/Auto。
H4四重組的群集與 k-core 不同：自噬與粒線體激效居 k-core 8；腎上腺素紅 k-core 7，群集 0.019。群集／k-core 對照（§05 表）。四重組群集／k-core 分布相似。
H5四節點皆具高於度保持空模型的介數（待本建構重跑）。先前建構空模型已退役；排入佇列（§09）。任一節點的介數於其度保持空模型的 ~2σ 內。
H6外源作用劑的 PPR 名次雙向最小為 AG（#4／#3）；MB 居中（#35／#16）。PPR 階梯（§03）；AG 直接邊對 MB 橋接耦合。去重節點加權 PPR 下 AG 跌出前 20。
H7耦合模式依儲存邊類型而異：反應／衍生／還原作用劑用直接邊（AG、卡巴佐酮、維他命 C）；調節劑用共享橋接（MB、其餘作用劑）。直接邊成員為 AG／卡巴佐酮／維他命 C；MB 有 Adamic–Adar 提議 1.976 但無已儲存邊。未來建構新增 MB–腎上腺素紅直接邊，或移除 AG 直接邊。
H8作為結果已退役（見 H2）。現行陳述「腎上腺素紅與其化學家族共享負 Fiedler 側」於本建構被證偽。所有追蹤節點共享一側 Fiedler（§07）。未來建構重現化學／程式符號分界。

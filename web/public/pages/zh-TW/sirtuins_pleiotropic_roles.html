SIRT 在腫瘤細胞代謝中的多效性角色與治療標靶

七種哺乳類 SIRT（SIRT1–SIRT7）是依賴 NAD+ 的醯基轉移酶，扮演著 區隔化、情境依賴的代謝恆定調節器。同一種酶究竟具有腫瘤抑制性 抑或致癌性，取決於次細胞位置、腫瘤類型、病程階段與 NAD+ 的可用度。 本頁將任務輸出綜述轉化為可互動的圖表，呈現 SIRT 相互對立的行為。

為何同一種酶既能抗癌又能助癌

多效性源自三個相互作用的來源。

1 · 區隔化

細胞核 [[SIRT1]]/6/7 調控代謝程式的轉錄。
細胞質 [[SIRT2]] 調節細胞骨架與細胞週期。
粒線體 [[SIRT3]]/4/5 設定代謝定點（TCA、麩醯胺酸、氧化還原）。 「SIRT 輸出」是粒線體定點與細胞核轉錄門控的整合。

2 · 催化廣效性

除去乙醯化外，還有：去丙二醯化、去琥珀醯化、去戊二醯化與 ADP-核醣基化。[[SIRT5]] 幾乎沒有典型的去乙醯酶活性（是去琥珀醯酶/去丙二醯酶/去戊二醯酶）， 並抵抗菸鹼醯胺抑制——在 SIRT1–3 受抑制的環境中仍保持活性。

3 · 情境依賴

同一受質、方向相反：SIRT1 與 SIRT3 都去乙醯化 [[p53]]，卻分別造成促腫瘤與抗腫瘤的後果； SIRT7 的 H3K18 去乙醯化既提升 p21（促增殖），也沉默 EMT 基因（抗轉移）。 沒有任何 SIRT 是純「促」或純「抗」癌的。

逐一檢視 SIRT — 雙重面貌

每個異構酶都兼具抑制者與致癌者兩副面貌。 兩者間的平衡取決於劑量、階段與基因背景。

[[SIRT1]]

典型的「雙刃劍」 細胞核
+ 細胞質

腫瘤抑制

  • 去乙醯化 [[p53]]、[[Ku70]]、p73、[[FOXO]] → 在急性壓力下偏向修復而非凋亡
  • hnRNP A1 去乙醯化 → 在 [[Hepatocellular Carcinoma|HCC]] 中抑制糖解/生長
  • AR（Lys630）去乙醯化 → 抑制前列腺生長
  • 抑制 [[NF-κB]] p65 與 HMGB1 → 在[[Ovarian Cancer|卵巢癌]]中具抗血管新生作用
  • [[PAK1]] K420 去乙醯化 → 阻礙[[Glioblastoma|膠質母細胞瘤]]

致癌 / 促腫瘤

  • 慢性情境下的 p53 去乙醯化削弱了腫瘤抑制煞車
  • 與 [[c-Myc]] 及 [[HIF-1α]] 合作
  • EMT/metadherin → 三陰性乳癌中的化學抗藥性
  • NSCLC 中順鉑抗藥性（VEGF-A）；他莫昔芬抗藥性（MRP2/FoxO1）
  • 經由 CDK2 去乙醯化導致 T-ALL → p27 降解
情境變數：劑量（[[Colorectal Cancer|CRC]]：異型合子剔除 → c-Myc/麩醯胺酸/增殖；同型合子剔除 → 凋亡）、腫瘤類型（在膠質瘤/HCC 中為抑制者；在胃/子宮內膜/白血病中為促進者）、嚴重度（心臟：7.5 倍保護性、12.5 倍病理性）。

[[SIRT2]]

上皮抑制者，基底樣/白血病促進者 細胞質

腫瘤抑制

  • [[BRCA1]]–BARD1 異源二聚化 → 同源重組（乳癌）
  • IDH1 去乙醯化 → 抑制 CRC 肝轉移
  • AKR1C1 + [[STAT3]] 抑制 → 抑制 NSCLC 遷移
  • 使卵巢癌對順鉑敏感化

致癌 / 促腫瘤

  • Slug 去乙醯化 → 穩定化 → 基底樣乳癌侵襲
  • 磷酸甘油酸變位酶 K100 → NADPH 流 → 肺腫瘤生長
  • 子宮內膜癌幹性 / MEK-ERK 訊號
  • LMO2 去乙醯化 → T-ALL 生長/移植
情境：常與具保護性的 SIRT1/3/6 軸對立的細胞質 SIRT。在神經退化性疾病（[[Alzheimer's Disease|AD]]、[[Parkinson's Disease|PD]]、[[Huntington's Disease|HD]]）中有害，在代謝/腎臟/關節疾病中具保護性。在白血病中則分歧：NAMPT/SIRT2 活化可降低 AML 增殖，但 SIRT2 抑制則抑制 T-ALL。

[[SIRT3]]

粒線體「守護者」，氧化表型雙刃 粒線體

腫瘤抑制（代謝性）

  • [[MnSOD]]/SOD2 + IDH2 活化 → 降低 ROS → 不穩定化 HIF-1α（抗瓦伯格效應）
  • 刺激丙酮酸脫氫酶 → 氧化性 TCA 流
  • Twist 下調 → 抑制卵巢癌轉移
  • GST-π1 下調 → 使 HCC 對索拉非尼/化療敏感化
  • 破壞乳癌中的 ERα–p53 交互作用

致癌（同一套生物學，方向翻轉）

  • ROS 抑制得過於徹底 → 放射/化學抗藥性（NSCLC 中的 ATM–Chk2）
  • 提升 CRC 中的藥物抗性（SOD2/PGC-1α）
  • p53 去乙醯化（致癌途徑）
  • ACC1 上調 → 脂肪生成 → 子宮頸癌侵襲
  • Ku70–Bax 穩定化 → 膠質瘤存活
核心矛盾：「低 ROS / 完整氧化磷酸化」的守護者表型防止癌症起始，但透過防止壓力誘發的死亡讓已確立的腫瘤存活。在 NAFLD 與[[Osteoarthritis|骨關節炎]]中確實雙重。在淋巴結陽性[[Breast Cancer|乳癌]]與 OSCC 中升高。

[[SIRT4]]

最一致地腫瘤抑制——但伴隨代謝成本 粒線體

腫瘤抑制（主導）

  • [[GDH]] 單 ADP-核醣基化 → 限制麩醯胺酸→α-KG 流 → 直接打擊麩醯胺酸依賴
  • 經由胺基酸刺激的胰島素分泌抑制 [[mTOR]]
  • p16/p21 上調 + CyclinB1/Cdc2/Cdc25c 抑制 → HCC 凋亡
  • 在 CRC 中恢復 E-cadherin
  • 透過抑制麩醯胺酸代謝負向調節 SIRT1

為何情境仍然重要

  • GDH 抑制 → 胺基酸刺激的胰島素分泌減少
  • 抑制肝臟脂肪酸氧化（MTPα）→ 脂質堆積
  • 唯一具有不良心臟作用的 SIRT（加劇血管緊張素 II 肥厚/纖維化）
  • 代謝上「節儉」——抗腫瘤但代價高昂
其缺失一致地預示較差的存活率，見於 HCC、[[Gastric Cancer|胃癌]]、CRC、膀胱癌、乳癌。治療角度：作為麩醯胺酸依賴煞車予以保留/誘導。

[[SIRT5]]

具促腫瘤代謝偏向的去醯酶 粒線體

腫瘤抑制 / 情境性

  • 胰臟癌：高表現 → 預後良好（缺失 → GOT1 乙醯化 → 增殖）
  • HCC：抑制免疫逃逸 / 由膽汁酸代謝驅動的 HCC
  • SOD1/IDH2 去琥珀醯化 → 抗氧化防禦

促腫瘤代謝重程式化

  • 在 HCC、CRC、NSCLC 中過度表現 → 推動麩醯胺酸分解 + 糖解
  • LDHB 去琥珀醯化 → 過度活化的自噬 → 營養回收
  • CRC 中依賴去戊二醯化的麩醯胺酸分解
  • 卵巢癌中經由 [[Nrf2]]/HO-1 的順鉑抗藥性
  • HCC：經由氧化磷酸化→糖解的轉換促進生長/轉移
注意：幾乎沒有典型的去乙醯酶活性（去琥珀醯酶/去丙二醯酶/去戊二醯酶），且抵抗菸鹼醯胺抑制——在 SIRT1–3 受抑制的腫瘤微環境中仍保持活性。

[[SIRT6]]

最一致地具保護性——僅在肺癌/HCC 中雙重 細胞核（異染色質）

抗癌（主導）

  • 共抑制 HIF-1α → 抑制糖解酵素 → 抗瓦伯格效應
  • 抑制 [[Survivin|survivin]]、c-MYC、SREBP1/2、[[ChREBP]]（抗脂肪生成）
  • 協調 CHD4 → DNA 修復（DDR）
  • [[JAK2]]/STAT3 抑制 → HCC 生長抑制
  • hnRNP A1 去乙醯化 → HCC 中的抗糖解

雙重例外 + 化學抗藥性

  • 肺：依賴 snail 的 [[KLF4]] 轉錄抑制 → [[EMT]]/轉移
  • HCC：高 SIRT6 與化學抗藥性相關
  • 抑制凋亡（survivin/HIF-1α）過於有效 → 乳癌/前列腺癌中的化學抗藥性
  • 先前防止腫瘤起始的 DDR/節約程式，之後在治療中讓已確立的腫瘤存活
結論：最明確無疑的抗癌 SIRT（抗瓦伯格效應、促 DDR）。其具保護性的基因組穩定性程式在治療期間是一把雙刃劍。

[[SIRT7]]

促增殖的生合成驅動者 細胞核 → 核仁

抗轉移（情境性）

  • EMT 相關啟動子上的 H3K18 去乙醯化 → 抑制轉移
  • 同樣提升 p21（促增殖）的 H3K18 標記也沉默 EMT 基因——方向依啟動子情境而翻轉

促腫瘤（大多數癌症）

  • RNA 聚合酶 I 活化 → 核醣體生合成 → 生長能力
  • p21/CDKN1A 啟動子 H3K18 去乙醯化 → 細胞週期進展
  • 在乳癌、甲狀腺癌、HCC 中過度表現
  • 抑制 E-cadherin（EMT）→ CRC 侵襲
  • 在 HCC 中抑制 p53
生物標記備註：其表現隨[[Leukemia|白血病]]治療反應良好而上升，復發時下降——具有監測價值而非固定的致腫瘤角色。為尚未開發藥物的標靶。

階段圖例

臨床前 = 細胞/動物或研究工具 · 一期/二期 = 人體試驗（大致已完成，無關鍵性進展） · 臨床試驗（進行中） = NAD+ 前驅物策略 · 已核准 = 為非 SIRT 適應症上市。

選擇性注意事項

早期的抑制劑（sirtinol、cambinol、tenovins、suramin）均為雙/多異構酶。真正具異構酶選擇性的異位調控劑 （EX-527→SIRT1、AGK2/SirReal2→SIRT2、MDL-800/801 與 UBCS039→SIRT6）都是近期且處於臨床前階段。

情境決定用法

當該異構酶具腫瘤抑制性時（HCC 中的 SIRT6、作為守護者的 SIRT3），活化劑有幫助；但當其致癌時 （胃/子宮內膜癌中的 SIRT1、SIRT3 放射抗性、SIRT6 化學抗藥性）則有害；抑制劑則面臨相反的風險。

貫穿性規律與最終結論

活性氧與 DNA 修復是分界線。 SIRT3/SIRT6 保護免受氧化損傷並修復 DNA——這防止腫瘤起始，但造成已確立疾病的治療抗性 （SIRT3 放射抗性、SIRT6 化學抗藥性）。
共用受質但方向相反。 SIRT1/SIRT3 都會去乙醯化 [[p53]]——SIRT1 的抑制具促腫瘤性，在某些模型中 SIRT3 則被視為「致癌基因」途徑； SIRT2 經由完全不同的複合物去乙醯化 Slug（致癌），但去乙醯化 BRCA1（抑制）。
區隔至關重要。 粒線體三兄弟（SIRT3/4/5）主導代謝狀態，細胞核 SIRT1/6/7 主導同一套程式的轉錄—— 細胞的「SIRT 輸出」是粒線體定點與細胞核轉錄門控的整合。
劑量與病程階段主導一切。 CRC 的 SIRT1、心臟的 SIRT1 以及 SIRT7 的 H3K18ac 都展現相同原則：低/中度活性具保護性， 高/長期活化則轉為病理性；早期缺失有利於腫瘤起始，晚期缺失則對治療敏感化。
注意事項。每個 SIRT 都展現雙重/情境依賴的行為——無法單獨從單一 SIRT 解讀代謝表型。 多效性並非隨機：它是 NAD+ 可用度、次細胞區隔、 標靶位點選擇性與腫瘤演化階段的產物。這就是為何 NAD+ 耗竭正成為 MYC 高表現 / 麩醯胺酸依賴型癌症中的合成致死槓桿，也是為何 SIRT 調控必須具備情境意識。

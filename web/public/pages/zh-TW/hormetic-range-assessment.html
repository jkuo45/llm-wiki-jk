時間維度

持續時間、時機與兩個保護窗口

雙相曲線不僅是劑量的函數——它在時間上也是雙相的。 Calabrese 對預適應的系統分析（Pharmacol Res 2016，被引用 208+ 次） 記錄了任何毒興調節刺激後兩個時間上不同的保護窗口：

早期窗口
1–3 h

翻譯後修飾——現有蛋白質被修飾（受體適應、磷酸化）。快速啟動，快速衰退。

無保護間隙
~30 分鐘–24 h

在兩個窗口之間，生物體的保護可能低於基線——壓力源耐受性的假設在此失效。不要在此區域疊加第二個壓力源。

延遲窗口
12–72 h

基因誘導和從頭蛋白質合成（HSPs、抗氧化酶）。啟動較慢，持續數天至數週。適應性在此被儲存。

Calabrese 和 Mattson 的分解–合成循環毒興模型（CACH） （Ageing Res Rev 2024，被引用 32+ 次）將此正式化：健康來自重複 分解挑戰階段（壓力反應、資源保存）和合成恢復階段 （生長、可塑性、記憶鞏固）的循環。Mattson 2025 年 Nature Metabolism 的 「循環代謝切換」論文將相同的邏輯延伸到禁食——燃料之間的切換，而非赤字本身， 才是毒興訊號。下表編譯了每個領域的持續時間和頻率數據：

序列洞見：因為早期窗口是翻譯後修飾（快速、短暫）而延遲窗口是轉錄性的（緩慢、持久）， 同一壓力源過早重施會落在無保護間隙中，或在延遲程式寫入前將其鈍化。相反地， 不同的壓力源匯聚到相同感測器（如 cold + exercise 都作用於 AMPK）可以協同或干擾， 取決於間隔。時機是一個劑量維度——將其視為如此。劑量上限依然適用：最大毒興刺激落在基線以上 30–60%（Calabrese）——生物標記追蹤的 +60% 上限即源於此。

分子架構

核心感測器與下游效應器

每個毒物興奮領域都匯聚到一個共享的感測器–效應器架構。感測器偵測特定的壓力源訊號 （ROS、氧氣張力、營養缺乏、溫度變化、機械負荷、微生物模式、光、DNA 斷裂），並將其路由到重疊的轉錄程式。 所有領域的通用規則是訊號特異性、劑量窗口、可逆性/時機—— 而非僅僅是表現水平——決定了反應是保護性的還是致病性的。

AMPK

低能量 → PGC-1α → 粒線體生長；自噬經由 ULK1；TFEB → 溶酶體生長；抑制 mTORC1。禁食、運動、缺氧、metformin、異體毒興的匯聚節點。

NRF2

氧化/親電壓力 → ARE → 內源性抗氧化酶（SOD、catalase、GPx、HO-1、NQO1）；Trx/Srx 前饋迴路。由 sulforaphane、4-HNE、運動 ROS、LDR 活化。

HIF-1α

低 O₂ → EPO、VEGF、糖酵解酶；正向 ROS 反饋 → AMPK。間歇缺氧、運動、冷暴露的匯聚節點。短暫活化 = 適應性；慢性 = 致癌性。

SIRT1 / SIRT3

NAD⁺ 感應去乙醯酶。SIRT1 → FOXO → MnSOD/catalase/GSH；SIRT3 → MnSOD 乙醯化調節（K68）。毒興窗口：2.5–7.5× 保護性；12.5× 致病性（Alcendor 2007）。由禁食、運動、resveratrol 活化。

HSF1

蛋白質展開 → HSP70/HSP90 → 分子伴護蛋白質穩定網路。熱毒興（三溫暖、熱休克）的核心；也由運動、異體毒興（curcumin）和禁食活化。長壽的標誌之一。

FOXO

AMPK/SIRT1 的下游；MnSOD、catalase、GADD45、自噬基因、萎縮抗性的轉錄因子。連接營養壓力 → 壓力抗性基因程式的輸出臂。

ATM / p53

DNA 斷裂 → ATM → p53 → BRCA1/GADD45 修復、FOXO 抗氧化臂。低劑量輻射的感測器；短暫啟動 = 適應性，慢性高劑量 = 致突變性。

NF-κB / TLR / Treg 軸

損傷與微生物模式感應 → 急性 NF-κB 修復 vs. Treg 耐受（TGF-β、IL-25、SCFAs 經由 GPR41/43）。EIMD、老朋友、腸道微生物群的感測器。急性可恢復 = 修復；慢性 = 炎性老化。

UPR — ATF4 / XBP1

錯誤摺疊蛋白負荷 → HSF1/HSP 臂加上內質網臂（ATF4、XBP1）→ 伴護蛋白、ERAD、粒線體自噬。蛋白毒性/內質網毒興的感測器（熱 + 高強度組）；慢性睡眠剝奪會瓦解它。

OPN4 / CLOCK-BMAL1

黑視蛋白光感應 → 生理時鐘重置 → 粒線體/BDNF 節律性。光生物調節的感測器；晨光 = 校準，深夜強光 = 振幅扁平化。

Integrin / YAP-TAZ + 滲透壓感應 MAPK

機械負荷與滲透壓 → integrin/YAP-TAZ 重塑、MAPK 水通道蛋白程式。骨骼、重力/振動、滲透壓力的感測器。漸進負荷 = 重塑；突然超載或慢性不足 = 損傷。

mTORC1 / Adenosine-PKC-mitoK-ATP

營養/能量與缺血感應 → mTORC1 生長開關、adenosine/PKC 預處理級聯。禁食/化學毒興與缺血預處理的感測器；脈衝式抑制 = 自噬/預處理，慢性 = 萎縮/再灌流損傷。

實例——抗氧化酶的教訓：Trx1、MnSOD、catalase 和 peroxiredoxin 並非可互換的自由基海綿。區室（粒線體 vs. 胞質）、劑量窗口（SIRT3 乙醯化循環，而非固定的開/關）以及修飾的可逆性（經由 Srx 的亞磺酸修復 vs. 不可逆的硝化）決定了酶反應落在毒興窗口內還是退出到病理狀態。同樣的特異性–窗口–可逆性邏輯適用於上述每個感測器。這就是為何你如何進行毒興壓力與你是否進行同樣重要。

# POMC

**POMC**（**Pro-O**pio**M**elanocortin）是前體多肽，經蛋白酶切割（經由 PC1/3 與 PC2）為生物活性肽，包括促腎上腺皮質激素（ACTH）、alpha-黑素細胞刺激素（alpha-MSH）與 beta-內啡肽。

## 下視丘角色

- 弓狀[[Hypothalamus|下視丘]]POMC 神經元是能量穩態與攝食行為的中樞節點。
- 在飲食限制（熱量限制與禁食）期間，[[SIRT1]]表現在 POMC 神經元中誘導，SIRT1 在此調控攝食行為（Cakir et al., 2009; Ramadori et al., 2010; Satoh et al., 2010）。
- POMC 神經元中的 SIRT1 去乙醯酶活性為對抗飲食誘導肥胖的穩態防禦所需（Ramadori et al., 2010）。
- 腦特異性 SIRT1 剔除小鼠喪失熱量限制誘導的適應性身體活動增加，腦 SIRT1 過度表現則增強該反應（Cohen et al., 2009）。

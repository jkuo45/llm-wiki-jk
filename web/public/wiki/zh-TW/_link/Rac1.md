# Rac1

Rac1 是一個 21 kDa 的 Rho 家族小 GTPase，也是[[Rac GTPase]]亞家族中廣泛表現的原型。它最初被辨識為 *Clostridium botulinum* C3 外酵素的受質——「ras-related C3 botulinum toxin substrate」一名的由來——如今已是細胞中特性最明確的訊號開關之一。

## 結構與結構域

Rac1 具有[[Rac GTPase]]成員共享的典型 Ras 超家族架構：

- **G 結構域**（約殘基 1–166），含磷酸結合的 P 環（Gx4GKS/T）、Switch I、Switch II，以及異位（allosteric）的 N/TKXD 與 ExSAK 基序。鄰近 switch II 的**插入區**（β2–β3、α3/L7）是 Rho 家族 GTPase 的特徵，並塑造效應子選擇性。保守的 Gly12 與 Gln61（Rac1 編號）是在致癌等位基因中最常被突變的殘基。
- **高變區（HVR）**位於 C 端，包含帶有**多鹼性區**——同時攜帶核定位序列——能結合 SH3 結構域的**脯胺酸 rich 區段**，以及 **- **高變區（HVR）**位於 C 端，包含帶有**多鹼性區**——同時攜帶核定位序列——能結合 SH3 結構域的**脯胺酸 rich 區段**，以及 **CAAX 盒**。CAAX 半胱胺酸的香葉基香叶酰化（geranylgeranylation），接續內源蛋白酶切割與羧基甲基化，正是使 Rac1 成為膜蛋白的機制；缺乏這些修飾時 Rac1 位於細胞質／細胞核。

HVR 不只是定位標籤。它直接參與效應子結合——多鹼性區的突變會降低 PAK1 自體磷酸化，且 Rac1 的 C 端可結合 PIP5K、DGK、SmgGDS 與 Nedd4——而 C 端還可回摺到 switch II 上，因此核苷酸狀態與效應子親和力是耦合的。

## 機制

Rac1 是一個二元開關。在靜止狀態下，大部分 Rac1 結合 GDP 並由 RhoGDI 侷限於細胞質。活化分兩步驟發生：

1. 受體刺激（[[EGFR]]、[[PDGFR]]、[[Insulin Receptor|胰島素受體]]、整合素[[Integrin]]、GPCR）招募並活化 RacGEF——Tiam1、β-PIX、P-REX1、Vav、DOCK——催化 GDP 釋放。
2. 載入 GTP 的 Rac1 停靠效應子。在細胞後方，GDI 被置換，Rac1 得以抵達細胞膜。

終止則由 GAP 加速的水解加上 RhoGDI 的萃取完成。因此 Rac1 的活性在空間與時間上皆受限制，而 Rac1、RAC2 與 RAC3 之間的訊號專一性主要來自 HVR，以及 GEF 偏好與效應子停泊動態的差異。

**下游效應子：**

- **WAVE 調節複合體。** Rac1-GTP 結合 IRSp53，解除 WAVE2 的自體抑制；WAVE2 接著活化 Arp2/3，生成分枝狀肌動蛋白，以及遷移細胞前緣的偽足與膜皺褶。
- **PAK1**（以及 PAK2/3）經由 CRIB/GBD，將 Rac1 連結至 [[ERK]]/[[MAPK]] 與[[JNK]]。
- **NADPH 氧化酶。** 組裝 Nox 複合體需要 Rac1-GTP，因此 Rac1 位於吞噬細胞呼吸爆發與大量[[Reactive Oxygen Species|活性氧]]訊號的上游。
- **[[NF-κB]]。** Rac1 驅動的轉錄輸出與其細胞骨架角色無關。

## 生理角色

Rac1 為[[Cell Migration|細胞遷移]]（前緣突出由後方的[[RhoA]]制衡）、新生[[Focal Adhesion|黏著斑]]形成、[[Cell Adhesion|細胞黏附]]、巨噬細胞與[[Neutrophils|嗜中性球]]中的[[Phagocytosis|吞噬作用]]、嗜中性球趨化，以及上皮極性所必需。Rac1−/− 小鼠可存活，但在多種組織中[[Cell Migration|細胞遷移]]受損、[[Phagocytosis|吞噬作用]]缺陷，且[[Osteoclast|破骨細胞]]的骨吸收減少，因為破骨細胞分化需要 Rac1 依賴的[[NADPH Oxidase|NADPH 氧化酶]]衍生 ROS。Rac1 亦驅動一種不依賴生長因子的發炎程式（NF-κB、ROS），並在[[Angiogenesis|血管新生]]中必需。

## 疾病關聯

- **[[Melanoma|黑色素瘤]]。** switch I 中的 **P29S** 取代出現在 4–9% 的日曬黑色素瘤中。這是一種快速循環的等位基因：GTP 水解減少，且對 PAK1、MLK3 與 WAVE 調節複合體的結合增強，但對內在性交換的影響不像 RAC1B 剪接變異體那樣。構成性活化的突變體（G12V、Q61K）已在晚期生殖細胞腫瘤中被發現。
- **RAC1B 剪接變異體。** 第 3b 外顯子的替代性包含會在 switch II 的 C 端側插入 19 個胺基酸，產生一種快速循環、大多數時間結合 GTP 的蛋白質：它無法結合 RhoGDI、不誘導偽足，且向 PAK1 與 JNK 的訊號傳遞不佳。RAC1B 在[[Breast Cancer|乳癌]]、[[Colorectal Cancer|大腸直腸癌]]與[[Lung Cancer|肺癌]]中過量表現，且在[[TGF-beta Signaling Pathway|TGF-β]]反應中主要作為 RAC1 的拮抗劑。
- **其他腫瘤。** Rac1 的上調與[[KRAS]]及 BRAF 協同驅動增殖，Rac1 也出現在 TGF-β 驅動的[[EMT]]中。
- **神經退化。** Rac1 控制樹突的形成與成熟；[[Alzheimer's Disease|阿茲海默氏症]]腦中已報告 RAC1 剪接異常與 RAC1B 升高。

> [!warning] 治療現實檢查
> 沒有任何核准藥物直接標定 Rac1。臨床上的標定位於上游：RTK 與 MEK 抑制劑，以及 PAK 抑制劑（FRAX597、IPA-3）正處於臨床前開發階段。Rac1–GEF 交互作用抑制劑（NSC23766、EHop-016）是工具化合物，效價不足以用於臨床。

## Connections

- [[Rac GTPase]] — 家族註記：Rac1 是原型，而家族層級相對於 RAC2/RAC3/RHOG 的專一性來自高變區。
- [[RhoA]] — 在遷移中的功能拮抗者：Rac1 突出前緣，RhoA 收縮後方；兩者的平衡決定細胞形態與運動模式。
- [[PAK1]] — 主要的激酶效應子，將 Rac1-GTP 連接到 MAPK 訊號。
- [[Actin Cytoskeleton|肌動蛋白細胞骨架]] — Rac1 最知名的輸出是 Arp2/3 依賴的分枝狀肌動蛋白與偽足。
- [[mTORC2]] — mTORC2 缺失會減少 Rac1 的 GTP 載入，並擾亂肌動蛋白聚合與細胞形態。
- [[NADPH Oxidase|NADPH 氧化酶]] — 組裝氧化酶複合體需要 Rac1-GTP，因此 Rac1 位於吞噬細胞與破骨細胞中 ROS 產生的上游。
- [[KRAS]] — 在細胞轉化中經常與 Rac1 協同，且兩者透過共享的 GEF 傳遞訊號。

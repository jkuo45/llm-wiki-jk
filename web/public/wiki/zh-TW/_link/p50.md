# p50

> [!warning]
> **命名歧義——請先閱讀。** 「p50」一詞在文獻中至少用於兩個互不相關的實體。在 [[NF-κB]] 領域，p50 是成熟的 NF-κB1 次單元（本註）。另一方面，「p50」曾是大鼠小膠細胞／巨噬細胞上一種細胞表面蛋白的原始名稱，現稱 **TMEM119**，被廣泛用作為小膠細胞專一性標記。兩者在生物學上毫無關聯。本註討論的是 NF-κB p50。

**p50** 是 **NFKB1** 基因產物的 C 端半段（UniProt P19838）。主要的轉譯產物是 **p105**，一個 968 個殘基的蛋白質；對 C 端半段進行構成性的、依賴泛素–蛋白酶體的加工，會產生成熟的 **p50** 次單元（UniProt 異形體，約 361 個殘基）。另一個不同的異形體 **p52**，以相同方式自 *NFKB2* 基因產物 p100 產生。

> [!info]
> **關於 p50 唯一需要理解的重點。** p50 是經典 NF-κB 的*結構*半邊：它提供結合 DNA 上 κB 位點、並與 Rel 家族蛋白質二聚化的 Rel 同源結構域。但它**沒有反式活化結構域**。因此其自身的同源二聚體通常是 κB 位點轉錄的*抑制因子*。p50 是允許性的夥伴，而非效應器。

## 結構與結構域

| 特徵 | 殘基（近似值，p105 編號） | 功能 |
| --- | --- | --- |
| Rel 同源結構域（RHD） | 42–367 | 與 κB 位點結合 DNA；二聚化；結合 [[IκBα]] |
| 富含甘胺酸的區域 | 372–394 | 反式活化；為加工邊界——15-deoxy-Δ12,14-PGJ2 會修飾此處的一個半胱胺酸並阻斷 p105 切割 |
| N 端尾部 | 1–42 | 細胞核定位訊號區域 |
| 六個 ankyrin 重複 | 542–747 | **IκB 功能**——p105 的 C 端本身就是一種 IκB 蛋白質，可將 NF-κB 保留於細胞質中 |
| 死亡結構域 | 805–892 | 媒介 p105 誘導的凋亡；加工時被移除，因此成熟的 p50 無法殺傷細胞 |

> [!info]
> **p105 是一種 IκB 蛋白質。** 這一點常被低估。由於其 C 端半段由 ankyrin 重複所組成，p105 會像 [[IκBα]] 一樣結合並隔離細胞質中的 NF-κB 二聚體。因此同一基因同時供應抑制蛋白與活性次單元。這也使得 *NFKB1* 基因敲除的結果難以解讀：它同時移除了一種 IκB、一種抑制因子（p50 同源二聚體）**以及**一種活化因子（RelA–p50）。

## 作用機制

**組裝。** p50 可形成同源二聚體，或與 RelA（[[p65]]）、[[c-Rel]]、RelB 形成異源二聚體。**RelA–p50 異源二聚體是多數細胞型態中最豐富的 NF-κB 種類。**

**核內進入。** 與 IκBα 結合的二聚體位於細胞質且不活化。在經典途徑中，[[IKK complex|IKK]] 磷酸化 IκBα（人類 IκBα 的 Ser32/36），引發泛素化與[[Proteasome|蛋白酶體]]降解；釋出的二聚體轉位至細胞核。

**活性完全取決於夥伴。**

- RelA–p50 → 轉錄活化因子。
- p50–p50 → 通常為抑制性；會將含[[Histone Deacetylase|HDAC]]的複合體招募至 κB 位點。
- p50–p50 與 **Bcl-3** 結合 → 轉變為活化複合體。因此 Bcl-3 這個 IκB 家族蛋白並非純粹具有抑制作用。

**反式活化結構域。** 不同的 Rel 蛋白使用不同的 TAD。RelA 使用 TA1 與 TA2；其 TA3 沒有貢獻。p50 則使用其富含甘胺酸的區域進行反式活化，這也是為何 p50 無法在完全活化時取代 RelA。

**非經典途徑的連結。** *p105* 的 C 端（殘基 650–684）媒介依賴 NIK 的加工，該加工對非經典 NF-κB 活化有所貢獻；在 p100 的情況下，這半段稱為 IκBδ。

## 調節

- **構成性與訊號誘導的加工。** p50 由 p105 生成的過程在很大程度上是構成性的，這也是為何 p50 的蛋白質含量相對穩定，以及 NF-κB 活化很快——不需要新的轉錄。
- **可被佛波酯與 [[TNFα]] 誘導表現。**
- **Cys61 的 S-亞硝基化**影響 DNA 結合；15-deoxy-Δ12,14-prostaglandin J2 會共價修飾富含甘胺酸區域中的一個半胱胺酸並阻斷加工。
- RHD 中 **Ser337 的磷酸化**調節其活性。

## 臨床相關性

- **癌症。** 構成性的 NF-κB 活性是人類腫瘤中最常見的轉錄因子異常之一，驅動增殖、抗凋亡基因表現（TRAF1、TRAF2）以及對免疫清除的抗性。在多數此類情境中，RelA–p50 是占主導地位的複合體。
- **NFKB1 缺陷。** *NFKB1* 的雙等位基因功能喪失會造成第 12 型常見變異性免疫缺陷（CVID）並伴隨自體免疫——這與 p50 同時參與淋巴球活化與耐受的角色一致。
- **發炎。** p50–RelA 驅動促發炎胞激素程式（IL-6、TNF-α、趨化因子），此為慢性發炎疾病與 [[SASP|SASP]] 誘導的基礎。
- **抑制劑。** 如 MLN120B 等 IκB 激酶抑制劑，以及阻斷蛋白酶體的藥物，作用於 p50 釋放的上游；沒有任何臨床核准的藥物直接以 p50 為標的。
- **單倍不足的注意事項。** 在中樞神經系統中，於純化神經元培養物所做的細緻研究幾乎找不到 NF-κB 活性；許多報告的神經元 NF-κB 訊號似乎源自膠細胞。對神經元內源性 p50 的主張應抱持謹慎態度。

## Connections

- [[p65]] — 不可或缺的活化夥伴。沒有 RelA 的 p50 是抑制因子；沒有 p50 的 RelA 仍可活化，但 RelA–p50 異源二聚體是經典途徑中占主導地位的種類。
- [[NF-κB]] — p50 是五個哺乳類次單元之一；本註即該家族的 NFKB1/p50 半邊。
- [[IκBα]] — 與 p50 的 Rel 同源結構域結合並遮蔽其細胞核定位訊號；p105 的 ankyrin 重複做同樣的工作，使 p105 成為內建的第二種抑制蛋白。
- [[IKK complex]] — 磷酸化 IκBα 是釋放 p50 二聚體的步驟；[[IKKbeta]] 是經典途徑中的主要催化次單元。
- [[Proteasome]] — 在兩處皆為必需：降解 IκBα 以釋放 NF-κB，以及將 p105 加工為 p50。
- [[TNFα]] — 觸發 IκBα 磷酸化與 p50 二聚體核內累積的原型刺激因子。
- [[SIRT1]] — 在 Lys310 去乙醯化 p65/p50 複合體中的 p65 夥伴，無須移除 p50 本身即可關閉該異源二聚體。
- [[c-Rel]] — p50 的第二個 Rel 家族夥伴；RelA–p50 與 RelA–Rel 複合體是經典的轉錄活化因子。

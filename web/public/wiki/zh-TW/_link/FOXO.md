# FOXO

一族轉錄因子（Forkhead box O，叉頭框蛋白 O），負責調節與細胞週期、[[Apoptosis|細胞凋亡]]與[[Autophagy|自噬]]相關基因的表現。


FoxO（forkhead box O）家族是一群轉錄因子，負責調節與細胞生長、增殖、分化、凋亡與長壽相關基因的表現。在肌肉組織中，FoxO 因子透過上調 E3 泛素連接酶（如 Atrogin-1 與 MuRF1）的表現，在調節肌肉蛋白質分解中扮演主要角色；當其過度活化時會導致肌肉萎縮。

## 連結
- [[Apoptosis]] — 程式性細胞死亡；清除受損或過多的細胞
- [[Autophagy]] — 細胞自我分解途徑；清除受損的蛋白質與細胞器
- [[FoxO1]]：SIRT1 與 FOXO1 形成互相正向的回饋迴路。
- [[Autophagy]]：經 SIRT1 去乙醯化的 FOXO 促進自噬。

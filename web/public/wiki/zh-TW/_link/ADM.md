# ADM

**Adrenomedullin**（ADM）是一種具有血管擴張、內皮保護作用的胜肽，在[[Heart]]衰竭、敗血症與老化時升高。ADM 的 DNAm 替代指標是 GrimAge 時鐘的組成成分之一，與[[Cystatin C]]、B2M、GDF15 和 PAI-1 並列，將 ADM 濃度轉譯為加速老化的訊號。

- [[DNAmGrimAge]] — 將 ADM 替代指標納入並作為加速老化訊號的時鐘。

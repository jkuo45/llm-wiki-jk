# 蛋白酶

**蛋白酶**（推薦命名：**肽酶 peptidase**）是催化蛋白質或多肽受質中肽鍵水解的酵素。蛋白酶屬於第三類水解酶，EC 3.4 亞類（肽鍵水解酶），也是生物學中數量最多、功能最多樣的酵素群之一。本資料庫已個別收錄其中許多成員——[[Proteasome]]、[[Cathepsins]]、[[Caspases]]——本筆記即是它們所屬的類別層級容器。

## 分類

肽酶首先依切割位置分類：

- **內肽酶**（endoproteinase，EC 3.4.21–99）切斷內部肽鍵——例如[[Thrombin]]、各類 chymotrypsin、[[Matrix Metalloproteinases]]。
- **外肽酶**（exoproteinase）切斷末端鍵：**胺肽酶**作用於 N 端，**羧肽酶**作用於 C 端。

第二個分類依據是**催化型**，由活性部位的親核殘基定義——這是 MEROPS 肽酶資料庫與 IUBMB 酵素命名法所使用的分類系統：

| 類型 | 親核殘基／機制 | 資料庫中的代表例子 |
|---|---|---|
| 絲胺酸型（S） | Ser–His–Asp 電荷中繼 | [[Thrombin]]、[[Plasmin]]、[[Tissue Plasminogen Activator]]、[[Factor XIIIa]]、[[Neutrophil Elastase]] |
| 半胱胺酸型（C） | Cys–His 二元組，硫醇鹽親核殘基 | [[Cathepsin B]]、[[Cathepsin K]]、[[Calpain]]、[[Caspase-3]] 與 caspase 家族（MEROPS clan CD） |
| 天門冬胺酸型（A） | Asp–Asp 二元組，活化水分子 | 胃蛋白酶（pepsin）、HIV-1 蛋白酶 |
| 金屬型（M） | 金屬活化的水分子（通常為 Zn²⁺） | [[Matrix Metalloproteinases]]（M10）、ACE、[[Cathepsin L1]]、astacin |
| 蘇胺酸型（T） | Thr 親核殘基 | [[Proteasome]] 催化次單元（T1） |
| 麩胺酸型（G）、天門冬醯胺型（N） | 細菌裂解酶 | 在哺乳類中無對應 |

## 生理功能

> [!info] 蛋白水解並不只是分解代謝
> 受限且具位點專一性的切割是一種調節訊號：酶原活化、訊號胜肽加工、前蛋白成熟（例如[[Hepatocyte Growth Factor]]在[[MET]]途徑中由 HGF 活化蛋白酶切割活化），以及由絲胺酸蛋白酶級聯[[Complement System|補體]]系統所介導的補體活化。

- **蛋白質轉換與品質管制**——細胞質與溶酶體蛋白酶回收[[Proteins]]；其不足會導致[[Proteostasis]]失衡、[[Proteotoxicity]]與[[Proteinopathy|蛋白病變]]。
- **消化**——胃蛋白酶、胰蛋白酶與腸道肽酶。
- **凝血與纖維蛋白溶解**——[[Thrombin]]→[[Fibrinogen]]→[[Factor XIIIa]]交聯形成纖維蛋白，由[[Plasminogen]]／[[Plasmin]]制衡。
- **發炎與免疫**——[[Neutrophils]]釋放[[Neutrophil Elastase]]與[[Myeloperoxidase]]；蛋白酶活化受體（PAR）家族將蛋白酶切割轉換為 G 蛋白訊息傳遞。
- **調控性細胞死亡**——[[Caspases]]是執行[[Apoptosis]]的半胱胺酸蛋白酶；granzyme 是顆粒絲胺酸蛋白酶，執行細胞毒性淋巴球殺傷；[[Gasdermin D]]本身就是半胱胺酸蛋白酶的受質，其切割會觸發[[Pyroptosis]]；[[Caspase-1]]在[[NLRP3 Inflammasome|發炎小體]]內使 IL-1β 成熟。
- **微生物與病毒蛋白酶**——[[HIV-1]]蛋白酶（天門冬胺酸型）在病毒顆粒成熟期間切割 Gag 與 Gag-Pol 多聚蛋白，是蛋白酶抑制劑的標的；[[Helminth|蠕蟲]]與細菌蛋白酶則是毒力因子與治療標的。

## 治療關聯

蛋白酶抑制是醫學上最成功的藥物策略之一：ACE 抑制劑、直接凝血酶抑制劑、HIV 蛋白酶抑制劑、HCV 蛋白酶抑制劑、[[DPP4]]抑制劑與中性球彈性蛋白酶抑制劑皆可追溯至此類別。蛋白酶在腫瘤學中也是藥物*標的機會*（[[Angiogenesis]]與[[Metastasis]]中的[[Matrix Metalloproteinases]]），並且是[[Autophagy]]非依賴性溶酶體降解的主要蛋白水解成分。

## 連結

- [[Proteasome]] — 泛素—蛋白酶體系統的蘇胺酸型肽酶機器；為主導的細胞質蛋白酶，有別於溶酶體的 cathepsins。
- [[Cathepsins]] — 主要的溶酶體半胱胺酸與天門冬胺酸蛋白酶家族，執行大部分蛋白質轉換，也在腫瘤侵犯中於細胞外發揮作用。
- [[Caspases]] — 半胱胺酸肽酶（clan CD），同時身為凋亡的起始型與執行型蛋白酶。
- [[Thrombin]] — 凝血中典型的絲胺酸內肽酶；體現了同時具有保護性與病理性的蛋白酶生物學。
- [[HIV-1]] — 其天門冬胺酸型蛋白酶是病毒顆粒不可或缺的成熟酶，也是蛋白酶抑制劑療法的著力點。
- [[MET]] — 說明受調控的蛋白水解活化：此受體酪胺酸激酶需要其配體經蛋白酶加工才能傳遞訊息。
- [[Proteostasis]] — 依賴平衡的蛋白酶能力；蛋白水解過量會造成蛋白病變，過少則造成蛋白質聚集。

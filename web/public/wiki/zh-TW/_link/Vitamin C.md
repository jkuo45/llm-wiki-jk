# 維生素 C

**[[Vitamin C]]**（抗壞血酸，L-抗壞血酸）是一種水溶性維生素與必需營養素，具有強效抗氧化特性。它是抗氧化網絡中位於水相末端的還原劑——在膜介面將 [[Vitamin E]] 從自由基形式再生，並維持 [[Glutathione]] 庫的還原態——同時也是 [[Collagen]] 合成的專性輔因子。

## 結構與氧化還原化學

抗壞血酸是一個六碳內酯，帶有烯二醇基團（C2–C3 羥基）。該烯二醇在較低的還原電位下捐出一個或兩個電子（pH 7 時，抗壞血酸自由基／抗壞血酸鹽電對為 +0.06 V），使其成為強力但受動力學控制的還原劑。其單電子氧化產物——**抗壞血酸半醌自由基**——具有共振穩定性，反應性低到足以自行歧化而非傳播損傷——正是這項特性使抗壞血酸在大多數生物情境中扮演抗氧化劑，而非促氧化劑。

由於在生理 pH 下完全水溶且帶負電，維生素 C 分佈於水相與膜–水介面。它無法取代 [[Vitamin E]] 在脂質相中的斷鏈作用；而是與之串聯運作。

## 吸收、運送與代謝

腸道攝取依賴鈉離子且具飽和性，由 **SVCT1**（SLC23A1）介導。組織攝取則透過 **SVCT2**（SLC23A2），其在腎上腺髓質、垂體與神經元中高度表現——這些組織同樣會濃集兒茶酚胺。氧化型維生素 C（**[[Dehydroascorbate]]**）由 GLUT 轉運蛋白攝取，並在細胞內被還原，是一條重要的回收途徑。

人類缺乏 L-gulonolactone oxidase，無法從葡萄糖合成抗壞血酸，因此該維生素是飲食中的必需品。對應的基因在大多數哺乳類與鳥類中是完整的。

血漿濃度被嚴格調控在腎格調控在腎閾值附近；組織庫（腎上腺、垂體、腦、晶狀體）的濃度為血漿的 10–100 倍。吸菸者、糖尿病患者與重症患者的血漿抗壞血酸明顯偏低。

## 抗氧化網絡

- **回收 [[Vitamin E|α-tocopherol]]**：在膜介面將 α-tocopheroxyl 自由基再生——這是水相與脂質抗氧化庫之間的關鍵連結，也是這兩種維生素具協同作用而非可互相取代的原因。
- **直接清除 [[Superoxide Radicals|superoxide]]、[[Hydroxyl Radicals|hydroxyl radicals]]、[[Singlet Oxygen]] 與次氯酸**，其中對 •OH 的清除速率接近擴散極限。
- **再生 [[Glutathione]]**：經由脫氫抗壞血酸還原酶與 glutaredoxin 系統將 GSSG 還原，因此抗壞血酸狀態與 GSH 狀態相互耦聯。
- **節省其他單電子還原劑**，包括四氫生物蝶呤，使 [[Nitric Oxide Synthase]] 的解偶聯受到抑制，維持 NO 的生物可利用度。

> [!info] 來源：[[_document_ - berrougui2009_resveratrol_as_atheroprotective_compound|Berrougui et al., Atherosclerosis 2009]]
> 諸如維生素 C 這類的水溶性抗氧化劑無法進入脂質相直接捕捉過氧自由基；它們實際上是消耗於回收 α-tocopheroxyl 自由基。這種相位互補性正是為何食用油富含 [[Vitamin E]]，而周圍的水相區室則富含抗壞血酸。

## 輔因子功能

抗壞血酸維持鐵與銅處於多種酵素所需的還原態：

- **[[Collagen]] 合成中的脯胺醯與賴胺醯羥化酶**——這是壞血病的基礎：羥化不足的膠原蛋白無法交聯，導致結締組織碎裂。
- **Dopamine β-hydroxylase**——在兒茶酚胺囊泡中將多巴胺轉化為 [[Norepinephrine]]。
- **[[Carnitine]] 生物合成**（trimethyllysine 與 γ-butyrobetaine 羥化酶）——將維生素 C 狀態與脂肪酸送入粒線體的運送連結起來。
- **腎上腺皮質中的胜肽醯胺化與類固醇生成**，該部位持有全身最高濃度的抗壞血酸。

## 兒茶酚胺保護

抗壞血酸與兒茶酚胺共定位於分泌囊泡中，並在其中防止自動氧化。它可以透過將電子回捐給反應性的 [[o-quinone]] 中間體，「逆轉」[[Epinephrine]] 的氧化，將其轉回穩定的 epinephrine，並阻斷 [[Adrenochrome]] 及其下游 aminochrome 產物的形成。囊泡單胺轉運蛋白 2（VMAT2）會將抗壞血酸與兒茶酚胺一同裝載入同一顆顆粒，因此抗壞血酸的耗竭會使平衡偏向醌類形成與 [[Adrenochrome Hypothesis|adrenochrome-mediated damage]]。

## 雙重促氧化作用

在藥理學濃度下且有游離過渡金屬存在時，維生素 C 可透過 [[Fenton Reaction]]（Fe³⁺/Fe²⁺ 與 H₂O₂ 循環生成 •OH）充當促氧化劑。這正是高劑量靜脈注射抗壞血酸用於 [[Cancer]] 治療的理論基礎：毫摩爾級的血漿抗壞血酸會優先在腫瘤組織中產生 [[Hydroxyl Radicals]]，因為腫瘤組織具有高含量的游離鐵與低量的 catalase。生理性的膳食攝取不會產生這種效果——這是一種取決於給藥途徑與劑量的藥理作用。

## 生理與臨床意義

- **壞血病**：典型的缺乏症——疲倦、瘀點、牙齦出血、傷口癒合不良、毛囊周圍出血；補充後數日內即可逆轉。
- **免疫支持**：抗壞血酸濃集於嗜中性白血球，並在呼吸爆發期間增強趨化、吞噬與 ROS 生成；補充劑在一般人群中對感冒病程有輕微的縮短作用，在承受身體壓力者中效果更明顯。
- **心血管**：維持 NO 生物可利用度、減少 [[Oxidized LDL]] 形成，並改善內皮依賴性血管擴張；流行病學上的攝取量與心血管風險呈負相關，惟補充試驗的結果不一。
- **神經退化**：腦中抗壞血酸隨年齡下降，在 [[Alzheimer's Disease]] 與 [[Parkinson's Disease]] 中更低；它能保護 substantia nigra 免受兒茶酚胺醌類與脂質過氧化損傷。
- **鐵吸收**：在 enterocyte 將膳食中的 Fe³⁺ 還原為 Fe²⁺，大幅提升非血基質鐵的吸收。## 與脂質過氧化軸的關係

維生素 C 無法單獨阻斷 [[Lipid Peroxidation]]——它與該過程並不同步。它的貢獻在於再生脂相捕獲劑（[[Vitamin E]]），並維持 [[Glutathione]]/[[GPX4]] 系統的運作。因此，抗壞血酸缺乏會間接放大脂質過氧化：生育酚自由基無法被回收，膜上的 PUFA 鏈反應得以走完全程，[[Malondialdehyde]]、[[4-Hydroxynonenal]] 與 [[Acrolein]] 隨之累積。

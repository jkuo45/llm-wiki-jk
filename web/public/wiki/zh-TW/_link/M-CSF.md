# M-CSF（巨噬細胞群落刺激因子）

**巨噬細胞群落刺激因子（M-CSF，又稱 CSF-1）** 是 CSF-1 家族的二聚體、含 cysteine-knot 的分泌性醣蛋白，為單核球–巨噬細胞譜系的主要營養與存活因子。它僅透過 [[CSF1R]]（CD115，一種受體酪胺酸激酶）傳訊，是單核球自骨髓動員、各組織巨噬細胞分化，以及包括微膠細胞在內之常駐巨噬細胞維持與表型所必需。

## 概述

M-CSF 是群落刺激因子家族的創始成員，也是單核球與巨噬細胞生物學的主要調控者。它經單一受體 CSF1R 作用，控制單核球離開骨髓、各組織巨噬細胞分化、組織常駐巨噬細胞（含微膠細胞）存活，以及巨噬細胞在抗原呈現與促腫瘤表型上的馴化。

## 結構與結構域

- **基因**：*CSF1* 位於 5q33；選擇性剪接與蛋白水解產生分泌型、膜結合型與具生物活性的細胞內型。
- **同源二聚體**：兩個相同次單元以鏈間雙硫鍵相連；每個單體含 N 端 Ig 樣結構域、cysteine-knot（PDGF 樣）生長因子結構域與 C 端 fibronectin type III 結構域。
- **CSF-1R**：單次跨膜第三型受體酪胺酸激酶，具含結合面的胞外 Ig 樣結構域、跨膜螺旋與胞內酪胺酸激酶結構域。IL-34 亦可活化此受體，兩配體下游訊號相似但細胞特異性不同。
- **蛋白水解**：跨膜型可被切割釋出高活性可溶型因子。

## 作用機制與路徑

- CSF-1 結合誘發 CSF1R 二聚化與自體磷酸化，隨後受體內化並運往溶酶體，訊號在該處持續；CSF-1 結合 CSF1R 的溶酶體結構域，是連結受體運輸與基因表現之「溶酶體轉錄軸」的關鍵調控步驟。
- **下游**：PI3K–AKT（存活、代謝重編程）、RAS–RAF–MEK–ERK（增殖與分化）、STAT3（自我更新與抗凋亡）。AKT 與 mTORC1 活化促使巨噬細胞轉向糖解、清除受體高表現的表型。
- **轉錄輸出**：誘發巨噬細胞身分基因，包括 PU.1 依賴增強子與執行吞噬程序的轉錄因子。
- 亦作用於骨髓中的 [[Monocytes]] 與前驅細胞，對樹突細胞前驅細胞作用較弱。

## 生理功能

- **單核球生成**：促進單核球分化；缺乏 CSF-1R 的小鼠幾乎完全沒有組織巨噬細胞。
- **組織常駐巨噬細胞**：肝臟 Kupffer 細胞（[[Kupffer Cell]]）、肺泡巨噬細胞（[[Alveolar Macrophages]]）、脾邊緣區與紅髓巨噬細胞、微膠細胞（[[Microglia]]）、Langerhans 細胞與腎臟常駐巨噬細胞的維持均依賴 CSF-1R。
- **母胎發育**：胎盤與胚胎巨噬細胞增殖。
- **骨重塑**：[[Osteoclast|破骨細胞]] 分化經由 M-CSF–CSF1R 軸，並驅動其存活與活性。
- **免疫調節**：使巨噬細胞適於抗原呈現與 [[Inflammation|發炎]] 消退期；與 IL-4、IL-13 同為典型巨噬細胞極化細胞激素。

## 病理與臨床關聯

- **腫瘤相關巨噬細胞**：許多腫瘤過度表現 CSF-1 與 CSF1R，CSF-1 在 [[Tumor Microenvironment|腫瘤微環境]] 中招募並極化促腫瘤巨噬細胞，支持生長、血管新生、免疫逃逸與 [[Metastasis|轉移]]；[[Tumor-Associated Macrophage|TAM]] 是免疫抑制微環境的主要成分。
- **發炎性疾病**：過量 CSF-1 促成類風濕性關節炎、發炎性腸道疾病、動脈粥狀硬化（[[Foam Cells]]）與 [[Inflammaging]] 中的巨噬細胞擴張；CSF1R 是致病性發炎巨噬細胞的標記。
- **骨疾病**：過量 M-CSF 訊號促成破骨細胞性骨流失，包括類風濕性關節炎與停經後骨質疏鬆。
- **致癌訊號**：CSF1R 是 AML 的反覆突變標的，CSF1R 易位則定義一部分組織細胞腫瘤。
- **治療**：CSF1R 抑制劑（pexidartinib、BLZ945、axatilimab 等單株抗體）正於癌症、發炎與纖維化疾病中試驗。因 CSF-1 與 [[TNF-alpha]]、IL-6 協同驅動發炎性巨噬細胞，雙重阻斷正被探索。

> [!info] 治療樞紐
> CSF1R 抑制劑同時被開發於腫瘤（抑制 TAM）與發炎／纖維化疾病；與 TNF-alpha、IL-6 的雙重阻斷是合理組合方向。

# 細胞骨架

**細胞骨架**——[[Actin]]微絲、微管與中間絲——組織細胞的形狀、分裂與運動。整合素-FAK 黏著（[[FAK Signaling]]、[[Focal Adhesion]]）將細胞外基質與肌動蛋白應力纖維耦合，把基質硬度轉化為[[Cell Migration]]與增殖訊號。

## Documents

- [[FAK Signaling]] — 黏著斑激酶在遷移情境中將整合素與細胞骨架重塑連結起來。
- [[Focal Adhesion]] — 將肌動蛋白細胞骨架錨定於基質的黏著複合體。

## 連結

- [[Actin]] — 細胞骨架的核心絲狀結構
- [[FAK Signaling]] — 黏著至細胞骨架的訊號傳導
- [[Focal Adhesion]] — 細胞骨架錨定複合體
- [[Cell Migration]] — 由細胞骨架動態驅動的過程
- [[Myosin]] — 在細胞骨架軌道上運作的分子馬達

# Phagolysosome（吞噬溶體）

**吞噬溶體**是吞噬路徑的終末胞器：[[Phagosome]] 與一個或多個 [[Lysosome|Lysosome]] 融合的產物。它是單一酸性、具降解性、富含活性氧的空間，被吞噬的微生物在此被殺死與分解，所得肽段則被載入 [[MHC type II|MHC class II]] 以供 [[Antigen Presentation]]。它與 [[Autolysosome]] 功能不同，雖然兩者皆為「吞噬體／囊泡 + 溶體」的雜交體。

## 結構與組成

吞噬溶體以其膜組成與腔內化學性質界定，而非單一蛋白：

- **膜**：富含溶體蛋白 [[LAMP1]]/[[LAMP2]] 與 V-ATPase；成熟過程中脂質組成向膽固醇與鞘脂偏移。
- **腔**：pH 約 4.5–5，由 [[V-ATPase]] 維持；高濃度溶體水解酶——[[Cathepsins]]（半胱胺酸型 B、L、K；天門冬胺酸型 cathepsin D）、酸性磷酸酶、糖苷酶與 RNase。
- **活性物質**：吞噬體膜上組裝的 [[NADPH Oxidase]] 產生超氧與過氧化氫，加上鐵依賴性 Fenton 化學與溶體 ROS。
- **膜修復機制**：吞噬體易受損，經溶體胞吐與膜封閉路徑修復；[[Phagocytic Lysosome Reformation]] 在損傷後重建吞噬溶體。

## 作用機制

1. **吞噬體成熟**：吞噬後先經 [[Rab5]] 與早期內體融合，再經 [[Rab7]] 與溶體融合，酸化並取得溶體膜蛋白，成為吞噬溶體。
2. **氧化殺菌**：嗜中性球與巨噬細胞的 NADPH 氧化酶在吞噬體膜組裝並產生超氧，轉為過氧化氫；與溶體水解酶、防禦素共同殺死病原。成熟與 ROS 相互依存。
3. **蛋白水解與抗原處理**：組織蛋白酶把病原及其蛋白降解為肽段；MHC 第二類分子行經此胞器被載入肽段，再輸出至細胞表面活化 CD4⁺ T 細胞。
4. **溶解與回收**：消化後殘餘物經胞吐排出或再降解；受損膜被修復，胞器由溶體再生成重建，回收溶體組件而不需重新合成。

## 生理角色

吞噬溶體是 [[Neutrophils]]、[[Macrophage|Macrophages]] 與 [[Kupffer Cell]] 等組織駐留吞噬細胞的抗微生物效應胞器。除殺菌外，它也是蛋白與脂質周轉、向適應性免疫呈現抗原、以及經 [[Efferocytosis]] 清除凋亡細胞的主要場所。它亦參與自噬相關周轉：[[Autophagosome-lysosome fusion|自噬體–溶體]] 融合產物（[[Autolysosome]]）是處理胞內貨物的對應降解胞器。

## 臨床意義

> [!important] 病原如何癱瘓吞噬溶體
> *Mycobacterium tuberculosis* 阻斷吞噬體成熟、僅部分酸化，因而能在吞噬溶體內存活；[[Legionella]] pneumophila 挾持吞噬體建立自身複製龕並逃入細胞質。兩者說明病原中和吞噬溶體的策略。

- **慢性肉芽腫病**：NADPH 氧化酶缺陷（如 NOX2 或 p47phox 突變）使氧化爆發消失，吞噬溶體無法殺死觸酶陽性菌——由 [[NADPH Oxidase]] 直通反覆感染與肉芽腫形成。
- **溶體儲積症**：吞噬溶體內降解失敗造成受質堆積，如 Gaucher 病等。
- **發炎與細胞死亡**：溶體膜通透化把組織蛋白酶釋入細胞質，可觸發 [[Autophagic Cell Death]] 或凋亡；持續的吞噬溶體活化驅動關節炎、動脈粥狀硬化與 [[Inflammaging]] 的慢性發炎。
- **抗原呈現失敗**：吞噬溶體成熟缺陷（如 Hermansky–Pudlak 或 Chediak–Higashi 症候群）損害 MHC 第二類載入，造成複合性免疫缺陷。

# SUV39H1

SUV39H1（suppressor of variegation 3-9 homolog 1），又稱 KMT1A，是一種組蛋白甲基轉移酶，特異性對組蛋白 H3 第 9 位離胺酸進行三甲基化（[[H3K9me3]]），這是典型的異染色質標記。在衰老過程中，SUV39H1 表現下降，而拮抗性的 H3K9 去甲基酶 [[KDM4]] 上升；此轉變減少 SASP 位點的 H3K9 甲基化，並促進 SASP 表現增強。

## 概述

SUV39H1 是 SET 域 H3K9 甲基轉移酶家族的創始成員。它生成 H3K9me3，招募異染色質蛋白 1（[[HP1alpha]]）以形成兼性與組成性異染色質。SUV39H1 作用於著絲粒周圍區與受抑制位點，維持轉錄抑制與基因組穩定。

## 結構與功能

催化 SET 域將甲基從 SAM 轉移至 H3K9。H3K9me3 由含 chromodomain 的蛋白（HP1α/β/γ）「讀取」，驅動染色質壓縮與受抑制域的擴散。SUV39H1 活性由正回饋迴路強化：H3K9me3 招募 HP1，HP1 進而協助招募 SUV39H1 甲基化相鄰核小體。

## 在衰老／SASP 中的作用

該綜述將 SUV39H1 置於調控 SASP 的 H3K9 甲基化軸上。主要 SASP 基因 [[IL-6]] 與 [[IL-8]] 周圍 H3K9me2/3 喪失，與其誘導相關（ref. 67）。在衰老細胞中，SUV39H1 蛋白下降而 KDM4 上升，導致整體 H3K9 甲基化狀態下降、SASP 表現增強（refs. 68, 69）。因此，SUV39H1↓／KDM4↑ 的平衡使抑制性異染色質轉向 SASP 位點所需的開放、轉錄可及狀態。這與 H3K27 軸（[[EZH2]] 對 [[JMJD3]]）及 H3K4 軸（[[MLL1]]）平行，共同構成衰老中抑制性標記的協調鬆弛。

## 機制細節

- IL-6/IL-8 啟動子處 H3K9me2/3 喪失，移除 SASP 轉錄的制動，類似於 H3K27me3 喪失。
- SUV39H1–KDM4 拮抗作用是衰老中更廣泛「抑制性染色質喪失」計畫的一部分，該計畫還包括異染色質解壓縮（[[Senescence-Associated Distension of Satellites|SADS]]）與 SAHF 動力學。
- H3K9 甲基化下降促進增強子–啟動子接觸與驅動 SASP 的 3D 基因組重組。

## 治療相關性

藥理抑制 H3K9 甲基化（如 chaetocin 等 SUV39H1/SETDB1 抑制劑）在腫瘤學中受到探索。相反地，恢復 SUV39H1 活性可能是一種 [[Senomorphic|senomorphic]] 策略，在 SASP 位點重建 H3K9 抑制。KDM4 抑制劑 TACH101 正對晚期癌症進行第 1 期試驗（NCT05076552），該綜述將其列為候選的 senomorphic 老藥新用靶點。

## SIRT1 調控（Lys266）

[[SIRT1]] 結合 [[SUV39H1]]，透過去乙醯化 SET 域中的 Lys266 上調其甲基轉移酶活性；SIRT1 缺陷的上皮細胞表現 H3K9 低甲基化（via " + DOC + "）。

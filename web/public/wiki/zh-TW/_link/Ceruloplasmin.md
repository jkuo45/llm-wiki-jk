# Ceruloplasmin

**總覽：** Ceruloplasmin 是一種約 1065 個胺基酸（約 151 kDa）的**藍色含銅醣蛋白**，以 20–60 mg/dL 的濃度在血漿中循環，是體內含量最豐富的含銅蛋白。它執行兩項不同的任務：它是血漿中主要的**銅運輸蛋白**，也是體內唯一已知能**氧化鐵**的酵素（**ferroxidase，鐵氧化酶**），將 Fe²⁺ 轉為 Fe³⁺，使鐵能與apo轉鐵蛋白結合。

## 結構與結構域

Ceruloplasmin 屬於**多銅氧化酶（MCO）**家族；此家族在脊椎動物中包括 hephaestin 與 mossy-heart tyrosinase，在 *Saccharomyces cerevisiae* 中則包括 FET3。人類蛋白是一個**六結構域**（Cp1–Cp6）建構，由祖先三聚體 MCO 核心複製並融合而成：

| 結構域 | 區段 | 說明 |
| --- | --- | --- |
| Cp1 | 1–255 | 部分三聚化結構域；既不結合銅也不結合受質 |
| Cp2 | 256–507 | 雙核 **Cu(II)/Cu(III)** 中心（「藍色」位點，His369、His375、His419、His423、Met440），加上**第二型「白色」Cu(II)**——ferroxidase 位點，其鐵結合配體為 **Glu272、Glu935、His940、Asp1025** |
| Cp3 | 508–782 | 第二個三聚化結構域；結構性連接區 |
| Cp4 | 783–1026 | 三核簇，含**三個第一型「整合型」銅原子**（His-4 配體）——使蛋白呈藍色的位點 |
| Cp5 | 1027–1065 | 另一複製結構域的片段 |
| Cp6 | Cp2/Cp4 接縫的一部分 | 提供連接兩半部的雙硫鍵 |

Ceruloplasmin 在 MCO 中相當特殊，因為它在偶數編號的結構域中含**三個第一型「整合型」銅離子**，而其他 MCO 僅有一個。每個分子可結合**6–7 個銅原子**，在氧化態下的吸光光度極大值接近 610 nm。

> [!info] 名稱
> 此名稱意為「藍銅」（*cerulum*，天藍色）。臨床化學中的「血清銅」是以 ceruloplasmin 結合銅的方式間接測得；任一時點全身銅只有一小部分位於血漿中，因此 ceruloplasmin 偏低是**銅缺乏**的指標，而非銅過量的指標。

## 功能機制

**Ferroxidase 活性。** Fe²⁺ 载入 Cp2 的第二型（「白色」）位點，被 O₂ 氧化為 Fe³⁺，再釋放給 apo轉鐵蛋白。這是必要的：轉鐵蛋白**只結合 Fe³⁺**，因此 ceruloplasmin 決定了鐵可供運輸的速率。在向氧氣進行雙電子轉移的過程中，Cp2 與 Cp4 的銅位點會經由第二型與第一型中心進行氧化還原循環。

**銅的處理。** Ceruloplasmin 攜帶大部分血漿銅，將其運送至小腸上皮細胞基底外側膜的 hephaestin 依賴性輸出途徑，以進行跨細胞銅吸收；同時它自己也會經由去唾液酸糖蛋白受體（辨識其去唾液酸化的 N-聚糖）被肝細胞內吞——這是銅從血漿清除的主要途徑。

**急性期行為。** Ceruloplasmin 是一種由白細胞介素-6 驅動的**急性期反應蛋白**，在發炎、感染、妊娠與雌激素治療期間會上升 2–4 倍。因此血漿 ceruloplasmin 作為單一指標並不可靠，必須與 CRP 一起判讀。

## 臨床關聯

| 疾病 | 機制 | 發現 |
| --- | --- | --- |
| **Wilson 氏症**（ATP7B 突變） | 膽道銅排泄缺陷，且銅併入 ceruloplasmin 受損 | ceruloplasmin 低、血清銅低、尿銅高、肝臟銅蓄積 |
| **Aceruloplasminemia**（*CP* 失去功能） | ferroxidase 缺失 | 糖尿病、視網膜退化、神經系統疾病（張力不全、共濟失調、震顫）、基底核與視網膜鐵過載、肝臟鐵蓄積、性腺功能低下；血清 ceruloplasmin 無法檢出、血清鐵低、轉鐵蛋白飽和度極低、鐵蛋白高 |
| **鐵缺乏** | ferroxidase 的受質（血漿 Fe²⁺）耗竭 | ferroxidase 活性下降，因此轉鐵蛋白飽和度的降幅超出預期——這是評估銅狀態的直接功能性檢驗 |
| [[Anemia|慢性病貧血]] | 發炎驅動的 hepcidin 將鐵困在巨噬細胞網狀內皮系統中，使 ferroxidase 缺乏受質 | 轉鐵蛋白飽和度低而鐵蛋白正常偏高 |
| 一般[[Neurodegeneration|神經退化]] | ferroxidase 活性隨年齡與神經退化而下降 | 在[[Parkinson's Disease|Parkinson 氏症]]、[[Alzheimer's Disease|Alzheimer 病]]與 ALS 中均有 Cu 活性下降的報告 |
| [[Atherosclerosis|動脈粥狀硬化]] | Ceruloplasmin 既是抗氧化劑也是促氧化劑 | ceruloplasmin 偏低與心血管風險上升相關；ceruloplasmin 釋出的游離銅可氧化 LDL |
| [[Diabetes|糖尿病]] | 第二型糖尿病本身即可不依賴鐵狀態而降低 ceruloplasmin | 加劇血漿的促氧化環境 |
| 鐵過載症候群 | 次發性鐵過載仍需 ferroxidase | 在晚期遺傳性血球鐵質沈著症中 ceruloplasmin 下降 |

> [!warning] Ceruloplasmin 偏低不能診斷 Wilson 氏症
> Ceruloplasmin 在[[Proteinuria|腎病症候群]]（尿液流失）、營養不良、嚴重肝臟疾病、[[Anemia|貧血]]以及 *ATP7B* 異型合子的個體中也偏低。反之，多數肝臟合成功能完整且處於急性發炎的 Wilson 病人，ceruloplasmin 是*正常或偏高*的，因此正常值無法排除診斷。

**新興的神經生物學。** 腦中的 ceruloplasmin 主要由**星狀膠細胞**表現，而據報告，星狀膠細胞特異性的 ceruloplasmin 表現對視網膜與基底核的鐵處理及神經元存活至關重要。這是全身性 aceruloplasminemia 與其神經表現型之間的機制橋樑，也正被開發為[[Parkinson's Disease|Parkinson 氏症]]及相關疾病的治療標的。

## Connections
- [[Iron|鐵]]——ceruloplasmin 的 ferroxidase 活性正是讓 Fe²⁺ 能負載到轉鐵蛋白上的原因；缺乏它，鐵對紅血球前驅細胞的供應與輸出都會失敗。
- [[Transferrin|轉鐵蛋白]]——ceruloplasmin 所氧化產生的 Fe³⁺ 的唯一接受者；就全身鐵運輸而言，兩種蛋白在功能上不可分割。
- [[Ferritin|鐵蛋白]]——ceruloplasmin 活性決定有多少鐵可供鐵蛋白負載與儲存。
- [[Copper|銅]]——ceruloplasmin 是血漿中主要的含銅蛋白，並運送銅以供 hephaestin 依賴性輸出。
- [[Oxidative Stress|氧化壓力]]——ceruloplasmin 是抗氧化性的銅氧化酶，但其活性銅池可能轉為促氧化並氧化 LDL。
- [[ApoE]]——ceruloplasmin 釋出的游離銅會氧化 LDL，兩者作用於同一動脈粥狀硬化受質。
- [[Astrocytes|星狀膠細胞]]——腦中 ceruloplasmin 的主要中樞神經系統來源；星狀膠細胞失去 ceruloplasmin 會造成視網膜與基底核的神經退化。
- [[Hepatocyte|肝細胞]]——肝細胞經由去唾液酸糖蛋白受體清除血漿 ceruloplasmin，這是銅排除的主要途徑。
- [[Parkinson's Disease|Parkinson 氏症]]——腦中 ceruloplasmin 活性在 Parkinson 氏症與老化腦中下降，助長黑質的鐵蓄積。
- [[Alzheimer's Disease|Alzheimer 病]]——AD 腦中曾有 ceruloplasmin ferroxidase 活性下降的報告，將其與鐵失調文獻連結起來。
- [[Diabetes|糖尿病]]——第二型糖尿病不依賴鐵狀態而降低 ceruloplasmin，加劇氧化壓力。
- [[Oxidized LDL|氧化 LDL]]——ceruloplasmin 釋出的銅是 LDL 氧化與粥狀硬化生成的一條途徑。
- 鐵代謝——ceruloplasmin 位於鐵循環的輸出步驟，與 hephaestin 及 hepcidin 並列。

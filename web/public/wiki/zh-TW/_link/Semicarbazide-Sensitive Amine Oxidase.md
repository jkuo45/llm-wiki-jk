# Semicarbazide-Sensitive Amine Oxidase（氨基脲敏感性胺氧化酶）

**氨基脲敏感性胺氧化酶（SSAO）**又稱血管黏附蛋白-1（VAP-1）或 AOC3，是血管表面的含銅胺氧化酶，將一級胺轉化為醛、過氧化氫與氨。位於內皮細胞、脂肪細胞、血管平滑肌、纖維母細胞與活化發炎細胞的外膜，是局部氧化壓力與反應性醛類的產生源。

## 結構

- **基因**：*AOC3*（4q31）；蛋白為約 85 kDa 次單元組成的同源四聚體（A2B2），每個次單元具 N 端跨膜或 GPI 錨定、五個 seed 區段（S1–S5）與 C 端催化區。
- **催化中心**：**第三型銅（CuB）活性位點**加上拓撲結合的 pyrroloquinoline quinone（PQQ）輔因子；活性位點位於次單元界面，故活性需正確的四級組裝。
- **活性位點環**：「flap」（約 158–176 位殘基）控制受質進入並決定受質與抑制劑特異性；Tyr393 阻擋活性位點，受質結合時移位。
- **氨基脲敏感性**：semicarbazide、aminoguanidine 等肼衍生物配位銅並不可逆抑制此酵素——其命名與多數實驗藥理的基礎。

## 機制與途徑

1. **受質氧化**：一級胺（如 benzylamine、butylamine）結合 Cu/PQQ 位點，釋出氨並生成醛，副產物為**過氧化氫**，故其活性即局部 ROS 來源。
2. **離胺醯氧化酶交聯途徑**：[[Collagen]]與彈性蛋白的離胺酸被離胺醯氧化酶氧化脫氨成反應性醛，啟動基質共價交聯。SSAO 放大此化學：把生成的羥離胺酸/甘胺酸產物與半醛氧化為最終交聯前驅物，並使膠原鏈上胺基轉為醛而與離胺酸形成成熟交聯。
3. **訊息傳遞**：SSAO 產生的 H2O2 與醛活化內皮 NF-κB 與 MAP 激酶訊號，上調 VCAM-1、ICAM-1 與單核球招募，並在內皮細胞與[[Cellular Senescence|senescent cells]]誘發促發炎、類衰老表型。
4. **黏附**：VAP-1 最初被描述為結合淋巴球的內皮黏附分子，現多理解為其酵素活性的結果。

## 生理功能

SSAO 由發炎訊號與進階糖化誘導，表現隨年齡上升。生理角色包括清除循環一級胺、調控血管張力（H2O2 依濃度可為收縮或舒張訊號）、調節細胞外基質更新，以及影響脂肪細胞功能與胰島素敏感性。血管損傷與發炎部位的活性顯著升高。

## 病理與臨床關聯

- **糖尿病併發症**：高血糖、[[Advanced Glycation End Products|AGEs]] 與[[Methylglyoxal]]提高表現與活性，促成[[Type 2 Diabetes]]相關內皮功能障礙、視網膜病變、腎病變（[[Albuminuria]]）與加速的[[Atherosclerosis]]；其 H2O2 產物加重[[Oxidative Stress]]。
- **發炎性疾病**：發炎性腸道疾病、類風濕關節炎、乾癬與慢性發炎狀態中 SSAO 升高，與疾病活動度及單核球招募相關。
- **老化與發炎老化**：屬衰老相關與年齡相關的發炎酵素，在老年組織與[[Inflammaging]]中活性上升。
- **癌症**：於多種腫瘤與腫瘤內皮過度表現，參與血管新生、侵襲與轉移，為乳癌與大腸癌侵襲性疾病的標記。
- **藥理**：semicarbazide 與 aminoguanidine 可抑制，較新的專一性抑制劑（PXS-4728A/BI 1467335、ASP8232 與抗體策略）亦在開發中；aminoguanidine 系列曾用於糖尿病腎病與視網膜病變，但選擇性差限制其臨床應用。[[Aminoguanidine]]是氨基脲敏感性反應的原型試劑。

> [!info] 一個酵素，三種身分
> 黏附分子（VAP-1）、胺氧化酶（SSAO）與發炎驅動者其實是同一蛋白；其黏附功能多為酵素活性與下游訊號的結果，而非獨立機制。

# c-Rel

**c-Rel** 是 [[NF-κB]] 轉錄因子家族的成員，由 *REL* 原始致癌基因（proto-oncogene）編碼，與 RelA（p65）和 NF-κB1（p50）二聚化，調控發炎、存活與分化程序。它與家族其他成員共享 N 端 Rel homology domain，但其 C 端轉錄活化定義域使其成為異常強效的轉錄活化因子。

## 概述

c-Rel 是 [[NF-κB]] 超家族五個轉錄因子之一（[[RELA|RelA/p65]]、NF-κB1/p50、NF-κB2/p52、RelB 與 c-Rel），各自共享 N 端 Rel homology domain，且除 p50/p52 前體外，皆具 C 端轉錄活化定義域。c-Rel 最初被鑑定為禽類 v-rel 致癌基因的細胞同源物，並在家族中佔據獨特的中間位置：不如 RelA 普遍，但具最強的內在轉錄活化能力，並同時作為發炎驅動因子與耐受情境下的轉錄抑制因子。

## 結構與定義域

- **Rel homology domain（RHD）：** N 端約 300 aa，包含 DNA 結合 motif 與二聚化表面。各 RHD 可互換，因此 c-Rel 可藉由工程融合或夥伴可得性被強制納入任何二聚體。
- **Nuclear localization sequence：** RHD C 端的一段鹼性序列，受磷酸化與氧化還原狀態調控。
- **Transactivation domain：** C 端富含麩醯胺的區域，p50 與 p52 缺乏此定義域；它招募共活化因子（p300/CBP）並驅動強的轉錄輸出。除 RelA 與 RelB 外，c-Rel 是家族中唯一具內在轉錄活化定義域的成員。
- **Ankyrin repeat：** 一小段內部 ankyrin repeat 區域可結合並遮蔽 NLS，防止組成性核定位。

## 作用機制與路徑

- **IκB 依賴（典型）活化：** 在靜息細胞中，c-Rel 二聚體被 [[IκBα]] 隔離於細胞質。如 [[TNF-alpha|TNF]]、IL-1 或 [[Toll-like Receptor]] 配體結合等刺激會活化 IKK 複合物（IKK1/IKK2/NEMO），其磷酸化 IκBα 使其經由 [[Proteasome]] 與 [[Ubiquitination]] 機器被泛素化並進行蛋白酶體降解。游離的 c-Rel/p50 與 c-Rel/RelA 二聚體轉位至細胞核。
- **非典型活化：** [[NOD-like Receptors]] 可啟用替代的 IKKα 依賴路徑，將 p100 加工為 p52，並使 p52/RelB（與 p52/c-Rel）二聚體累積。
- **氧化還原控制：** c-Rel 對細胞內硫醇氧化還原狀態異常敏感；還原條件（高 [[Reactive Oxygen Species|ROS]] 驅動的 Keap1 氧化）增強其 DNA 結合，將 NF-κB 輸出與氧化代謝耦合。
- **標的：** 細胞激素（IL-2、IL-6、TNF、GM-CSF）、趨化因子、抗凋亡基因（[[Bcl-2]]、Bcl-xL、[[Survivin]]），以及如 [[MYC]] 等主要調節因子。

## 生理功能

c-Rel 為一組獨特、非冗餘的 NF-κB 輸出所必需：

- **B 細胞與 T 細胞活化與增殖：** c-Rel 缺陷淋巴細胞無法回應有絲分裂原，也無法維持 IL-2 產生；c-Rel 對初始 T 細胞發育非必要，但對擴增為必需。
- **免疫耐受：** c-Rel 與 RelB 一起被調節性 T 細胞與 B 細胞誘導，作為發炎基因的轉錄抑制因子，抑制自體免疫。
- **抗原呈現與樹突細胞成熟：** c-Rel 缺陷樹突細胞無法上調 MHC class II 與共刺激分子。
- **存活與增殖：** c-Rel 支持細胞週期進入與抗凋亡程序，與 [[Apoptosis]] 逃脫協同作用。

## 病理與臨床意義

- **淋巴瘤：** *REL* 基因座位於 11p13，在相當比例的 [[Diffuse large B-cell lymphoma]] 與何杰金氏淋巴瘤（Hodgkin lymphoma）中被擴增，且 *REL* 重排（如 *REL*–*BACH2*，見於 t(4;11) 樣急性淋巴芽細胞白血病）可產生組成性核定位、具二聚化能力的 c-Rel。*REL* 擴增本身是啟動事件，但不足以致淋巴瘤；需要協同病變（如 *NOTCH1*、*MYD88*、BCL2 轉位）——與 c-Rel 致癌的「two-hit」模式一致。
- **自體免疫與發炎：** 過量的 c-Rel 活性促進 [[Adaptive Immune System]] 脈絡中的 [[Inflammation]] 以及慢性發炎性疾病；c-Rel 缺陷小鼠對數種自體免疫模型具抗性，使 c-Rel 成為治療標的。
- **標靶治療：** 破壞 c-Rel 二聚體的胜肽抑制劑與 IKKβ 抑制劑正處於臨床前與早期臨床開發中。

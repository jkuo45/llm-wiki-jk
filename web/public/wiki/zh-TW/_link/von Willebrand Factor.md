# von Willebrand Factor（類血友病因子）

**類血友病因子（von Willebrand factor, vWF）** 是由內皮細胞與巨核細胞（儲存於血小板 α 顆粒）產生的大型多聚體血漿醣蛋白。它在初期止血中擔負兩項不可或缺的功能：在高剪應力處媒介血小板黏附於暴露的內皮下層，以及結合並保護第八凝血因子（factor VIII）免於清除。

## 概述

vWF 是初期止血的多聚體黏附蛋白，執行兩項獨立而互補的工作：在血流下經 GPIb-IX-V 複合體把血小板橋接至暴露的內皮下層，以及結合並穩定第八凝血因子。其含量與多聚體大小是 von Willebrand 氏病的分子基礎。

## 結構與結構域

- **基因**：*VWF* 位於染色體 12p13，超過 40 個外顯子，反映其加工複雜度。
- **多聚體架構**：成熟蛋白為約 2,250 kDa、以雙硫鍵連結的 pro-VWF 同二聚體。N 端的 A1 結構域帶血小板 GPIb 結合位（及 botrocetin 位點）；A3 結合細纖維 [[Collagen|膠原蛋白]]；C 端 D′D3 區帶第八凝血因子結合位。
- **前胜肽（D1D2）** 為多聚化與 type 1 抗原結合所必需；其缺失（如 type 2M/3）造成多聚體大小缺陷。
- **切割**：ADAMTS13 於 Tyr1605–Met1606 切割生成循環多聚體；由內皮 Weibel-Palade 小體釋出的超大形式是 ADAMTS13 的首選受質。

## 作用機制與路徑

1. 內皮 vWF 儲存於 Weibel-Palade 小體，剪應力或凝血酶（經 PAR1）觸發釋放；血小板活化時 α 顆粒亦釋出 vWF。
2. **血小板黏附**：vWF 結合暴露的內皮下膠原與血小板 GPIb（GPIb-IX-V 複合體），在流動血液中形成橋接而捕捉血小板。此交互作用具剪應力依賴性：有別於整合素媒介的黏附，vWF–GPIb 結合需要多聚體夠長、流速夠快，使 A1 結構域展開並暴露結合位。
3. **第八因子載運**：vWF 結合並穩定第八因子（D′D3／A1 區），保護其免於蛋白水解與清除，並將其定位至血小板表面，支持 tenase 活性與凝血酶生成。
4. **訊息傳遞**：vWF 結合 GPIb 經 Gαi–PLCβ–鈣訊號活化血小板，提升胞質 [[Calcium|鈣]] 並促使整合素 αIIbβ3 活化與纖維蛋白原結合以聚集。

## 生理功能

vWF 是血小板黏附的首要分子與初期止血栓的錨。它同時是第八因子的載體與伴護蛋白，故 vWF 缺乏會同時降低血小板黏附與內在凝血輔因子池。其釋放是內皮活化的經典標記：循環 vWF 與 vWF/[[Platelets|血小板]] 比值用於評估內皮損傷。內皮 vWF 亦參與發炎與白血球募集，其與平滑肌細胞整合素 αvβ3 的交互作用支持血管平滑肌遷移與新生內膜增生。

## 病理與臨床意義

- **von Willebrand 氏病（vWD）**：最常見的遺傳性出血疾病（多數型別為體染色體顯性），表現為黏膜皮膚出血。**Type 1**（量不足）、**Type 2**（質的變異：2A/2M/2B 之多聚體大小或 GPIb 結合缺陷，2N 之第八因子結合缺陷）、**Type 3**（嚴重同合子缺乏，vWF 測不到、第八因子極低）。診斷用 vWF 抗原、vWF 活性（ristocetin cofactor 或 GPIb 基礎分析）、第八因子濃度與多聚體分析；出血以 desmopressin（type 1 與部分 type 2）、含 vWF 之濃縮製劑（type 3、2A/2N）與抗纖溶藥治療；desmopressin 於 type 2B 為禁忌。
- **主動脈狹窄與 Heyde 症候群**：狹窄處的高剪應力切割高分子量 vWF 多聚體，造成後天性類 type 2A vWD，並因血管發育不良而胃腸道出血。
- **心血管疾病**：vWF 升高是內皮功能障礙的生物標記，可預測 [[Atherosclerosis|動脈粥狀硬化]]、中風與心肌梗塞的血栓事件；vWF 偏低則與血小板低下時的出血風險相關。
- **糖尿病與慢性發炎**：[[Diabetes|糖尿病]] 與 [[Type 2 Diabetes|第 2 型糖尿病]] 中內皮 vWF 升高，促成微血管血栓；[[Albuminuria|白蛋白尿]] 與腎病變伴隨此內皮活化。
- **後天性 vWD**：亦可見於主動脈狹窄、骨髓增生性腫瘤（後天 type 1 伴高分子量多聚體喪失）與自體抗體媒介型。
- **治療前沿**：重組 vWF 與基因治療在開發中；vWF–血小板 GPIb 交互作用拮抗劑用於血栓適應症的研究。

> [!warning] 用藥陷阱
> Desmopressin 會釋出內源性 vWF，但在 type 2B 會加重血小板聚集與血小板低下，屬禁忌。

# Actin（肌動蛋白）

**Actin** 聚合成微絲，塑造細胞形態、驅動運動能力並錨定細胞連接：內皮 [[CDH5]] 透過連環蛋白複合體與肌動蛋白相連，以控制通透性；Iba1 在 [[Microglia]] 中交聯肌動蛋白，參與吞噬作用與趨化性。Actin-[[Myosin]] 收縮驅動 [[Muscle]] 力量產生與細胞質分裂；[[Caspase-3]] 的切割在 [[Apoptosis]] 中瓦解細胞骨架。

## Documents（文獻）

- [[CDH5]] — 透過 p120/β/α-catenin 與肌動蛋白細胞骨架相連，形成黏著連接。
- [[Cytosol]] — 將肌動蛋白與微管、中間絲並列為細胞骨架組成成分。
- [[Iba1]] — 與肌動蛋白及凝溶膠蛋白結合，促進交聯，利於小膠細胞吞噬與運動。

## Connections（關聯）

- [[Cytoskeleton]] — 肌動蛋白絲所構成的網絡
- [[Myosin]] — 拉動肌動蛋白絲的馬達蛋白
- [[CDH5]] — 錨定於肌動蛋白的連接蛋白
- [[Caspase-3]] — 在細胞凋亡中切割肌動蛋白網絡
- [[Cell Migration]] — 由肌動蛋白重塑驅動的運動能力

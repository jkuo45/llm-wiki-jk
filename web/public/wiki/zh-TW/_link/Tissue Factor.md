# Tissue Factor

**Tissue factor（TF、factor III、CD142）**是第一型單次穿膜醣蛋白，是外在（組織因子）凝血路徑的主要細胞性啟動者。暴露的 TF 結合循環中的 factor VIIa 形成 TF–FVIIa 複合體，活化 factor X 與 factor IX，產生凝血酶與纖維蛋白血塊。

## 概覽

Tissue factor（factor III）是啟動外在凝血級聯的細胞表面受體—輔因子。它是唯一具穿膜結構域的凝血蛋白，通常被隔絕於內皮之下；其暴露，或在細胞與微粒上的異常表現，是止血與疾病中凝血酶生成的單一共同觸發點。

## 結構與結構域

- **基因**：第 1p21 上的 *F3*；選擇性剪接產生可溶型。TF 是唯一具細胞穿膜結構域、除循環可溶池外另有細胞外「組織」存在的凝血因子。
- **三個結構域**：與纖維母細胞生長因子同源的 N 端細胞外結構域、單一穿膜螺旋，以及短 C 端胞質尾。
- **轉譯後修飾**：N-連結醣化，以及關鍵的 TF–FVIIa 複合體**雙硫鍵依賴同源雙體化**，後者顯著增強促凝血活性。
- **表現**：富於內皮下滑平滑肌與周皮細胞、纖維母細胞與心肌細胞；在[[Monocytes]]與[[Endothelial Cells]]上由 TNF、IL-1 與凝血酶（經 PAR1）及組織因子路徑抑制因子（TFPI）耗竭所誘導；許多腫瘤異位表現。

## 作用機制與途徑

1. TF 以高親合力結合 factor VIIa（其輔因子），形成 TF–FVIIa 複合體。
2. 該複合體活化 factor X（成為 Xa）與 factor IX（成為 IXa，與輔因子 VIIIa）；Xa 與 Va 將凝血酶原轉為凝血酶。
3. 凝血酶切割纖維蛋白原成纖維蛋白、活化 factor XIII 成 XIIIa 以進行交聯，並經 PAR 受體活化[[Platelets]]。
4. **放大迴圈**：凝血酶與 TF 回饋增加 TF 表現（PAR1 訊號），而 Xa／TF–FVIIa 活性由組織因子路徑抑制因子、[[Antithrombin III]]與[[Factor XIIIa]]緩衝。
5. **凝血之外的訊號**：TF 接合活化 PAR2（PAR1/FVIIa）→ MAPK、PI3K–AKT 與鈣離子訊號，驅動[[Inflammation]]、[[Cellular Senescence]]誘導，以及在腫瘤中的促侵襲基因表現。

## 生理功能

TF 僅在組織損傷暴露內皮下 TF 之處啟動止血——該處通常被完整內皮覆蓋。它與組織因子路徑抑制因子（TFPI）在內皮上的共位域化設定門檻：無足量 TFPI 的暴露 TF 即產生凝血酶與纖維蛋白。TF 也作為不參與凝血之細胞上的訊號受體，介導促發炎與促遷移基因表現（衰老相關分泌表型誘導、趨化因子產生）。

## 病理與臨床關聯

- **血栓**：破裂斑塊、癌細胞、微粒與循環中帶有 TF 的單核球上的 TF 暴露，驅動動脈與靜脈血栓。含 TF 的微粒在敗血症、創傷與類 COVID 高凝血狀態中升高，促成纖維蛋白沉積與器官損傷。
- **癌症**：腫瘤細胞表現 TF，既促進腫瘤相關血栓，也促進 TF 介導的促侵襲訊號、血管新生與轉移播種。TF 表現在乳癌、胰臟癌與肺癌中是侵襲性疾病的標記；PAR2 軸是[[Tumor Microenvironment]]生物學的標的。
- **發炎與敗血症**：單核球 TF 驅動瀰漫性血管內凝血；TF 阻斷在實驗性敗血症中改善結局，並在病毒性肺炎中受到探索。
- **診斷／治療**：可溶 TF 與帶 TF 微粒是候選生物標記。直接 TF 抑制劑（例如 anti-TF 抗體、TFPI 模擬物）與 factor VIIa 抑制劑正為血栓與癌症相關凝血病變開發中；癌症病人的抗凝血治療可在不影響腫瘤控制的情況下減少血栓。

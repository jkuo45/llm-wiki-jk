# Amiodarone

**Amiodarone** 是一種第三類（兼具 I/II/IV 類特性）抗心律不整藥，可阻斷鉀離子、鈉離子與鈣離子通道，以及 β-腎上腺素受體，用於難治性心室性心律不整與 [[Cardiac arrest]] 復甦流程。其碘負荷與親脂性會造成甲狀腺功能異常、肺纖維化、角膜沉積物，以及長期使用的肝毒性。

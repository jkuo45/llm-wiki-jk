# RANK

RANK（receptor activator of nuclear factor-κB，基因符號 *TNFRSF11A*）是腫瘤壞死因子受體（TNFR）超家族的第一型跨膜受體，也是 [[RANKL]] 唯一的訊號受體。它是[[Osteoclast|破骨細胞]]形成、活化與存活的主控開關，其喪失在小鼠與人類中都會造成特有的骨骼與免疫表型。

## 結構與結構域

人類 RANK 是 616 殘基的第一型跨膜醣蛋白；該基因位於 18q 染色體。胞外區帶有四個富含半胱胺酸的偽重複序列（CRD），每個約 40 殘基、含六個保守半胱胺酸——正是這種模組化摺疊定義了 TNF 家族受體。RANK 之處特殊在於 CRD2、CRD3 與 CRD4 都缺少一個典型的內部雙硫鍵，該作用部分由廣泛的氫鍵網絡取代，在 CRD3 中則由一個**非典型 Cys125–Cys127 雙硫鍵**取代。「Loop3」頂端的這個額外橋鍵固定了該環的拓樸結構，也是 RANK 對 RANKL 相較於其他 TNF 配體之專一性的主要決定因子——突變 Cys127 或 Glu126 會消除配體結合能力。RANK–RANKL（以及 RANKL–OPG）的晶體結構顯示，受體停靠在三聚體配體的三個裂隙中。

胞質尾端長 383 殘基，含三個 TRAF 結合 motif。TRAF6 結合一個靠近膜的 Pro-X-Glu-X-X-(aromatic/acid) motif；TRAF1、TRAF2、TRAF3 與 TRAF5 則結合較遠端的區域。一個與 TRAF motif 不同的保守近膜區域結合磷脂酶-Cγ2，並為鈣離子流通所必需。

## 機制與下游訊號

RANK 沒有本身的酵素活性。配體結合（通常由鄰近細胞上的膜結合型 RANKL 進行）會使受體聚集成三聚體，尾端招募 [[TRAF6]]，後者是主要的轉接蛋白：TRAF6 缺乏的小鼠會出現嚴重骨質硬化症。活化的 TRAF6 透過 TAB1/TAB2–[[TAK1]] 複合體傳遞訊號以活化 [[IKK complex|IKK 複合體]]，因而啟動經典的 [[NF-κB]] 訊號；同時也獨立地透過 [[MAPK]] 途徑——[[JNK]]、[[p38 MAPK]] 與 [[ERK]]——以及 [[PI3K]]/[[Akt]] 傳遞訊號。

> [!info] 主控轉錄因子是 NFATc1
> NF-κB 與 AP-1（透過誘導 *c-Fos*）作用於上游，但破骨細胞的身分程式是由 NFATc1 書寫的，而 NFATc1 需要持續的[[Calcium Signaling|鈣離子振盪]]。這些振盪由 RANK 與帶有 ITAM 的共受體（OSCAR、TREM-2、PIR-A）協同產生，後者透過 Syk 與 PLCγ2 傳遞訊號。任一途徑中任一成分的喪失都會阻斷破骨細胞生成。

RANK 也間接驅動破骨細胞中的溶酶體生物生成：RANK 活化促進 [[TFEB]] 核轉位（透過 PKCβ）以及經由 [[MAPK]] 使 [[TFE3]] 磷酸化，從而提高骨吸收所需的溶酶體水解酵素的表現。

## 生理角色

- **骨重塑。** M-CSF 會在前驅單核／巨噬細胞譜系細胞上上调 RANK；接著來自成骨細胞譜系細胞的 RANKL 觸發分化、融合為多核破骨細胞，以及存活。缺乏 *Tnfsf11* 或 *Tnfrsf11a* 的小鼠會發生嚴重骨質硬化症，並伴隨牙齒萌出缺陷。
- **免疫系統。** RANK 表現於 T 細胞與[[Dendritic cells|樹突細胞]]，且為樹突細胞存活、淋巴器官發生與 T 細胞／樹突細胞溝通所必需。
- **乳腺。** 乳腺中的 RANK/RANKL 訊號對妊娠期間泌乳乳腺的發育是必需的。
- **反向訊號。** RANKL 本身也能作為受體作用；破骨細胞釋放的表現 RANK 的胞外囊泡可觸發成骨細胞分化——即反方向的「反向訊號」。

## 病理與臨床關聯

*TNFRSF11A* 的失去功能突變會造成**伴低丙種球蛋白血症的體染色體隱性骨質硬化症**，這是破骨細胞缺乏型的骨質硬化症（Guerrini et al., *Am J Hum Genet* 2008）。活化型突變會造成**家族性膨張性骨溶解**與**幼年型 Paget 病**；RANKL 突變則造成一種相關的隱性骨質硬化症。在[[Osteoporosis|骨質疏鬆症]]與類風濕性關節炎中，RANKL/RANK 比值會偏向 RANKL，而源自 T 細胞的 RANKL 會驅動[[Periodontitis|牙周病]]與[[Rheumatoid Arthritis|類風濕性關節炎]]中的局部骨侵蝕。

> [!important] 治療標的
> RANK 本身並未被直接藥物化，但這條軸已被：Denosumab 是一種針對 RANKL 的全人源 IgG2 單株抗體，已獲核准用於停經後與糖皮質素誘發的骨質疏鬆症、荷爾蒙剝奪相關的骨流失、[[Multiple Myeloma|多發性骨髓瘤]]與實體腫瘤骨轉移之骨骼相關事件的預防，以及巨細胞骨腫瘤。人類乳癌腫瘤中的 RANK 表現也與預後相關，支持了「腫瘤細胞的 RANK 驅動骨轉移」這個觀點。

## Connections

- [[RANKL]]——唯一的配體；結合使 RANK 三聚化並啟動所有下游訊號。RANK/RANKL/OPG 三元組是骨吸收的核心調節因子。
- [[TRAF6]]——必需的胞質轉接蛋白；TRAF6 缺乏的小鼠會出現骨質硬化症，使其成為 RANK 觸及 IKK 與 MAPK 的節點。
- [[Osteoclast|破骨細胞]]——其分化、活化與存活受 RANK 控制的細胞型態；其吸收機制在 RANK 下游依賴 TFEB／溶酶體。
- [[NF-κB]]——經由 TRAF6–TAK1–IKK 啟動的經典途徑；與 NFATc1 一同為破骨細胞生成所必需。
- [[TFE3]]——MAPK 依賴性的下游轉錄因子，將 RANK 與髓系及破骨細胞譜系的命定連結起來。

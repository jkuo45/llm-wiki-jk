# CRTC2

SIRT1 去乙醯化 CRTC2，是禁食期間肝臟糖質新生動態調控的一部分，與其對 FOXO1 與 PGC-1α 的作用互補，共同控制葡萄糖生成（Szczęsny-Małysiak et al., 2026）。

## 禁食開關（Liu et al., 2008）

在早期禁食，CRTC2 經乙醯化（CBP/p300）活化，驅動早期糖質新生基因；在長時間禁食，[[SIRT1]] 使 CRTC2 與[[FOXO1]]去乙醯化，將糖質新生從 CRTC2 驅動轉換為 FOXO1 驅動基因（Liu et al., 2008；經由 " + DOC + "）。

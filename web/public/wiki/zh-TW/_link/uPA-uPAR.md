# uPA/uPAR（尿激酶型纖溶酶原活化因子系統）

**uPA/uPAR 系統**由絲胺酸蛋白酶 [[uPA]]（urokinase plasminogen activator）與其 GPI 錨定受體 [[uPAR]]（CD87、PLAUR）組成。兩者在細胞表面的「駕駛艙」把 [[Plasminogen|纖溶酶原]]轉為 [[Plasmin|纖溶酶]]，將纖溶作用與細胞遷移、胞外基質重塑耦合，並透過受體運輸連結到基因表現。

> [!info] 命名說明
> 本註記把 uPA/uPAR 軸視為一個整體；兩個組成實體另有專屬註記 [[uPA]] 與 [[uPAR]]。

## 概述

uPA/uPAR 系統把蛋白水解與訊息傳遞耦合起來。絲胺酸蛋白酶 uPA 繫於 GPI 錨定受體 uPAR，在細胞表面產生纖溶酶；uPAR 被佔據時同時招募整合素與甲醯胜肽受體以驅動遷移與基質重塑，而被內化的受體則被送往溶小體以活化 mTORC1 並重塑轉錄。由於兩元件在本知識庫中已各自記載，本註記將其視為單一功能軸。

## 結構與結構域

- **uPA**：54 kDa 單鏈前絲胺酸蛋白酶（pro-uPA），含 N 端生長因子結構域（結合 [[uPAR]]）、kringle 結構域與 C 端催化結構域；有限蛋白水解後轉為活化之雙鏈型。[[Plasminogen|纖溶酶原]]亦帶 C 端離胺酸結合位（kringle）並經此結合 uPAR，故與 uPA 一同被招募。
- **uPAR**：GPI 錨定的三結構域蛋白——D1 結合 uPA，D2 結合玻連蛋白（vitronectin，把受體連向[[Extracellular Matrix|胞外基質]]黏附），D3 攜帶 GPI 錨。本身無酵素活性；訊息經共同受體傳遞（整合素 αvβ3、α5β1；甲醯胜肽受體 FPRL1/2）。
- **抑制物**：纖溶酶原活化因子抑制物-1（[[PAI-1]]）同時阻斷 uPA 與 tPA；α2-抗纖溶酶抑制纖溶酶。

## 作用機制與路徑

1. uPA 結合 uPAR D1；pro-uPA 與纖溶酶原在細胞表面共同組裝，使纖溶酶原活化集中於所需位置。
2. 生成的 [[Plasmin|纖溶酶]]分解纖維蛋白（纖溶），並活化前基質金屬蛋白酶（[[MMP-3]]、[[MMP-9]]），降解[[Extracellular Matrix|胞外基質]]並釋出游離的基質結合型生長因子。
3. **uPAR 訊息**：uPA 佔據 uPAR 觸發整合素共同訊息、FAK 活化、Rac1/RhoA 重塑，以及 MAPK 與 PI3K–AKT 存活訊號；uPAR D2–D3 切割片段（uPAR[84-95]）經 FPRL1 成為趨化訊號。
4. **溶小體—轉錄軸**：內化的 uPA–uPAR 被送往溶小體，複合體在此經 PI3K 依賴的 PI(4)P 再合成，招募並活化[[mTORC1-Lysosome Compartment|溶小體表面的 mTORC1]]。轉錄輸出包括 [[NF-κB]] 標的基因，以及在衰老細胞中 SASP 的蛋白水解分支。

## 生理功能

- **纖溶**：uPA 是多數組織中的主要纖溶酶原活化因子，對比之下[[Tissue Plasminogen Activator|tPA]] 在循環中居主導；兩者共同清除血管與癒合傷口中的纖維蛋白。
- **細胞遷移與組織修復**：uPAR 是遷移細胞的經典標記；玻連蛋白–uPAR–整合素交互作用在傷口癒合時把細胞錨定於基質。
- **免疫細胞行為**：單核球、嗜中性球與巨噬細胞表現 uPAR，支持[[Inflammation|發炎]]時的外滲與組織浸潤。
- **蛋白水解的恆定**：纖溶酶生成的空間局限可保護旁觀組織免於無差別水解。

## 病理與臨床關聯

- **癌症**：高 uPA／低 PAI-1（「uPA/PAI-1 比值」）是乳癌中最被驗證的預後標記之一，uPA 與其受體水準可指引輔助治療決策。此系統驅動侵襲、[[Metastasis|轉移]]，並在[[Tumor Microenvironment|腫瘤微環境]]中提供衰老相關分泌表型（SASP）的促遷移、降解基質分支；可溶性 uPAR（suPAR）為預後與免疫活化的生物標記。
- **纖溶與血栓**：uPA 活性受抑（PAI-1 偏高）促成低纖溶狀態與血栓風險，包括[[Atherosclerosis|動脈粥狀硬化]]與轉移情境。
- **發炎性疾病**：uPAR 自嗜中性球表面脫落會促進纖溶，並在[[Inflammation|發炎]]與[[Sepsis|敗血症]]中造成組織傷害。
- **治療**：uPA 抑制劑（upamostat）、PAI-1 抑制劑，以及 uPAR 導向抗體／抗體藥物複合體（如 B7-H3/uPAR ADC）均在臨床開發中。

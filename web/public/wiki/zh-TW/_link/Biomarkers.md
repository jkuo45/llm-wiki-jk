# 生物標記
在[[Geroscience|老年生物學]]領域，**生物標記（biomarkers）**是測量一個生物體生理狀態並預測其未來健康結果的必備工具。以[[Epigenetics|表觀遺傳學]]為基礎的生物標記，尤其是 **DNA 甲基化（DNAm）生物標記**，是目前測量「生物年齡」最準確的分子工具。
### 1. [[DNA Methylation|DNA 甲基化]] 生物標記
與時序年齡（自出生以來的時間）不同，表觀遺傳生物標記藉由分析 DNA 的特定化學修飾，評估組織與器官的生物年齡。
*   **[[CpG Island|CpG 島]]：** 此過程涉及監測甲基基團添加至胞嘧啶鹼基的情形，通常發生在 CpG 位點。
*   **表觀遺傳漂變：** 隨著生物體老化，DNA 甲基化模式會以可預測的方式改變——某些位點獲得甲基化（過度甲基化），而其他位點則失去甲基化（低甲基化）。
### 2. [[Epigenetic Clock|表觀遺傳時鐘]]
稱為表觀遺傳時鐘的數學模型，會選取一組特定的 CpG 位點來計算個人的「DNAm 年齡」。
*   **第一代時鐘：** 例子包括 **Horvath 時鐘**（一種多組織時鐘）與 Hannum 時鐘（血液專一性），它們與時序年齡高度相關。
*   **第二代時鐘：** **PhenoAge** 與 [[DNAmGrimAge]] 等工具的訓練目標是預測健康壽年、發病率與死亡率，而非僅僅預測時序年齡。[[DNAmGrimAge]] 尤其對吸菸等生活方式因子高度敏感，並能預測距死亡的時間。
### 3. 臨床與研究意義
*   **年齡加速：** 個人的 DNAm 年齡與其時序年齡之間的差值，是「年齡加速」的標記。正值表示該人在生物學上比其日曆年齡更老。
*   **疾病預測：** 表觀遺傳老化加速與[[Cancer|癌症]]、[[Cardiovascular Disease|心血管疾病]]及[[Neurodegenerative Diseases|神經退行性疾病]]（如[[Alzheimer's Disease|阿茲海默氏症]]）較高的風險相關。
*   **介入措施測試：** 由於表觀遺傳標記具有潛在的可逆性，這些生物標記被用於測試抗老化介入措施（包括飲食、運動與藥理治療）的效力。
### 4. 限制
*   **機制落差：** 雖然這些時鐘具有高度的預測力，但驅動這些特定位點產生甲基化變化的確切生物機制仍在釐清之中。
*   **組織專一性：** 在同一個體內，不同組織可能展現出不同速率的生物老化。

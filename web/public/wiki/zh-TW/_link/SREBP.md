# SREBP

**SREBP**（sterol regulatory element-binding protein）是錨定於內質網的 basic helix-loop-helix 轉錄因子家族，掌管脂質合成與膽固醇恆定。三個成員各有分工：**SREBP-1c** 驅動脂肪酸與三酸甘油脂合成（脂肪組織與肝臟），**SREBP-1a** 廣泛表現並將脂質合成與細胞生長連結，**SREBP-2** 則驅動膽固醇合成與 LDL 受體表現。

## 結構與活化

- SREBP 以先驅蛋白形式合成，含 N 端轉錄因子結構域、basic helix-loop-helix 亮氨酸拉鏈、結合 SCAP 的調控結構域，以及 C 端膜錨定區。
- 在內質網，SREBP 由 SCAP 與膜錨定區滯留；低膽固醇（與低固醇）使 SCAP 得以護送 SREBP-2 至高基氏體，由 S1P/S2P/S2P 蛋白酶切割，將 N 端片段釋入細胞核。
- [[Insulin]]與高糖亦經[[Akt]]介導的誘導並促進其加工過程而活化 SREBP-1c；因此[[Insulin Signaling]]與葡萄糖直接輸入脂質生成。
- [[AMPK]]磷酸化 SREBP-1c（並抑制其加工），這是 AMPK 活化及多種營養限制介入抗脂質生成作用的分子基礎。

## 生理功能

- SREBP-2 提升膽固醇合成的速率決定酵素 HMG-CoA reductase，以及 LDL 受體；此軸是[[Statins]]的作用標的。
- SREBP-1c 提升脂肪酸合成酵素（ATP-citrate lyase、fatty-acid synthase）與三酸甘油脂合成，是將過量碳水化合物轉為脂質的轉錄節點。
- SREBP 活性喪失造成脂肪營養不良與肝脂肪變性；慢性過度活化則驅動脂肪肝、血脂異常與胰島素抗性。
- 當蛋白水解與降解解耦時，核內 SREBP 亦誘導細胞凋亡與細胞週期停滯程式——這是將脂質合成連結至[[Cellular Senescence]]與肝細胞死亡的「脂毒性 ER 壓力」軸的基礎。

## 臨床意義

Statin（抑制 HMG-CoA reductase）、PCSK9 抑制劑、mTOR 與 AMPK 調節劑，以及胰島素增敏劑皆作用於 SREBP 軸的上游或下游；SREBP-2 活化狀態預測 statin 反應，SREBP-1c 則是 NAFLD 與代謝症候群的標的。

# p53
[[p53]]（由[[p53|TP53]]基因編碼；此庫中將基因與蛋白質整合為同一實體）是重要的腫瘤抑制蛋白，常被譽為「基因組的守護者」。它透過誘導細胞週期停滯、[[Apoptosis|細胞凋亡]]或[[Senescence|細胞衰老]]，協調細胞對 DNA 損傷的反應。
**p53**（又稱腫瘤蛋白 P53 或 TP53）是調節細胞週期、防止癌症形成的重要腫瘤抑制蛋白，常被譽為「基因組的守護者」。
## 在細胞重編程與多能性中的角色
在[[Cellular Reprogramming|細胞重編程]]中，[[p53]]是生成[[Induced Pluripotent Stem Cells|誘導性多能幹細胞]]（iPSCs）的主要路障。用於遞送[[Yamanaka Factors|山中因子]]（OSKM）的常見病毒轉導過程會觸發[[Innate Immunity|先天免疫反應]]，進而產生[[Reactive Oxygen Species|活性氧類]]（ROS）並造成氧化性 DNA 損傷。此損傷會活化[[p53]]，後者接著在被轉導的細胞中啟動[[Apoptosis|細胞凋亡]]或[[Senescence|細胞衰老]]，大幅降低 iPSC 誘導的效率。
雖然抑制[[p53]]能顯著提升重編程效率，但也帶來重大風險。在[[p53]]缺席下產生的 iPSC 更易發生染色體異常與基因體不穩定，從而提高治療應用中[[Tumorigenicity|腫瘤形成]]的風險。因此，尋找能暫時調節[[Innate Immunity|先天免疫反應]]、以避免活化[[p53]]卻又不永久使其失效的方法，是優化 iPSC 技術的關鍵研究領域。
## 在癌症中的角色
- **突變**：*TP53* 基因突變是人類癌症中最常見的基因改變之一。
- **Claudin-low T11**：帶有 p53 突變的小鼠乳癌模型，用於研究[[melittin]]的選擇性。
## SIRT1–p53 調節軸
SIRT1 與 p53 密切相連——兩者在物理上結合並互相調節對方的活性：
### SIRT1 去乙醯化 p53
[[SIRT1]]去乙醯化 p53 的多個離胺酸殘基：
- **小鼠 p53**：Lys³¹⁷、Lys³⁷⁰、Lys³⁷⁹
- **人類 p53**：Lys³²⁰、Lys³⁷³、Lys³⁸²
**去乙醯化的後果**：抑制 p53 的轉錄活化活性，並在氧化壓力與 DNA 損傷反應中**抑制細胞凋亡**。
### HIC1–SIRT1–p53 回饋迴圈
一套複雜的調節迴路支配此相互作用：
1. 正常情況下：**HIC1（hypermethylated in cancer 1）**壓制 SIRT1 表達 → 在壓力下促進 p53 活性與細胞凋亡
2. DNA 損傷復原：**p53 下調 HIC1** → 誘導 SIRT1 轉錄 → SIRT1 去乙醯化 p53 → 促進細胞存活
3. 老化期間：HIC1 高甲基化 → SIRT1 表達增加 → p53 去乙醯化 → **細胞發生腫瘤轉化的風險升高**
這代表一個 SIRT1–HIC1–p53 回饋迴圈，可能與年齡相關的癌症風險有關。
## p53 與細胞衰老
[[SIRT1]]可透過抑制 p53 的促凋亡活性（經 PML 核體招募），將小鼠胚胎纖維母細胞從 PML 介導的早發性細胞衰老中挽救出來。
反之，在 SIRT1 缺乏的 MEF 中：
- 複製潛力延長
- 慢性亞致死壓力後具有更強的增殖能力
- 此表型需要 **p19ᴬᴿᶠ** 及其下游標的 p53
## p53 在 SIRT1 敲除表型中的角色
**SIRT1 缺乏小鼠**表現：
- DNA 損傷後 p53 過度乙醯化
- 胸腺細胞對游離輻射的敏感度增加
- 然而，在 SIRT1 敲除小鼠中消除 p53 並**不**能解除敲除表型，顯示 p53 過度乙醯化並非 SIRT1 敲除效應的主因
## p53 在癌症情境中的角色
### 肝細胞癌
在肝癌細胞（HepG2）中，**p33ᴵᴺᴳ¹ᵇ**與 SIRT1 相互作用，抑制其去乙醯化 p53 的能力 → 負向調節 AFP（甲型胎兒蛋白，肝細胞癌診斷標記）的轉錄。
### 攝護腺癌
有假說認為，在攝護腺癌細胞中，SIRT1 對 FOXO1 的去乙醯化（由 FHL2 增強）會在老化相關壓力增加時促進腫瘤形成——這代表 SIRT1/p53 途徑可能具有致癌意涵的情境。
### 腎臟疾病
SIRT1 **透過 p53 去乙醯化**減少氧化壓力誘導的腎絲球細胞凋亡，從而預防腎絲球疾病。
### 心臟保護
SIRT1 **以 p53 依賴的方式**保護心肌細胞免於程序性細胞死亡（經由血清飢餓或 PARP-1 活化）。
## 調節的複雜性
SIRT1/p53 途徑涉及超越單純 p53 去乙醯化的複雜機制，包括：
- 關於 SIRT1 是否損害輻射後胸腺細胞/脾細胞存活的矛盾報告
- SIRT1 究竟扮演腫瘤抑制因子或癌基因的情境依賴性
- 小鼠轉基因研究如今對解析*體內*角色至關重要

## 性別差異

> [!important] p53 受性荷爾蒙與 X 染色體調節
> p53 途徑展現廣泛的性別依賴調節：雌激素與 p53 雙向交互作用（活化 + 扣押），睪固醇在 C2C12 氧化模型中降低 p-p53，而 X 連鎖的 miR-504（假說中的劑量效應）提供另一層調節。這些差異促成癌症發生率、治療反應與老化軌跡的性別不平等。

### 雌激素–p53 雙向調節

雌激素與 p53 雙向交互作用——經 CTF-1/NF-κB/ERα 的轉錄活化，但也有 E₂–ERα 的物理扣押抑制 BAX/PUMA/NOXA。結果具情境依賴性。特定 ERα 元件數量需原始引文（先前「4 個元件 / Desai Cells 2025」未經證實；Huang et al., *Oncotarget* 2015）。

### 睪固醇抑制 p53

- 在骨骼肌 C2C12 氧化模型中，睪固醇透過 FoxO3a 使 p53 失活以對抗凋亡（Pronsato et al., *Steroids* 2017 — 僅限體外，勿廣泛推論至全身）。
- 在攝護腺癌中，p53 與雄性素受體（AR）互相抑制對方的功能：p53 結合 AR 啟動子並破壞 AR 的 N 端–C 端相互作用；DHT 降低 p53 水準。此雙向抑制在疾病進展為去勢抗性時喪失。

### X 染色體與 p53 途徑調節

- X 染色體編碼**約 10% 的人類 miRNA**。X 連鎖的 miR-504（Xq26.3）靶向 TP53 3'-UTR（Hu *Mol Cell* 2010）；雌性經逃脫 X 失活而享有的劑量優勢屬假說（無證據顯示 miR-504 逃脫 XCI）。
- **KDM6A/UTX**（逃脫 X 失活）增強 p21 轉錄，使雌性在 p53 介導的衰老上擁有獨特的劑量優勢。
- 雌性具備**「不表現突變」屏障**：X 連鎖的 p53 調節因子可能突變但在其中一組等位基因上保持不表現，提供雄性所缺乏的功能喪失緩衝。

### 各性別的 TP53 突變頻率

- 在 12/13 種非生殖器官類型中，雄性具有**較高的 TP53 突變癌症族群頻率**，且與較差的存活率相關（Haupt et al., 2019；Dunford et al., *Nature Genetics* 2017）——發生率 + 每腫瘤突變率的合計。
- 帶有 TP53 突變的 NSCLC 雌性患者展現**較好的免疫治療反應**（PFS 6.1 vs 2.6 個月），顯示性別專一的臨床意涵。
- TP53 突變頻率在雄性腫瘤中較高，部分原因是雌性具有 X 連鎖 p53 調節因子的雙等位基因表現，提供了備援機制。

### SNP72（Pro72Arg）— 性別專一效應

- Pro72 偏向衰老而非凋亡 → 腫瘤抑制較弱，但在丹麥隊列中**中位存活期 +3 年**。
- 壽命益處在德國隊列中**僅限雌性**。
- 曾報告性別專一的癌症風險關聯（需原始文獻驗證；先前「Desai Cells 2025」未經證實）。

### p53 與性別專一的衰老支線

- 雌性細胞偏好 **p53→p21→衰老**（細胞週期停滯）；雄性細胞偏好 **p53→凋亡**（細胞死亡）。
- 子宮內的卵巢程式化使雌性偏向 p21 依賴的衰老；KDM6A 經由 X 連鎖的表觀遺傳調節中介此作用。
- 此一衰老支線選擇的性別差異對癌症治療（誘導衰老的療法在雌性可能更有效）與老化（雄性累積較多的凋亡性細胞流失）具有意涵。

### 各性別的 Trp53⁻/⁻ 小鼠表型

- 標準表型：兩性皆出現胸腺淋巴瘤。
- 淋巴瘤被預防時：**雌性發展出較多的骨肉瘤**。
- 雌性 Trp53R210X/R210X 小鼠繁殖力差且體型較小，暗示 p53 具性別專一的發育角色。

### 交叉連結：統一的性別專一細胞死亡框架

- p53 位於本庫統一細胞死亡框架（[[Apoptosis|細胞凋亡]] ↔ [[Caspases|Caspase]] ↔ p53 ↔ [[Bcl-2]]）的**決策點**：雌激素在某些組織中驅動 p53 趨向促凋亡的 BAX/PUMA/NOXA 標的，在另一些組織中則扣押它（抗凋亡），而性荷爾蒙使 p53 依賴的選擇偏向[[Apoptosis|細胞凋亡]]（經由[[Caspases|Caspase]]）或[[Senescence|衰老]]之一。
- 雌性偏好 p53→p21→衰老支線（見上），而雄性細胞則偏向同一 p53/AIF 軸中[[PARP1]]依賴的壞死支線——完整的 XX-caspase / XY-PARP-1 生理學見[[Apoptosis|細胞凋亡]]與[[Caspases|Caspase]]。

## 連結
- [[Apoptosis]]：[[p53]]是重編程期間細胞對壓力反應的主要程序性細胞死亡誘導者。
- [[Caspases]]：p53 驅動的 caspase 活化為雌性偏好（見統一的[[Apoptosis]] ↔ [[Caspases]] ↔ p53 ↔ [[Bcl-2]]框架）。
- [[Bcl-2]]：p53 轉錄驅動 BAX/PUMA/NOXA，對抗雌激素支撐的 Bcl-2 閾值。
- [[Senescence]]：[[p53]]活化的主要結果之一，可防止體細胞進入多能狀態。
- [[Cancer]]：作為腫瘤抑制因子，[[p53]]的喪失或突變是多種癌症的特徵，凸顯 iPSC 製備中使其失效的安全風險。
- [[Cellular Reprogramming]]：[[p53]]是高效誘導多能性最顯著的生物學障礙。
- [[OSKM]]：經病毒載體遞送四個山中因子通常會導致[[p53]]活化。
- [[melittin]]：評估其對 p53 突變腫瘤細胞株的選擇性。
- [[Apoptosis]]：p53 是細胞凋亡途徑的關鍵調節者。
- [[SIRT1]] — 直接去乙醯化並抑制 p53 轉錄活性；主要調節關係
- [[HIC1]] — 與 SIRT1 形成複合體；HIC1–SIRT1–p53 回饋迴圈
- [[FoxO1]] — 癌症情境中 SIRT1 的相關標的
- [[Apoptosis]] — p53 驅動細胞凋亡；SIRT1 介導的去乙醯化抑制此作用
- [[Senescence]] — p53 中介衰老；SIRT1 可經 p53 去乙醯化加以對抗
- [[PML]] — 在衰老反應中將 SIRT1 與 p53 招募至核體
- [[NF-κB (RelA/p65)]] — 細胞凋亡調節中平行的 SIRT1 標的
- [[MnSOD]]：經 SIRT1 去乙醯化的 p53 上調 MnSOD。
- [[Apoptosis]]：SIRT1 對 p53 的去乙醯化減少細胞凋亡。

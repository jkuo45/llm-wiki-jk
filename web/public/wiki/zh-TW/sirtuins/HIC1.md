# HIC1

**HIC1**（Hypermethylated in Cancer 1）是一種具序列特異性的鋅指轉錄抑制因子，含 N 端 POZ/BTB 域。它是在基因體區域（17p13.3）經常發生高甲基化、突變或缺失於多種人類癌症中的關鍵抑癌基因。HIC1 結合 GC 富集的啟動子，並招募共抑制複合物來沉默參與細胞週期調控、壓力反應與 DNA 修復的標的基因。

## 結構與功能域

N 端 POZ/BTB 域介導同二聚化與招募轉錄共抑制因子（包括 SIRT1 與 HDAC）。五個 C 端 C2H2 鋅指介導序列特異的 DNA 結合。HIC1 經常與 [[p53]] 及其他抑癌基因共同存在於核內亞核體，反映其在壓力反應中的整合角色。

## HIC1–SIRT1–p53 反饋迴路

HIC1 在一個複雜的轉錄反饋迴路中作用，與 [[SIRT1]] 和 [[p53]] 共同調節細胞對 DNA 損傷的存活與凋亡反應：

1. **抑制 SIRT1**：HIC1 經由其 N 端 POZ 域與 [[SIRT1]] 啟動子形成物理複合物，直接抑制 SIRT1 轉錄。此舉使 SIRT1 水平保持低位，讓 [[p53]] 保持活性（乙醯化狀態），在壓力下驅動凋亡通路。
2. **p53 活化 HIC1**：在細胞壓力下，活化的 p53 直接反式活化 HIC1 表現。
3. **DNA 損傷修復**：當細胞從 DNA 損傷中恢復時，p53 下調 HIC1，使 SIRT1 表現短暫上升。接著 SIRT1 使 p53 去乙醯化，減弱凋亡反應，促進細胞存活與恢復。
4. **衰老與癌症風險**：在衰老與腫瘤發生期間，*HIC1* 啟動子經常發生高甲基化，導致基因沉默。這會使 [[SIRT1]] 異常上調，持續使 [[p53]] 去乙醯化並失活，從而增加壓力下的細胞存活並提高腫瘤轉型的風險。

## 生理與病理功能

此反饋迴路體現了一種精密平衡：短暫的 HIC1 表現對不可修復的損傷強制執行強的 p53 依賴性凋亡反應，而在修復後下調 HIC1 則促進存活。當 *HIC1* 在癌症中被表觀基因沉默時，此迴路偏向 SIRT1 驅動的 p53 失活，助長基因體不穩定與治療抗性。

## 臨床意義

*HIC1* 高甲基化是多種惡性腫瘤（乳癌、肺癌、膠質瘤）中的預後與預測性生物標誌。恢復 HIC1 表現或選擇性抑制 SIRT1 去乙醯酶活性，可能重建 p53 的抑癌監視。此軸亦與 [[Aging]] 相交，因為 *HIC1* 中逐漸累積的表觀漂移可能使組織偏向促存活、一癌前狀態。

# DBC1

**DBC1**（**D**eleted in **B**ladder **C**ancer **1**，亦稱為 **CCAR2**）是一種抑癌基因，係因其在膀胱癌中的缺失而被發現。它是 [[SIRT1]] 的負向調控者：DBC1 結合 SIRT1 的 N 端，抑制其 NAD+ 依賴的去乙醯酶活性（Kim et al., 2008; Zhao et al., 2008）。

## 機制

- 結合 SIRT1 的 N 端可阻斷受質去乙醯化，抑制 SIRT1 驅動的存活程式（包括 p53 去乙醯化）。
- 抑癌基因 DBC1 與 [[HIC1]] 分別作用於不同層次：DBC1 抑制 SIRT1 酶活性，而 [[HIC1]] 抑制 SIRT1 基因轉錄。
- 由於 DBC1 與 [[HIC1]] 在某些癌症中被沉默，其缺失間接促進腫瘤發生——至少部分是因為使 SIRT1 失去箝制。

## 關聯

- [[SIRT1]]: DBC1 抑制的直接酶標的。
- [[HIC1]]: 在轉錄層次作用於 SIRT1 的平行抑癌煞車。
- [[p53]]: 當 DBC1/HIC1 缺失使 SIRT1 失去箝制時，其下游效應被抑制。

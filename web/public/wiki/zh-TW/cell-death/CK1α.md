# CK1α

**CK1α**（酪蛋白激酶 1α；基因 *CSNK1A1*）是 [[CK1]] 絲胺酸／蘇胺酸激酶家族的 α 異構型，也是調控紅血球存活的異構型。在成熟紅血球中它具**促 eryptosis** 作用：調節細胞質 Ca2+ 活性，其活化與抑制皆使 PS 外露朝預期方向變化。

## 結構與結構域

CK1 各異構型共用 N 端催化結構域與帶自磷酸化位點的 C 端調節尾；CK1α 另有 C 端脂質錨定基序（N 端豆蔻醯化甘胺酸）使其定位於膜上。CK1 激酶通常需要鄰近殘基上由其他激酶提供的「priming」磷酸才能有效停泊，這使 CK1α 活性與上游訊號耦合。

## 機制與途徑

- **經 Ca2+ 促 eryptosis。** 在人類與小鼠紅血球中，以 D4476 或 (R)-DRF053 抑制 CK1 可減弱葡萄糖耗竭與 tert-butyl hydroperoxide 誘發的細胞質 Ca2+ 上升、annexin V 結合增加（PS 外露）與細胞皺縮（Zelenak et al., 2012）。CK1α 專一性活化劑 pyrvinium pamoate 則相反：增強 Ca2+ 上升與 PS 外露，並活化對 Cl⁻ 敏感的可通透 Ca2+ 陽離子通道、抑制 Ca2+ 活化的 K+ 通道，因此放大 Ca2+ 進入而減弱皺縮。
- **不依賴 caspase。** CK1α 對 eryptosis 的效應在無 caspase 招募的死亡細胞中同樣重現，顯示 CK1α 位於 Ca2+ 閾值的上游或平行位置，而非 caspase 下游。
- **與有核細胞的悖論。** CK1α（以及 [[PKC]]、JAK3）在有核細胞多為抗凋亡，在紅血球卻促 eryptosis——這是無核細胞效應器組被截短所致。
- **抑制劑注意事項。** 吡啶基咪唑類 p38 抑制劑 SB203580 與 SB202190 在體外亦抑制 CK1，因此僅憑此類化合物推論的「p38 依賴性」可能受 CK1 抑制混淆。

## 病理與臨床意義

CK1α 活性升高或失調會降低 eryptotic 閾值、縮短紅血球存活，並在氧化壓力與能量耗竭情境（敗血症、慢性腎病、瘧疾）促成貧血。CK1 抑制劑主要作為 WNT 途徑與癌症研究工具（如 D4476、PF-4800567）；作為紅血球存活藥物的用途仍屬實驗性。

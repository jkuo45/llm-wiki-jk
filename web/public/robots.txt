# llm-wiki-jk — Longevity-Focused Biomedical Wiki & Knowledge Graph
# An interactive biomedical knowledge graph with a longevity focus built
# around three themes: adrenochrome (catecholamine oxidation chemistry),
# mitohormesis (hormetic mitochondrial stress signaling), and autophagy
# (cellular clearance) — alongside sirtuins/NAD+ metabolism, senescence,
# and oxidative stress — with an analysis panel that lets you prompt the wiki
# or explore the graph (3D exploration + quantitative multi-node network
# analysis). Bilingual EN / 中文.
#
# All content is public and crawlable: the interactive graph (root),
# articles (/pages/), and the machine-readable graph data (/data/, JSON
# with per-node descriptions used by the web app).

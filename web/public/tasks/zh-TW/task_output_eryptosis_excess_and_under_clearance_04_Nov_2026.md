# 紅血球凋亡（eryptosis）— 過度死亡訊號與清除不足；證據綜合

範圍：機制導向的彙整，探討 [[Eryptosis]] 作為成熟紅血球的受調控細胞死亡（RCD）、其在長壽／抗老化論述中的定位、可歸因於 eryptosis 的紅血球週轉比例（量化與未量化者），以及兩種失敗模式——加速型 eryptosis 與 eryptosis 不足／清除不足。證據層級：Tier 1 = 人體 RCT／介入試驗；Tier 2 = 人體世代／關聯性研究；Tier 3 = 囓齒類／體內動物；Tier 4 = 體外或離體人體血液／細胞；Tier 5 = 假說。目前沒有任何 Tier 1 證據支持將 eryptosis 調節作為介入手段。

## 機制核心（簡述）

成熟紅血球無核、無胞器，無法執行粒線體凋亡。[[Eryptosis]] 以 Ca²⁺ 依賴的執行機制定義：胞質 Ca²⁺ 經由陽離子通道（TRPC6、NMDA/AMPA、[[Piezo1]]、Cav2.1）進入 → 活化 [[Gardos Channel|Gardos 通道（KCNN4）]] → K⁺/Cl⁻/水外流 → 細胞皺縮；抑制 flippase 並活化 [[Scramblase]] → [[Phosphatidylserine|磷脂醯絲胺酸（PS）]]外翻；活化 calpain → 細胞骨架蛋白水解／出泡。PS 陽性細胞在**數分鐘**內經由胞葬作用被清除（衰老細胞：數天），因此老化細胞中的 PS 陽性即代表 eryptotic 活化。Eryptosis 為非溶裂性、膜完整，且 PS 暴露具抗發炎性；[[Hemolysis]] 則是促發炎的意外性替代路徑，其被先行的 eryptotic 清除所阻斷，正是 eryptosis 的主要生理學理由。完整的訊號圖譜請見 [[_document_ - Current understanding of eryptosis mechanisms, physiological functions, role in disease, pharmacological applications, and nomenclature recommendations|Tkachenko et al., Cell Death Dis 2025;16:467]] 與 [[Eryptosis]] 筆記。

## 以此路徑死亡的細胞比例

正常人群中經歷 eryptosis 的紅血球比例在所引文獻中**未被量化**；不得引用任何數值。已量化者：

- 紅血球壽命 ≈ **120 天**；週轉 ≈ **每日約 1% 的紅血球質量**（常見報告為約 2–3 × 10⁶ 細胞 s⁻¹）。Eryptotic 清除是此通量中受壓力細胞的子集；參見 [[Erythrocytes]] 筆記與 Tkachenko et al. 2025。
- 基線 PS 暴露 ≈ 對照世代中**0.5–0.6%** 的紅血球（PV/ET 文獻報告；並非 eryptosis 專一檢測——annexin V 結合也會標記其他狀態）。
- 老化細胞更易發生 eryptosis（氧化誘導的 PS 暴露），且 PS 陽性的衰老細胞被計分為 eryptotic（Tkachenko 2025）。
- 疾病可顯著提高此比例：例如鉛暴露工人 PS 陽性 2.82% vs 0.1%（vault 擷取的職業資料）；PD 腹膜炎第 1 天較對照增加 3 倍；eGFR < 60 mL/min/1.73 m² → eryptosis 高於 eGFR ≥ 60（p < 0.001）（Clementi 2022）。

解讀：eryptosis 是紅血球的主要 RCD，但穩態下 eryptotic 清除與衰老抗原／IgG 清除之間的比例未發表。除「未量化」之外的任何數字皆無法由所引來源支持。

## 在長壽／抗老化論述中的定位

Eryptosis 是品質監控的清除臂，而非嚴格意義上的衰老調控者。可成立的長壽論述：

- **預防溶裂性、促發炎的處置方式。** [[Hemolysis]] 釋放 Hb/heme/ATP/IL-33/HSP70 → TLR4/NF-κB 內皮活化、NETs、補體募集、heme 驅動的壞死性凋亡／HO-1 鐵死亡／NLRP3 焦亡、腎小管血紅素蛋白損傷。Eryptosis 在細胞溶裂前將受損細胞移除；PS 外翻具抗發炎性，巨噬細胞攝取為促消退（HO-1 上調、促發炎細胞因子下降；實驗性腦內出血模型）。Tier 4–3。
- **系統性氧化還原與紅血球能量代謝作為長壽讀出。** [[Glucose-6-Phosphate Dehydrogenase|G6PD]]/PPP → NADPH → glutathione reductase；能量耗竭 → PKCα → Ca²⁺；AMPK 抑制 eryptosis（AMPKα 缺失小鼠：脾腫大、貧血——Tier 3）；NO → sGC → cGMP → [[cGMP-Dependent Protein Kinase I|cGKI]] 抑制 eryptosis（eNOS 缺失小鼠清除紅血球較快——Tier 3）；[[Erythropoietin|EPO]] 急性抑制 eryptosis，但持續高 EPO 會增加易 eryptotic 的細胞（Tier 2 世代／Tier 4）。
- **紅血球區室的老化提高易感性。** Eryptosis 易感性隨細胞年齡增加，部分經由氧化敏感性；NAC 在體外阻斷 eryptosis，並在體內延長小鼠紅血球半衰期（Tier 3–4）。人體轉譯未見報告。
- **宿主防禦。** *Plasmodium* 感染的紅血球由 eryptosis 清除；G6PD 缺乏、鐮刀型特徵、地中海貧血特徵藉由降低 eryptotic 閾值提供部分保護（Tier 2）。這界定了 eryptosis 可被壓制的程度上限。
- **生物標記框架。** Eryptosis 可指示氧化／尿毒症／發炎負荷；與 MPO、Cu/Zn SOD、IL-6（Clementi 2022；Tier 2）及敗血症內毒素活性／IL-6（Tier 2）相關。用作暴露／嚴重度標記有用；未驗證作為長壽替代終點。

Eryptosis 對長壽**不**代表什麼：沒有證據顯示調節 eryptosis 可延長人類壽命或健康壽命；所有介入資料皆為動物／離體。應將抗 eryptotic 藥理學視為臨床前階段。

## 加速型 eryptosis 的後果

### 貧血與紅血球生成刺激劑（ESA）低反應性
- CKD/ESRD：紅血球壽命縮短至 **60–90 天**（Frontiers Pharmacol 2025；PMID 41383483）；貧血盛行率隨 CKD 分期上升；透析病人 >90%。ESA／鐵劑校正約半數治療病人效果不佳。較高的發炎、副甲狀腺素、較低的白蛋白、ferritin 與 eryptosis 生物標記相關（Gok 2022；PMID 35469112）。程序：eGFR < 60 vs ≥ 60 → eryptosis 較高（p < 0.001）；eryptosis 與 MPO（ρ = 0.77, p = 0.01）、IL-6（ρ = 0.52, p = 0.05）相關。
- CKD 關聯世代中的貧血續發症狀：生活品質受損、心血管併發症、疾病進展、認知障礙、失眠、較高死亡率（Bissinger, FEBS J 2019）。Tier 2——關聯性，非因果。
- Eryptosis 橫跨多種疾病：癌症（週轉驅動的貧血；cisplatin/topotecan/tamoxifen/sorafenib/sunitinib 具促 eryptotic 作用）、心衰竭、肝功能衰竭、敗血症、瘧疾；「慢性病貧血」反覆與 eryptosis 相伴。

### PS 介導的促凝血活性
- 外翻的 PS 提供凝血酶原酶組裝（factor X 活化）的催化表面；在某些病理狀態下，紅血球對凝血酶生成的貢獻可達 **約 40%**（Tkachenko 2025；報告，此處未重新推導原始數據）。
- 紅血球衍生微囊泡暴露 PS，並經由 **factor XII（接觸路徑）、組織因子非依賴** 途徑觸發凝血酶生成（van der Meijden 2012；J Thromb Haemost 10:1355–62）。
- PS 暴露的紅血球結合血小板（CD36／PS 受體）與內皮（**CXCL16/SR-PSOX**、CD36、thrombospondin-1）。動脈剪切速率下的黏附已於離體證實；可被 annexin V 或 CXCL16 阻斷／沉默減弱（Borst 2012；Am J Physiol Cell Physiol 302:C644–51）。
- 肝硬化：血球與內皮細胞上的 PS 縮短凝血時間，提高凝血酶／纖維蛋白形成（Wu 2016；Liver Int 36:1800–10）。

### 內皮功能障礙與攝取
- PS/CXCL16 介導的黏附；隨後**內皮細胞攝取 eryptotic 細胞，並誘導內皮鐵死亡**（Tkachenko 2026；Biochim Biophys Acta Mol Cell Res 1873(5):120161；PMID 42155670）。Tier 4→3 機制性；人體結果數據缺如。
- 並存的促消退臂：巨噬細胞吞噬 eryptotic 細胞後重編程為促消退表型；腦出血情境（HO-1 依賴）。淨體內效應取決於區室（內皮／免疫促發炎 vs 巨噬細胞促消退）。

### 微循環障礙
- 黏附 → 微聚集 → 毛細血管血流下降；已見於鐮刀型貧血與糖尿病；並被指涉參與 Long COVID 纖維蛋白類澱粉微血栓（假說）與溶血性尿毒症候群。
- CKD ESRD 綜述：eryptotic 細胞可能黏附血管壁並損害微循環；當 ESA 劑量被強制推至高目標時風險放大（Lang 2017；Kidney Blood Press Res 42:749–60）。

### 發炎訊號——雙臂
- 促消退：胞葬作用、HO-1 上調、細胞因子抑制（腦內出血模型；Tier 3）。
- 促發炎：eryptosis 與 IL-6、MPO、CRP 相關（腹膜炎、闌尾炎、敗血症）；從 eryptotic 紅血球釋放的 EVs 攜帶 DAMPs（見於儲存的紅血球濃縮液）；當清除飽和時發生溶血 → 完整的 DAMP 級聯（TLR4/補體/NETs/發炎小體）。

### 前饋迴路（機制性描述，非臨床實體）
氧化壓力／尿毒素／能量耗竭 → 陽離子通道開啟 → Ca²⁺ → PS 外翻 → 加速胞葬作用 → 貧血 → 缺氧／ESA 升階 → 更多易 eryptotic 的循環細胞；同時 PS／內皮黏附 → 微血管受損 → 局部缺氧與 ROS → 進一步通道活化。每一環節皆有個別證據；端到端迴路在人體中未被實驗性閉合。

## eryptosis 不足或清除不足的後果

兩種不同的缺陷經常被混為一談：

- **死亡訊號不足**——受損細胞無法啟動 eryptosis（或被藥物學抑制）。
- **清除不足**——eryptosis 已執行（PS 暴露、皺縮），但胞葬作用飽和或受阻，PS 陽性細胞滯留於循環中。

已記錄的後果分為兩臂。

### 受損細胞滯留 → 溶血級聯
- [[Hemolysis]] 釋放 Hb、heme、ATP、IL-33、HSP70。游離 Hb 清除 [[Nitric Oxide|NO]] → 血管收縮、血小板活化、內皮功能障礙；游離 heme 驅動 Fenton 化學、TLR4/NF-κB 內皮活化、TNF-α 釋放、NET 形成、補體募集、NLRP3 發炎小體活化，以及 heme 驅動的內皮／免疫細胞受調控死亡（壞死性凋亡、HO-1 依賴性鐵死亡、焦亡）。Tier 4/3；溶血病理生理在人體疾病中已充分建立（鐮刀型貧血、地中海貧血、輸血反應、機械瓣膜）。
- 釋放的血紅素蛋白經腎過濾造成腎小管損傷；haptoglobin 與 hemopexin 的緩衝為可飽和。Tier 2/4。
- 肝功能衰竭時 [[Bilirubin]] 與膽汁酸過量形成惡性循環，促使紅血球 Ca²⁺ 內流／神經醯胺生成 → eryptosis 更多而非更少——這是兩種失敗模式共存的例子。

### PS 陽性細胞滯留 → 促凝血與促黏附負擔
- 若胞葬作用飽和（大規模同步細胞死亡，如氧化劑暴露後）或受損（Kupffer 細胞功能障礙、stabilin-1/2 訊號缺陷，或 EV 清除超載），PS 暴露的紅血球滯留於循環。它們保留上述促凝血表面與黏附表型（CXCL16/SR-PSOX、CD36），因此血栓／微循環風險持續而非於數分鐘內解除。Tier 4；直接人體結果數據缺如。
- 紅血球不進行局部清除；肝竇 stabilin-1/2 辨識與 Kupffer 細胞攝取主導（實驗中 80% 紅血球衍生囊泡於 5 分鐘內被清除）。肝清除下降或輸注儲存濃縮液（累積 PS 陽性 EVs 與攜帶 DAMP 的微囊泡）可能延長受血者的 PS 暴露；臨床後果未量化。Tier 3–4/2（儲存損傷關聯）。
- CD47–SIRPα 是組成性的「不要吃我」煞車；老化紅血球通常下調 CD47。病理性的 CD47 保留或 SIRPα 訊號失衡會延遲清除；直接臨床對應未驗證。Tier 5/4。

### 宿主防禦的後果
- *Plasmodium* 感染紅血球依賴 eryptosis 清除；抑制 eryptosis 會使受感染細胞滯留循環。這是抗 eryptotic 治療的主要體內代價，以及與細胞毒性腫瘤凋亡的未解干擾。Tier 3/2（保護性 G6PD、鐮刀、地中海貧血特徵的流行病學）。

### 臨床地位
- 明確定義的人體「eryptosis 不足」症候群**不成立**。此失敗模式表現為溶血（細胞溶裂而非被清除），或較少被測量地表現為大規模氧化／尿毒症攻擊後持續的 PS 陽性細胞。不存在以生物標記為基礎的診斷閾值或介入試驗。應視為機制性的平衡力量，而非公認的適應症。

## 證據限制與轉譯缺口

- 無人體 RCT 的抗 eryptotic 治療；ESRD 中 eryptosis 抑制劑（NAC、NO/cGMP 軸、離子通道調節劑、EPO）的療效未確立；介入性主張僅限 Tier 3–4。
- 清除不足臂由溶血生理學與清除路徑細胞生物學推論而來，而非來自介入性人體世代；肝臟／Kupffer 清除的飽和與輸血相關的 PS/EV 負擔在臨床上未量化。
- 正常人群 eryptotic fraction：未量化。Annexin V 也會結合非 eryptotic 狀態；檢測標準化是 Tkachenko 2025 的主動建議。
- 因果性：多數疾病關聯為世代／離體；尿毒症、發炎與 ESA 劑量的干擾很少被完全校正。
- 抑制風險：瘧原蟲清除；與細胞毒性藥物的腫瘤細胞凋亡協同（未解決）；溶血保護喪失；EV-DAMP 負擔不確定。

## 結論

Eryptosis 是受損紅血球非溶裂、由 Ca²⁺/PS 執行的品質監控清除，也是有核組織中凋亡所服務之「受損細胞移除原則」的紅血球層級。它朝兩個方向失敗。**過度**將保護轉化為病理：ESA 低反應性的貧血、PS 驅動的凝血酶生成與微血管阻塞、伴隨鐵死亡性損傷的內皮黏附，以及在內皮與敗血症中偏向促發炎。**eryptosis 不足／清除不足**使受損或 PS 陽性細胞溶裂或滯留：NO 清除、heme/TLR4 發炎損傷、腎血紅素蛋白腎病變，以及缺乏及時巨噬細胞攝取的促凝血／促黏附負擔；最清楚的體內代價是 *Plasmodium* 清除喪失與溶血驅動的血管損傷增加。兩種失敗模式都收斂於貧血與血管功能障礙，但路徑不同。臨床上，過度臂在 CKD/ESRD、糖尿病、心衰竭與肝硬化中已被記錄；清除不足臂在機制上有支持，但缺乏明確的人體症候群或介入數據。正常 eryptotic fraction 未量化；所有介入資料皆為臨床前。對長壽／抗老化而言，eryptosis 最好被視為**系統性氧化／尿毒症／發炎負荷的生物標記與血管／血液學衰退的上游驅動因子**，而非已確立的抗老化標靶。

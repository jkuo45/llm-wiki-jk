# Propidium Iodide

**Propidium Iodide** (PI) is a membrane-impermeant intercalating dye excluded by intact plasma membranes. PI positivity reports membrane rupture: Annexin V+/PI− defines early [[Apoptosis]], while Annexin V+/PI+ marks [[Parthanatos]], lytic programs ([[Necrosis]], [[Necroptosis]], [[Pyroptosis]]), and late secondary necrosis of uncleared apoptotic bodies.

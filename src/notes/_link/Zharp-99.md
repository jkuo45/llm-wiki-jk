# Zharp-99

**Zharp-99** is a small-molecule inhibitor of [[RIPK3]] kinase activity used experimentally to block [[Necroptosis]]. It belongs to the same direct-inhibitor class as [[GSK872]] and [[GSK840]], targeting the core necrosome kinase rather than upstream [[RIPK1]] or downstream [[MLKL]].

> [!warning] Kinase-dead rerouting caveat
> Like other RIPK3 kinase inhibitors, Zharp-99 may not fully prevent adaptor-driven [[Apoptosis]] from kinase-dead RIPK3; pair with death-mode controls.

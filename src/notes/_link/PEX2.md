# PEX2

**PEX2** is a RING-finger ubiquitin ligase of the peroxisomal importomer (with [[PEX10]]/[[PEX12]]) that ubiquitinates the [[PEX5]] import receptor to recycle it after cargo delivery. Biallelic PEX2 loss causes [[Zellweger Spectrum Disorders]] with defective peroxisomal matrix import.

## Documents

- [[PEX13]] — importomer docking component functionally coupled to PEX2-mediated receptor recycling.
- [[PEX5]] — cargo receptor ubiquitinated by the PEX2/PEX10/PEX12 RING complex.

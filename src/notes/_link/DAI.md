# DAI

## Overview

DAI (DNA-dependent activator of IRFs) is the original name for [[ZBP1]]. See [[ZBP1]] as the main sensor note.

DAI senses Z-form nucleic acids (Z-RNA/Z-DNA) via its Zα domains and engages [[RIPK3]] through its [[RHIM]] motif, nucleating a [[RIPK1]]-independent [[necrosome]] that drives [[MLKL]]-mediated [[Necroptosis]] — a key antiviral backup when [[RIPK1]] or [[Caspase-8]] are blocked.

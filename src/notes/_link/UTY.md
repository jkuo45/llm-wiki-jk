# UTY

[[UTY]] (Ubiquitously Transcribed TPR Gene on Y Chromosome, also called KDM6C) is the Y-chromosome homolog of [[KDM6A]] (UTX). It lacks H3K27 demethylase activity but retains non-catalytic tumor-suppressor function (Gozdecka et al., 2018), partially compensating for KDM6A loss in males.

## Function

- No catalytic H3K27 demethylation; scaffolding roles in MLL/SET1 complex retained.
- Partial backup for [[KDM6A]]/[[KDM5C]]/[[DDX3X]] class EXITS genes with Y homologs.

## Sex Differences

- Males with [[KDM6A]] LOF plus mosaic chrY loss lose UTY backup (trend 10.2% vs 5.8%, P=0.077); X-X female compensation stronger than X-Y male compensation (36% vs 8.2%, P=0.0022; Dunford et al., *Nature Genetics* 2017).
- UTY is not fully equivalent — females retain net EXITS advantage (see [[EXITS]]).

# miR-134

**miR-134** (microRNA 134) is a brain-enriched [[MicroRNA]] that constrains CREB and [[BDNF]] expression in neurons.

## SIRT1 axis

- [[SIRT1]] promotes [[CREB]] expression through repression of miR-134 and induces transcription of [[BDNF]], which has crucial roles in normal cognitive function (Gao et al., 2010).
- Brain SIRT1 activation enhances — and SIRT1 deletion impairs — memory formation and synaptic plasticity in mice, mechanistically via this miR-134 arm.
- Directionally, SIRT1 sits upstream of miR-134 repression, which is in turn upstream of CREB/BDNF output.

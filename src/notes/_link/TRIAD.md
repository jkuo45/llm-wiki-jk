# TRIAD

## Overview

**TRIAD** (Test of Rapamycin In Aging Dogs) is a parallel-group, double-masked, randomized, placebo-controlled, multicenter clinical trial testing whether intermittent low-dose [[Rapamycin]] extends lifespan and healthspan in healthy middle-aged companion dogs. It is the first rigorous pharmacologic geroscience trial with lifespan endpoints **outside the laboratory, in any species**.

## Trial Design

- **Design:** Parallel-group, double-masked, randomized, placebo-controlled, multicenter
- **Population:** Healthy middle-aged dogs from the Dog Aging Project
- **Intervention:** Low-dose intermittent rapamycin
- **Primary endpoints:** Lifespan + healthspan metrics
- **Reference:** Coleman et al., *Geroscience* 2025 (PMID: 39951177)

## Mechanistic Expectations

Intermittent low-dose rapamycin → mTORC1 partial inhibition → ULK1 de-repression → improved autophagic flux + immune/metabolic effects. Prior small canine cardiac studies suggested improved diastolic function with short-course rapamycin.

## Translational Significance

- Companion dogs share environment/exposome with owners, develop spontaneous age diseases (MMVD, CKD, cognitive dysfunction, cancer)
- Extreme breed size variance provides natural lifespan experiments
- Short lifespan allows trial completion in years, not decades
- Canine DNA methylation clocks track biological age

## Related Canine Evidence

- **MMVD cells (Tang 2025):** Rapamycin/torin-1 reverse senescence via autophagy in canine valve interstitial cells — high biological plausibility for cardiac aging endpoints
- **Canine MSCs (Deng 2021):** Curcumin delays senescence via autophagy activation; rapamycin phenocopies this effect

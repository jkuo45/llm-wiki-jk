# Neutrophil Elastase

**Neutrophil Elastase** (NE, gene *ELANE*) is a granule serine protease released during neutrophil activation. In [[NETosis]] it translocates to the nucleus, clips histones to aid decondensation (a PAD4-independent route when dominant), and decorates extruded NETs with [[Myeloperoxidase]] and [[cit-H3]] — forming the DNA–histone–protease web that traps pathogens and, pathologically, drives immunothrombosis. NE/MPO inhibition is part of the standard NETosis blockade panel.

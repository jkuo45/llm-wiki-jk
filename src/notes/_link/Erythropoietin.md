# Erythropoietin

**Erythropoietin** (EPO) is the kidney-derived cytokine induced by hypoxia-inducible factors that drives red-cell production via the EPO receptor/JAK2/STAT5 axis. In [[Eryptosis]] literature it is listed as protective — plausibly by supporting RBC energy/redox homeostasis and opposing Ca2+ overload — but a direct anti-eryptotic mechanism is not established in the cited sex-difference studies, so the comparison page flags it with an inference asterisk.

# Zellweger Spectrum Disorders

**Zellweger spectrum disorders** (ZSD) are autosomal-recessive peroxisome-biogenesis disorders caused by biallelic [[PEX2|PEX]]-gene loss ([[PEX2]], [[PEX10]], [[PEX12]], [[PEX13]], [[PEX5]]), abolishing peroxisomal import. The severe end (Zellweger syndrome) presents with hypotonia, seizures, liver dysfunction, and early lethality; milder infantile Refsum and Heimler phenotypes reflect residual import function.

## Documents

- [[PEX13]] — peroxisomal importomer component mutated across Zellweger spectrum phenotypes.
- [[PEX5]] — import receptor whose dysfunction produces Zellweger spectrum disorders.

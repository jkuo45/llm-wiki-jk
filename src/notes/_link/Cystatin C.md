# Cystatin C

**Cystatin C** (CST3) inhibits lysosomal cysteine cathepsins and is freely filtered at the glomerulus, making serum levels a muscle-mass-independent marker of kidney function (eGFR) superior to [[Creatinine]] in sarcopenia and aging. DNAm surrogates of cystatin C are built into GrimAge clocks; it rises with [[Acute Kidney Injury]] and predicts mortality.

# PEX12

**PEX12** is the third RING-finger subunit of the peroxisomal importomer (with [[PEX2]]/[[PEX10]]), required for ubiquitin-dependent recycling of the [[PEX5]] import receptor. Biallelic PEX12 loss produces [[Zellweger Spectrum Disorders]] with absent peroxisomal import.

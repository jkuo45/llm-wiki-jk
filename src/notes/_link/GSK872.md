# GSK872

**GSK872** is a small-molecule ATP-competitive inhibitor of [[RIPK3]] kinase activity, used alongside [[Necrostatin-1]] (RIPK1) and necrosulfonamide (MLKL) to dissect the necrosome rung by rung: death blocked by GSK872 but not Nec-1 implicates RIPK1-independent (TRIF/[[ZBP1]]) necrosome assembly. Caveat shared with all RIPK3 kinase inhibitors: kinase-dead RIPK3 can reroute signaling to adaptor-driven [[Apoptosis]], so GSK872 rescue must be read with death-mode controls.

In the comparison-table context, GSK872 is a defining entry of the necroptosis Blocked-by cell.

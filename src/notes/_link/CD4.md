# CD4

**CD4** is the co-receptor on helper T cells that binds [[MHC type II]]-peptide complexes, enabling Th1/Th2/Th17/Treg differentiation ([[T-bet]], GATA3, RORγt, FoxP3 programs). CD4+ helpers license B cells, CD8 killers, and macrophages; HIV depletes CD4+ cells to cause immunodeficiency.

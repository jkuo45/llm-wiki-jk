# Cyclosporine A

## Overview

Cyclosporine A (CsA) is a calcineurin-inhibiting immunosuppressant that is also the classic pharmacological blocker of the [[Mitochondrial Permeability Transition]]. It binds mitochondrial [[Cyclophilin D]], desensitizing pore opening.

## Mechanism in Cell Death

By occupying [[Cyclophilin D]], CsA prevents mitochondrial swelling, [[Reactive Oxygen Species]] burst, [[NAD+]] depletion, and downstream necrotic death. This makes it the standard tool for testing whether a necrosis model is MPT-dependent.

> [!tip]
> Contrast with [[Sanglifehrin A]]: both bind [[Cyclophilin D]], but [[Sanglifehrin A]] lacks calcineurin inhibition, so it separates MPT blockade from immunosuppression. Neither blocks canonical [[Necroptosis]] ([[RIPK3]]–[[MLKL]]) directly.

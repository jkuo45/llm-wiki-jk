# MIF

**MIF** (macrophage migration inhibitory factor) is a moonlighting protein with two separable lethal faces. Classically it is a pro-inflammatory cytokine amplifying [[NLRP3]]/IL-1β output and a [[Parkinson's Disease]]/[[Alzheimer's Disease]] biomarker. In [[Parthanatos]] it is **PAAN** (parthanatos-associated AIF nuclease): cytosolic [[AIF]] recruits MIF via a PD-D/E(X)K nuclease domain (E22 critical, tautomerase-independent), and the co-translocated pair executes large-scale DNA fragmentation, with AIF boosting MIF's DNA affinity.

[[HDAC6]] keeps MIF deacetylated to license AIF binding (HDAC6 inhibition blocks translocation); HSP70 sequesters cytosolic AIF as a brake; the brain-penetrant PAANIB-1 selectively inhibits the nuclease function. No verified sex difference exists for the MIF/PAAN step.

## Connections

# MitoStores

**MitoStores** are cytosolic [[Granule|granules]] that function as temporary storage depots for [[Mitochondrial protein import|mitochondrial precursor proteins]] when import into [[Mitochondria]] is impaired or saturated. They are part of the cellular triage system for managing [[mPOS]] (mitochondrial precursor over-accumulation stress).

## Mechanism

- Formed under conditions of mitochondrial import stress or when precursor production exceeds import capacity
- Regulated by [[Heat shock protein]] chaperones ([[HSP70]], [[HSP90]])
- Prevent precursor aggregation and [[Proteotoxicity]] in the cytosol
- Precursors remain in a [[Chaperone|chaperone-bound]], import-competent state
- When import capacity is restored, precursors are released from MitoStores and targeted to mitochondria

## Related Pathways

- [[mitoTAD]] — Constitutive degradation of stalled precursors
- [[mitoCPR]] — Stress-induced clearance at the TOM complex
- [[mPOS]] — Over-accumulation stress that MitoStores mitigate
- [[mitoRQC]] — Ribosome-level quality control
- [[UPRam]] — Mistargeting stress

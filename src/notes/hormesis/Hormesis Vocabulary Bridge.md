# Hormesis Vocabulary Bridge

Searching PubMed for `hormesis` or `hormetic` misses 80-90% of relevant literature because the same biphasic dose-response phenomenon travels under discipline-specific names.

> [!important]
> Key synonyms: [[Trained Immunity]], [[Preparation for Oxidative Stress]], [[Dietary Hormesis]], [[Eustress]], [[Exercise Hormesis]], ischemic preconditioning, repeated bout effect, preparation for oxidative stress, supercompensation.

## Synonym map

- Cardiology / neurology: ischemic preconditioning, remote ischemic conditioning
- Immunology: [[Trained Immunity]], priming, tolerance
- Nutrition: [[Dietary Hormesis]], [[Hormetin]], xenohormesis
- Plant biology: [[Eustress]] / distress, priming, seed priming
- Physiology: [[Preparation for Oxidative Stress]], conditioning hormesis
- Exercise neuroscience: [[Exercise Hormesis]], redox hormesis, mitohormesis
- Pharmacology: biphasic dose-response, [[Brosimine B]] hormetic window
